# 第1部分 设计边界、输入输出和总体数据链

## 1.1 本方案要实现什么

跟踪逻辑接收连续的数字中频复样点，为每个已建立的跟踪通道生成本地载波和本地码，对输入信号完成载波剥离、五抽头相关和约1 ms复数累加，再把定点相关结果交给处理器。处理器根据相关结果计算载波频率、载波相位和码相位误差，并向逻辑写入下一次控制命令。

本方案只设计实时逻辑部分，目标是回答下面五个问题：

1. 每个输入样点进入逻辑后依次经过哪些模块；
2. 每个模块使用什么定点格式，在哪里扩位、缩位或饱和；
3. 载波NCO和码NCO在什么时刻使用当前值，在什么时刻推进；
4. VE、E、P、L、VL五个相关抽头如何安排到有限数量的物理相关通路；
5. 一条PDI结果如何与实际使用的NCO、命令号和时间信息一一对应。

本方案不在逻辑中实现载波鉴频器、载波鉴相器、DLL鉴别器、环路滤波器、长时间积分、同步搜索、C/N0估计和跟踪状态机。这些模块需要较长历史、浮点或更复杂的控制策略，统一由处理器在PDI接口之后完成。

## 1.2 最小术语

| 术语 | 本文定义 |
|---|---|
| NCO | 数控振荡器。载波NCO保存载波相位和相位步进，码NCO保存码相位和码步进 |
| DDC | 数字下变频。输入IQ与本地载波做复数共轭相乘，得到基带IQ |
| tap | 一个本地码相位抽头。本文固定使用VE、E、P、L、VL五个抽头 |
| component | 同一信号中的数据分量或导频分量 |
| replica | 同一分量的不同本地副本，例如完整调制副本和PRN-only副本 |
| lane | 一条物理复数相关运算通路。lane可以分时更新多个逻辑相关结果 |
| PDI | Pre-Detection Integration，预检测积分结果。本文指约1 ms形成的一条硬件复相关记录 |
| channel | 一个独立跟踪通道，拥有自己的载波NCO、码NCO、累加器和命令状态 |

## 1.3 逻辑输入

### 1.3.1 连续IQ样点

每个时刻输入一个复样点：

| 字段 | 建议格式 | 说明 |
|---|---:|---|
| `sample_valid` | 1 bit | 当前拍输入样点有效 |
| `sample_index` | u64 | 绝对复样点编号，严格递增 |
| `sample_i` | s4 | I支路量化值 |
| `sample_q` | s4 | Q支路量化值 |

`sample_index`不能在PDI边界或状态切换时清零。它是检查输入缺口、关联捕获结果、复现NCO相位和定位第一错误样点的统一时间基准。

### 1.3.2 通道启动配置

通道开始工作前必须一次性装载：

| 字段 | 作用 |
|---|---|
| 信号参数 | 采样率、码速率、主码长度和每主码PDI数 |
| 码号与分量码表 | 选择本通道的数据码和导频码 |
| 启动样点 | 指定第一个由本通道处理的绝对样点 |
| 初始载波步进 | 载波NCO的初始频率控制字 |
| 初始码相位和码步进 | 码NCO的初始状态 |
| 抽头距离 | E/L和VE/VL相对P的码片距离 |
| 分量与副本使能 | 决定本通道需要计算哪些相关结果 |

启动配置必须在首个有效样点到达前稳定。运行中不得一边处理样点一边改写本地码存储。

### 1.3.3 运行命令

处理器通过运行命令更新载波步进、码步进、抽头距离和相关使能。所有字段必须作为一条完整命令原子生效，不能让载波步进先变、码步进晚几个样点再变。命令的目标历元和确认时序在第8部分单独设计，本部分只冻结“运行命令不得破坏连续载波相位和连续码相位”这一原则。

## 1.4 逻辑输出

### 1.4.1 PDI相关结果

每条PDI最多输出：

| 维度 | 最大数量 | 说明 |
|---|---:|---|
| component | 2 | 数据、导频 |
| replica | 2 | 完整副本、PRN-only副本 |
| tap | 5 | P、E、L、VE、VL |

因此最大逻辑相关数量为：

$$
2\times2\times5=20\ \text{个复相关结果}
$$

每个复相关结果包含独立的I、Q累加值。当前接口目标格式为s24 I和s24 Q；具体累加位宽证明放在第6部分完成。

### 1.4.2 PDI时间与控制信息

相关值之外，每条PDI还必须携带：

| 信息 | 用途 |
|---|---|
| PDI历元号 | 标识结果顺序 |
| 实际命令号 | 说明本PDI使用了哪一条控制命令 |
| 首样点编号与样点数 | 定义本PDI覆盖的输入区间 |
| 载波NCO首相位与步进 | 重建本PDI的载波参考 |
| 码NCO首相位与步进 | 重建本PDI的码时间轴 |
| 主码周期号和片段号 | 支持多PDI组成一个完整主码 |
| 异常标志 | 报告样点缺口、累加溢出和命令迟到 |

处理器只能依据PDI中记录的实际命令号和实际NCO参考解释相关结果，不能使用“原本打算写入的命令”替代逻辑真正使用的值。

## 1.5 总体逻辑数据链

![[90-附件/图LTFP-00_跟踪逻辑总体数据流_v01.svg]]

图LTFP-00只表达模块关系，不表达各模块内部需要多少流水拍。输入IQ沿上方主数据链流动：载波DDC先去除大部分载波旋转，相关调度模块再把同一个基带样点与多个本地码符号相乘，复累加器保存约1 ms的结果，最后形成PDI并写入输出FIFO。

载波NCO和码NCO位于下方本地生成支路。载波NCO只向DDC提供本地载波相位；码NCO产生当前P码相位，抽头地址模块再生成VE、E、P、L、VL五个地址，本地码模块根据地址读出码符号并送入相关调度模块。两条NCO支路彼此并行，它们都以同一个输入样点有效节拍推进。

## 1.6 模块职责边界

| 逻辑模块 | 必须完成 | 明确不做 |
|---|---|---|
| 输入接口 | 接收s4 IQ和绝对样点号，检查连续性 | 不缓存任意长时间原始IQ |
| 载波NCO | 保存u32相位与步进，逐有效样点推进 | 不计算载波误差 |
| 载波DDC | 复数共轭混频、定点缩位和饱和 | 不做长时间积分 |
| 码NCO | 保存连续码相位，处理主码回绕和片段边界 | 不计算DLL误差 |
| 抽头地址 | 从P相位生成VE/E/P/L/VL地址 | 不判断哪个抽头最强 |
| 本地码 | 输出数据/导频以及不同副本的$+1/-1$符号 | 不擦导航数据位或二次码 |
| 相关调度 | 把有限物理lane映射到全部逻辑相关槽 | 不合并不同槽的历史 |
| 复累加器 | 保存每个逻辑槽的独立I/Q累加 | 不计算幅值、功率或鉴别量 |
| PDI生成 | 在码片段边界冻结结果和时间信息 | 不执行跟踪状态判断 |
| 输出FIFO | 保持PDI顺序并吸收处理器调度抖动 | 不允许覆盖尚未读取的旧PDI |

## 1.7 第一部分冻结的基础参数

| 参数 | V0.1基础值 | 备注 |
|---|---:|---|
| 逻辑系统时钟 | 245.76 MHz | 后续所有逐拍时序以此为基准 |
| 最大输入采样率 | 30.72 Msps | 最少8个系统时钟处理一个样点 |
| 其他输入采样率 | 7.68、10.24 Msps | 拥有更多空闲系统拍 |
| PDI名义长度 | 约1 ms | 实际样点数由码NCO边界决定 |
| 最大component数 | 2 | 数据和导频 |
| 最大replica数 | 2 | 完整副本和PRN-only副本 |
| 固定tap数 | 5 | VE、E、P、L、VL |
| 最大逻辑复相关数 | 20 | $2×2×5$ |
| 相关输出目标格式 | s24 I/Q | 位宽证明留到第6部分 |

“约1 ms”不能被实现成固定样点计数器。码步进会受到载波辅助和码环修正，相邻PDI可能相差一个或少量样点；真正的结束条件必须来自连续码NCO越过下一个码片段边界。
