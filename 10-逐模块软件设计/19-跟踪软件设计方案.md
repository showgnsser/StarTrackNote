# GNSS跟踪软件算法设计

## 1 设计范围与阅读顺序

跟踪软件持续调整本地载波频率和本地码速率，使接收机保持在信号的相关峰附近，并确定数据位或导频二次码的位置。本文从硬件每1 ms输出的复相关结果开始，说明软件如何积分、测量误差、完成同步和更新环路。

硬件负责NCO、混频、本地码和相关；软件只消费PDI，不读取原始IQ或硬件内部相位。软件中的积分、鉴频、鉴相、码鉴别、载噪比估计及环路滤波均采用双精度浮点数，直接使用Hz、cycle、chip和chip/s。仅在PDI解码和硬件控制字编码处处理定点格式；历元、计数和码符号仍采用整数。硬件数值格式和装载时序见[[09-逐模块定点化/18-跟踪逻辑定点化设计方案|跟踪逻辑定点化设计方案]]。本文不展开寄存器地址、日志协议和导航电文译码。

| 章节 | 回答的问题 |

| 第5章：鉴别方法 | 怎样得到频差、相差和码差？ |

基础章节给出共用运算，信号章节给出完整处理顺序。普通牵引与同步后的Short、Long路径在信号章节展开；极弱和外部辅助状态单列适用边界，不从普通路径的积分表推断其配置。

### 1.2 基本术语

| 名称 | 本文含义 |
|---|---|
| PDI | 硬件形成的一条1 ms预检测积分结果，包含相关值和时间、有效性信息 |
| Prompt，简称P | 当前本地码位置上的复相关；E、L分别在其提前和滞后位置，VE、VL更远 |
| 复相关 $P=I+jQ$ | I、Q共同表示相关结果的幅度与相位；$j^2=-1$ |
| 主码 | 用来区分卫星并形成相关峰的伪随机码；chip是一个码片，也是码误差单位 |
| 数据位／数据符号 | 正负号未知、承载导航信息的符号 |
| 二次码／覆盖码 | 叠加在主码上的已知正负序列；序列已知，不等于当前位置已知 |
| 擦码 | 按已知的正负号乘回相关结果，消除该符号翻转；不是删除数据 |
| NCO | 数控振荡器；载波NCO生成本地载波，码NCO控制本地码推进 |
| FLL／PLL／DLL | 分别根据频差、相差、码差工作的频率环、相位环和码环 |
| C/N0 | 载噪密度比，单位dB-Hz；数值越大，信号相对噪声越强 |

公式中的频率用Hz，时间用s，码误差用chip。鉴相输出用cycle，1 cycle等于$2\pi$ rad。局部变量在对应计算步骤定义，参数表中的ms须换成s后代入频率与相位公式。

## 2 跟踪软件总体流程

### 2.1 三条并行工作线

一次跟踪不是“同步完成后才开始所有环路”。载波处理、码处理和同步处理共享PDI，但各自积累、各自判断结果是否可用。

![[90-附件/图STSW-21_软件并行处理总览_v01.svg]]

<p class="figure-caption" style="text-align: center;">图2-1 软件主数据流。实线表示数据或控制结果，虚线表示策略与开放条件；同步结果决定后续怎样擦码和积分，不阻塞所有同步前观察。</p>

| 工作线 | 任务 | 输出 |
|---|---|---|
| 载波 | 根据符号是否已知选择鉴频、鉴相，交给FLL／PLL | 连续载波频率控制 |
| 码环 | 从五抽头或BOC双副本形成码误差，交给DLL | 连续码率控制 |
| 同步 | 搜索数据边界或二次码位置，再用独立数据确认 | 候选、锁定边界和擦码符号 |

数据型信号先牵引频率，再开放同步；L5频段三种信号在温启动频差条件下保持移交频率并直接搜索二次码；BOC信号还要先通过粗码牵引和细码居中检查。具体顺序分别见第9、10、11章。

### 2.2 入口、同步进度和环路状态

以下三个概念彼此独立。

| 概念 | 取值举例 | 决定什么 |
|---|---|---|
| 捕获入口 | 强；中、弱 | 初始选择ShortFast或LongFast |
| 同步进度 | 搜索、候选确认、锁定 | 边界是否可信，哪些符号可以擦除 |
| 跟踪状态 | Fast、Normal、Slow及专用状态 | 积分配置、鉴别器、环路带宽和PLL许可 |

捕获强档选择强入口；捕获中、弱档选择中弱入口。跟踪期间不根据某一次C/N0重新解释捕获等级。同步成功也不直接跳入最慢状态：先切换观察方式，后续换档由第8章规定。

### 2.3 模块职责与结果有效性

| 模块 | 只负责 |
|---|---|
| 积分器、观察器 | 组织相关结果，计算本次测量 |
| 同步器 | 形成候选及确认后的边界 |
| 环路 | 保存并更新控制状态 |
| 监测器 | 汇总多次测量，判断稳定程度 |
| 状态机 | 选择处理策略，不计算鉴别误差 |
| 显示与日志 | 记录和显示，不反馈控制 |

每个观察都区分三种情况：未收满数据、已收满但无效、已收满且有效。接口分别用`ready`和`valid`表示；是否实际进入环路另行记录。没有新结果或结果无效时，不得生成一个“有效零误差”。

## 3 PDI输入与时间基准

### 3.1 输入与输出

通道初始化时保存载频、标称码率、主码周期、公开码表、分量相位和捕获移交结果。G1还保存FDMA频道。每条PDI保留全部有效相关支路，以及解释这些相关值所需的绝对历元、完整性和实际NCO参考。

| 信号类型 | 使用的相关结果 |
|---|---|
| 单分量数据型 | 数据VE、E、P、L、VL |
| 数据+导频 | 导频五抽头，数据Prompt |
| BOC | 导频BOC五抽头、导频PRN-only五抽头，数据BOC Prompt |

输入模块将硬件复整数直接转换为软件浮点复数，不除以样点数，不补偿前端增益，不改变各抽头比例。资源池0、2、3使用s18相关，资源池1使用s20相关。例如输入I=−1200、Q=350，转换后仍为$-1200+j350$。

![[90-附件/图STSW-01_硬件相关结果输入_v03.svg]]

<p class="figure-caption" style="text-align: center;">图3-1 输入转换、闭环分量选择与固定相位统一。选择默认五抽头不删除其他分量或副本。</p>

### 3.2 闭环分量与固定相位

| 信号 | 默认闭环分量 | 该分量固定相位／cycle |
|---|---|---:|
| L1CA、B1I、G1 | 数据 | 0 |
| L5 | L5Q | −0.25 |
| B2a | B2a-P | +0.25 |
| E5a | E5a-Q | +0.25 |
| E1 | E1C | +0.50 |
| B1C | B1C-P | +0.25 |

设表中的固定相位为$a$，原始相关为$P$，统一相位参考后的结果为：

$$
X=P\,e^{-j2\pi a}
$$

同一分量的五抽头使用相同旋转。L5Q取$a=-0.25$时，结果为$I'=-Q$、$Q'=I$。这是消除固定分量相位，不是载波频差补偿，也不是二次码擦除。

### 3.3 完整性与NCO参考

不足1 ms的首段、缺失或重复历元、溢出及命令确认异常，不进入正常积分。发生断点时丢弃未完成的跨历元统计，从新的合法边界开始；不把断点两侧数据拼成连续观察。

频率和相位观察必须保留数据首末历元、观察中心时刻及实际NCO参考。原因是环路在收数期间可能更新NCO，历史Prompt不一定来自同一个本地频率。

处理一个频率候选前，先补偿窗口内NCO变化，使历史数据处于同一参考。观察输出的是相对该参考的残差，而不是相对“最新命令”的残差。第7章再将它换算到当前控制边界。

主码周期号与主码内片段位置由移交时间基准和连续PDI推进。E1收齐同一主码的4条PDI，B1C收齐10条，才能发布完整主码；不完整前缀直接丢弃。

## 4 积分与符号处理

### 4.1 相干积分、功率累加与幅度累加

相干积分直接相加复数，保留相位；非相干累加先去掉相位，再相加非负量。两者不能交换顺序。

![[90-附件/图STSW-22_积分方式对比_v01.svg]]

<p class="figure-caption" style="text-align: center;">图4-1 相同的复相关输入可以组成不同观察。块间采用功率还是幅度，由后续鉴别器决定。</p>

设一个块内的相关依次为$P_1$至$P_N$，先得到复相干结果：

$$
Z=P_1+P_2+\cdots+P_N
$$

多个块的复相干结果分别为$Z_1$至$Z_K$，再按用途合并：

| 合并方式 | 运算 | 是否保留块间相位 |
|---|---|---|
| 连续相干 | $Z_1+\cdots+Z_K$ | 保留，块间符号与相位必须一致 |
| 功率累加 | $\lvert Z_1\rvert^2+\cdots+\lvert Z_K\rvert^2$ | 不保留 |
| 幅度累加 | $\lvert Z_1\rvert+\cdots+\lvert Z_K\rvert$ | 不保留 |

例如两个块为$Z$和$-Z$，复数相加得到0，功率相加仍为$2|Z|^2$。因此未知导航bit之间不能直接相干相加。延长相干时间可以提高积累能力，但也更怕符号翻转和未补偿频差。

码环幅度使用浮点模长$|z|=\sqrt{I^2+Q^2}$，实现采用`hypot(I,Q)`；功率使用$I^2+Q^2$。软件不对I/Q缩位、截断或采用整数幅度近似。幅度累加与功率累加仍是不同的观察方法，不能混用。

### 4.2 四个时间参数

后文统一分开列出四个量。

| 参数 | 含义 | 例子 |
|---|---|---|
| 单块相干时长 | 一次直接复数相加覆盖多久 | 20 ms |
| 块间合并方式与块数 | 每块结束后累加什么 | 8块功率相加 |
| 观察跨度 | 形成本次测量使用多少时间的数据 | 160 ms |
| 更新周期 | 隔多久产生一次新观察供环路使用 | 160 ms |

“20 ms相干、8块功率累加”和“连续160 ms相干”具有相同的观察跨度，但不是相同算法。载波与码环即使都每160 ms更新，也可以采用不同的相干长度。

相邻两个20 ms块鉴频需要40 ms数据，但块中心间隔为20 ms，之后每新增20 ms可产生一次结果。同步搜索的滑动窗口和监测历史也可能长于更新周期，必须明确标注；不将它们混称为环路积分时间。

### 4.3 公开符号擦除与未知数据符号

当前符号$c$已知且取值为±1时，擦码只需：

$$
X=cP
$$

擦除G1的meander或B1I的NH20后，导航bit仍未知，所以普通数据型信号的相干积分止于一个完整20 ms bit。导频没有导航bit，公开二次码正确擦除后可跨二次码周期继续相干。

不知道符号但只需测频时，可以对Prompt作复平方：

$$
X=P^2=(I^2-Q^2)+j\,2IQ
$$

正负符号平方后相同，但载波相位也加倍，鉴频尺度必须随之改变。$P^2$与功率$|P|^2=I^2+Q^2$不同：前者仍有相位，后者没有。

外部已知bit辅助还可以擦除导航bit，但必须逐PDI提供正确符号及有效时间映射。普通位同步只确定边界，不自动提供这种能力。

### 4.4 边界对齐与清窗

数据位边界必须换算成绝对历元的模位置。设搜索窗起点为$e$，候选偏移为$b$，20 ms块首位置为：

$$
B=(e+b)\bmod20
$$

例如$e=1001$、$b=7$，则$B=8$。合法块为1008～1027、1028～1047；1010～1029会跨真实边界，不能作为同一个bit积分。

导频的二次码位置用于查擦码符号，软件积分网格用于分块，两者不是同一个量。导频已擦码后不必等待二次码第0码片才开始积分；BOC码观察仍须等待完整主码。

边界改变、积分配置改变或PDI断点时，清除不兼容的未完成统计。触发切换的PDI不重复进入新窗口。清窗只影响软件统计，不跳变载波或码NCO相位。

## 5 鉴频、鉴相与码鉴别方法

### 5.1 怎样选择鉴别器

鉴频测量相位随时间的变化，鉴相测量当前相位，码鉴别测量相关峰相对本地码的位置。三种结果分别送往FLL、PLL和DLL。

| 方法 | 输入条件 | 主要用途 |
|---|---|---|
| 相邻Prompt的asin鉴频 | 相邻间隔短；符号翻转影响由观察平均处理 | L1CA、G1强入口 |
| 平方Prompt鉴频 | 正负符号未知；平方后按二倍角换算 | B1I与BOC同步前 |
| 功率DFT与插值 | 候选内可以形成有效相干块 | 频率搜索和同步后普通跟踪 |
| 相邻块atan2鉴频 | 两块的公开符号已擦除，残差在局部范围内 | 已同步导频ShortNormal／ShortSlow |
| 固定三频点FMS | 频率已进入专用局部支路工作区 | 极弱或辅助状态 |
| Costas／四象限鉴相 | 分别适用于未知数据正负／已擦码导频 | 形成相位观察 |

### 5.2 相邻相关鉴频

将前一条复相关记为$A$，后一条记为$B$，两条中心的时间差为$T$。先计算共轭积：

$$
U=A^*B
$$

星号表示复共轭。$U$的相角就是两个相关结果的相位变化；在当前约定下，正相位变化对应正频差。计算前先统一两条数据的NCO参考。例如10 Hz频差在1 ms内多转0.01周，即约0.0628 rad；鉴频就是从这段相位变化反推频差。

#### 5.2.1 asin鉴频

以幅度积$R=|A||B|$归一化共轭积的虚部：

$$
e_f=\frac{\arcsin\!\left(\operatorname{Im}U/R\right)}{2\pi T}
$$

反正弦输入限制在−1～1。$e_f$是频差，单位Hz。L1CA、G1强入口取$T=0.001$ s，每对先鉴频，再对20个间隔等权平均。符号翻转会改变该对结果，不把这种平均解释为逐对已经消除了未知bit。

本路径中$R=0$的一对角度贡献取0，但保留间隔计数；整窗仍须通过累计幅度和相应质量检查。空窗不能因此变成有效零频差。

#### 5.2.2 复平方后鉴频

B1I先将每条1 ms Prompt平方，再按5.2.1节逐对取角。因为相位变化加倍，频差改为：

$$
e_f=\frac{\phi}{4\pi T}
$$

$\phi$是平方后测得的角度。强入口平均20个间隔，中弱入口平均160个间隔；从空状态分别需要21、161条PDI，窗口之间保留末端Prompt。

BOC同步前也使用复平方，但先对相邻完整主码形成$U=(A^*B)^2$，再用atan2取角。强入口“先加复积、后取角”，中弱入口“逐间隔取角、后平均”；第11章给出五抽头合并及非重叠分组规则。

#### 5.2.3 擦码导频的atan2鉴频

二次码已擦除时，直接使用$U=A^*B$：

$$
e_f=\frac{\operatorname{atan2}(\operatorname{Im}U,\operatorname{Re}U)}{2\pi T}
$$

相邻20 ms块取$T=0.020$ s，无模糊半范围为25 Hz；不是用两块共40 ms作为分母。未擦码而直接使用本式，会把符号反号误当成载波旋转。

| 取角方式 | 数学无模糊半范围 |
|---|---|
| 不平方的asin | $1/(4T)$ |
| 平方后的asin | $1/(8T)$ |
| 平方后的atan2 | $1/(4T)$ |
| 不平方的atan2 | $1/(2T)$ |

实际移交范围与工作范围还受信号、噪声和质量检查约束，不能仅凭数学范围放宽捕获要求。

### 5.3 功率DFT与三点插值

DFT鉴频在若干候选频率中寻找“补偿后最能相干相加”的一个。这里计算少量指定频点，不等于对原始IQ重新捕获。

![[90-附件/图STSW-23_功率DFT方法_v01.svg]]

<p class="figure-caption" style="text-align: center;">图5-1 每个候选使用同一批Prompt；先旋转再相干，最后沿频率方向选峰。多个相干块之间可以累加功率。</p>

#### 5.3.1 一个候选怎样得到功率

固定候选频率$f$，对每条已统一NCO参考的Prompt执行：

$$
X=P\,e^{-j2\pi ft}
$$

$t$为当前相干块内时间。将一个块的$X$相加得到$Z$，块结束后取$|Z|^2$。若本次观察包含多个块，再把各块功率相加，得到该候选的评分$J$。

连续160 ms相干只形成一个160 ms的$Z$；20 ms×8功率积累形成8个$Z$，最后相加8项功率。只有后一种允许各块采用独立相位零点。

实现保存逐1 ms数据，在窗口成熟时计算候选。不能先把未作候选补偿的全部Prompt压缩成一个复数，再尝试恢复多个频率结果。

#### 5.3.2 寻峰与细化

选出最大功率频点$f_p$。若它有左右邻点，将左、峰、右功率记为$a,b,c$，频点间隔为$h$：

$$
\delta=\frac{a-c}{2(a-2b+c)}
$$

$$
e_f=f_p+h\delta
$$

$\delta$是相对峰点的分数频点偏移。例如$f_p=25$ Hz、$h=12.5$ Hz、$\delta=0.2$，细化结果为27.5 Hz。分母退化时只保留粗频点。

边缘处理与输出范围依应用配置，不混为一种规则：

| 路径 | 频点间隔 | 插值与边缘处理 |
|---|---|---|
| L1CA／G1同步前牵引，以及数据位同步搜索 | 12.5 Hz | $\delta$限±0.5；边缘不插值，保留边缘候选 |
| 数据型信号普通同步后跟踪 | 10 Hz | 使用芯片三点计算尺度；边缘向内半点，最终控制鉴频量限±25 Hz |
| 已擦码导频普通跟踪 | 10、3.125或1.5625 Hz | 按实际网格插值；边缘向内半点，不外插 |

因此11点×10 Hz表示实际搜索±50 Hz，不保证控制输出也覆盖±50 Hz。数据型20 ms路径的芯片尺度恰为10 Hz，但最终仍有±25 Hz限幅。导频160 ms网格边缘为±15.625 Hz，向内半点的粗估为±14.0625 Hz。

功率必须为有限有效数据。当前普通跟踪DFT不额外设置高于1的峰值比或正的归一化功率门限，保留非空功率等数值检查。它与同步器的1.18边界区分度检查用途不同，不套用同一个“峰值比”。普通DFT寻峰后不再串联FMS。

### 5.4 固定三频点FMS

FMS使用中心和左右两个固定频点。两侧功率分别为$J_+$、$J_-$，先计算归一化差：

$$
d=\frac{J_+-J_-}{J_++J_-}
$$

正侧功率较大时输出正方向校频，负侧较大时反之。它在当前中心附近提供局部控制量，不重新寻找11点全局峰。

当前固定±5 Hz数据支路中，20 ms相干采用$e_f=46.72d$，120 ms已知bit相干采用$e_f=11.68d$。这些是芯片控制增益，不能把未标定的控制量直接用于物理频率变化率测量。空功率和零分母无效。

已擦码导频使用与相干时长匹配的专用换算；是否具有物理频率意义由观察标志给出。FMS不是每个信号牵引必须经过的一步，专用状态边界见8.5节。

当两侧频率为相干时长倒数的一半，即$h=1/(2T)$时，导频使用解析换算：

$$
e_f=\frac{d}{2T\left(1+\sqrt{\max(0,1-d^2)}\right)}
$$

$T$为单次连续相干时长，单位s。导频Sensitivity取$T=0.320$，两侧为±1.5625 Hz；它与数据Sensitivity的20 ms、固定±5 Hz和46.72倍控制增益不同，不能互换。

### 5.5 鉴相：一个块的相位

输入为一个有效相干Prompt $I+jQ$，输出相位误差$\phi$，单位cycle。

| 输入符号条件 | 方法 | 相位周期 |
|---|---|---|
| 导航bit正负未知 | Costas：$\phi=\operatorname{atan}(Q/I)/(2\pi)$ | 半周，输出回绕到−0.25～+0.25 |
| 导频二次码已擦除 | 四象限：$\phi=\operatorname{atan2}(Q,I)/(2\pi)$ | 一周，输出回绕到−0.5～+0.5 |

数据bit取反使I、Q一起反号，$Q/I$不变，所以Costas不把bit翻转当成载波相位变化。零幅度、非有限结果或Costas的I接近零时不发布有效鉴相。

能计算相位不等于允许PLL控制。第7章集中规定PLL开放条件，所有中弱状态禁止把相位误差注入载波NCO。

### 5.6 普通五抽头码鉴别

码鉴别先得到各抽头的功率或幅度量，再比较峰的左右两侧。设E/L单边间距为$d$，五抽头位置为$-2d,-d,0,d,2d$。

#### 5.6.1 牵引阶段的局部中心

| 模式 | 最大抽头 | 选择中心 | 中心位置$x$ | 左右邻点 |
|---|---|---|---:|---|
| 强入口 | VE或E | E | $-d$ | VE、P |
| 强入口 | P | P | 0 | E、L |
| 强入口 | L或VL | L | $+d$ | P、VL |
| 中弱入口 | 不按噪声峰移动中心 | P | 0 | E、L |

设中心左右观测量为$a,b$，码误差为：

$$
e_c=x+(1-d)\frac{b-a}{a+b}
$$

$e_c$单位chip。分母为0时无效；中心为P时限幅到±0.25 chip。右侧更高对应正误差，DLL提高本地码率；左侧更高则降低码率。

强入口逐1 ms鉴别，再按固定20 ms分母平均；至少一次有效鉴别才发布有效结果。中弱入口先累加相关度量，再鉴别一次。前者不能替换成“先累加功率再鉴别”。

#### 5.6.2 浮点计算顺序

牵引1 ms功率路径直接计算每个抽头的$I^2+Q^2$。5／10／20 ms幅度路径先完成复相干积分，再计算各抽头模长，最后跨块累加。所有中间量和码误差均为浮点数，不再经过整数缩放或Q11量化。

强入口将20次逐1 ms码误差相加，再除以20；无效样本贡献零，整窗至少一次有效才发布。中弱入口先积累五抽头度量，再执行一次码鉴别。鉴别时允许将五路度量同时除以最大值，防止大数相加溢出；公共归一化不改变码误差。非有限、负度量或空分母不形成有效观察。

#### 5.6.3 同步后的标准与双差鉴别

普通码观察先按状态积累各抽头幅度，再选择标准E−L或双差。令E、L幅度为$a,b$，VE、VL幅度为$u,v$；Prompt中心的双差为：

$$
e_c=(1-d)\frac{2(b-a)-(v-u)}{a+b}
$$

它在标准左右差之外加入外抽头补偿。分母有效性和Prompt中心±0.25 chip限幅规则与标准方法一致；中心不在P时退回标准局部鉴别。

ShortSlow、LongSlow、Sensitivity、OutdoorBitAiding在环路质量量有效且>13.5 dB-Hz时选择双差，其余使用标准E−L。BOC不走此分支，而使用5.7节双副本方法。信号章节中的“码观察组成”只描述积分方式，不能替代这里的鉴别器选择。

### 5.7 BOC双副本细码鉴别

BOC相关峰存在多个局部峰。完整BOC副本保留副载波，PRN-only副本只使用主码，两者组合用于抑制不希望跟随的峰。

对每个完整主码，两个副本分别计算：

$$
D=\operatorname{Re}[(E-L)P^*]
$$

将BOC结果记为$D_b$，PRN-only结果记为$D_r$，BOC Prompt功率记为$H$。跨主码分别累加这三个量，再计算一次码误差：

$$
e_c=-\frac{D_b-2D_r}{7H}
$$

当前固定E/L为±0.25 chip，完整间距0.50 chip，系数2，归一化分母系数为$6+2\times0.50=7$。负号将抽头方向转换为软件DLL方向，后级不再翻转。$H$须通过正功率检查，各量须有限。

同一主码内E、L、P带有共同二次码符号，点积会消除该正负号，所以细码观察不必等待二次码锁定。粗码方向判决和有限调码属于BOC专用流程，在11.3节说明，不将粗方向直接送入DLL。

## 6 位同步与二次码同步方法

### 6.1 同步究竟寻找什么

| 对象 | 已知内容 | 未知内容 | 锁定后获得什么 |
|---|---|---|---|
| 数据位同步 | 位长，及位内公开符号结构 | 哪一毫秒是位首 | 一个完整数据位的起止 |
| 导频二次码同步 | 二次码完整序列 | 当前对应序列哪个位置 | 每条PDI应擦除的符号 |

两者都不直接给出导航电文内容。软件用“候选边界正确时，擦码后的数据更容易相干积累”来评分，再以独立数据确认。本文的ML（最大似然）同步具体采用6.2节的相干功率评分。

<p class="figure-caption" style="text-align: center;">图6-1 共用搜索与确认流程。候选通过不等于锁定；确认必须重新比较所有位置，并使用搜索结束后的新数据。</p>

### 6.2 给一个候选评分

固定一个候选，依次执行四步：

1. 根据该候选决定当前公开符号$c$，取值±1。
2. 将Prompt乘$c$；需要频率候选的路径再作候选频率旋转。
3. 在规定短块内复相干，得到$Z$。
4. 块末取$|Z|^2$并加入评分$J$；清空$Z$，继续下一块。

不同候选独立评分。每个候选的公开码位置须贯穿整个窗口，不允许每块自由选择最有利的正负号。不同短块只累加功率，不把整个搜索窗直接连续相干。

数据型搜索同时枚举频率和20 ms边界；导频二次码搜索只枚举码位置。这是候选维度的区别，不是两套完全无关的同步思想。

### 6.3 边界和二次码位置的表示

数据位候选$b$表示相对于搜索窗首条PDI的偏移。每20条构成一个候选bit，L1CA直接累加，G1擦除meander，B1I擦除NH20。为使20个边界候选拥有相同数量的完整bit，每个统计窗口额外保存19条PDI。

导频候选$b$表示“二次码第0码片对应的绝对主码周期模位置”。当前主码周期号为$p$，二次码长为$N$，查表位置为：

$$
i=(p-b)\bmod N
$$

取模结果归一到0～N−1。例如$b=7$、$p=9$，使用第2个码片。换搜索窗或进入确认时，绝对周期的含义不变，才能比较两窗候选是否一致。

### 6.4 选峰与质量检查

同步的峰值比统一使用1.18，但分母的定义必须说明。

| 同步路径 | 主评分 | 用来比较的评分 |
|---|---|---|
| 数据型 | 获胜频率、边界的评分 | 同一频率下，与该边界相差10 ms的评分 |
| 导频二次码 | 获胜位置的评分 | 其余全部位置中的最大评分 |

二者都要求主评分及相关分母有效，主评分至少为比较评分的1.18倍。比值是候选区分度，不是正确锁定概率。

#### 6.4.1 数据型的局部峰形与质量积

L1CA和G1还检查边界峰的两侧：距峰2 ms的评分须小于同侧距峰1 ms的评分。两侧均满足才通过，用于排除不像边界峰的局部高点；B1I的NH结构不同，不使用该峰形判据。比较始终固定在获胜频率上，边界按20 ms循环。

数据型三种信号还使用同一质量积。设$M$为完整bit相干功率和，$W$为这些bit包含的全部1 ms Prompt功率和，统计时长为$\tau$秒：

$$
C_0=1000\frac{M-W}{20W-M}
$$

$$
Q=C_0\frac{\tau}{0.5},\qquad Q\ge370
$$

$C_0$是线性C/N0，不是dB-Hz。边界余量中没有用于完整bit的数据不计入$W$。$M-W\le0$时无效；信号功率为正而噪声分母非正时，按无噪声极限处理。

### 6.5 独立确认与失败重试

| 本次结果 | 后续处理 |
|---|---|
| 搜索未通过 | 按该信号规定增加新数据，再搜索 |
| 搜索通过 | 保存候选，清除搜索数据，进入确认 |
| 确认通过且候选一致 | 宣布锁定 |
| 确认通过但候选改变 | 保存新候选，再用新数据确认 |
| 确认无效 | 按该信号规则延长确认或回到搜索 |

确认重新比较全部边界或位置，不只检查旧候选自己的功率。数据型确认只保留0 Hz候选；导频搜索和确认本来就没有附加频率候选。独立确认不复用搜索数据。

数据型首次搜索成功还执行一次校频；导频候选不产生校频。搜索窗长度、失败后是否滑动以及环路在等待期间的行为，统一在第9～11章列出。

### 6.6 二次码评分的两种计算实现

E1使用64点零填充FFT实现25位置循环相关；FFT只加速二次码位置评分，不搜索新的主码码相位或载波频率。

B1C一个20 ms段恰好包含两个10 ms主码，记为$A,B$。先计算：

$$
W_+=|A+B|^2,\qquad W_-=|A-B|^2
$$

候选码表中两个符号相同就累加$W_+$，相反就累加$W_-$。两个符号同时反号不改变功率，因此这两个值足以覆盖全部候选。每段只算一次，再由1800个候选查表使用；不能每段随意选较大值，也不能删除共同功率底项，否则会改变峰值比。B1C这一路不使用FFT。

## 7 载波环与码环控制

### 7.1 测量和控制分开

观察器给出的频差、相差和码差含有噪声，环路不会每次直接将测量值覆盖到NCO，而是按当前带宽逐步修正。宽带宽响应快、噪声较大；窄带宽更平稳，但需要先完成收敛。

![[90-附件/图STSW-25_公共环路控制_v01.svg]]

<p class="figure-caption" style="text-align: center;">图7-1 FLL维护基频预测，PLL有效时优先校正；同一历元不重复反馈FLL。码环叠加载波辅助，监测器不直接生成控制修正。</p>

### 7.2 将频差换算到当前控制时刻

设观察自身的NCO参考为$f_r$，测得残差为$e_f$，则观察对应的信号频率为：

$$
f_s=f_r+e_f
$$

再减去当前NCO频率，才能得到本次控制需要的残差。如果观察中心到控制边界之间存在已被独立监测认可的频率变化率，还要按实际时间差推进。参考换算不是额外的信号搜索。

没有可信变化率时保持现有频率，不从牵引噪声建立逐毫秒外推。PDI时间轴中断后重新锚定时间，不跨缺口传播旧趋势。

### 7.3 FLL：频率与趋势递推

FLL保存两个量：当前频率修正$f$，以及一个更新周期内的趋势步进$d$。更新周期为$T$秒时，物理变化率为$d/T$，单位Hz/s。

在允许预测的连续时间内，经过$\Delta t$秒，先推进频率：

$$
f\leftarrow f+\frac{d}{T}\Delta t
$$

收到新的有效频差后，记旧趋势为$d_o$，先更新趋势，再更新频率：

$$
d\leftarrow d_r+\lambda(d_o-d_r)+K_2e_t
$$

$$
f\leftarrow f+(d-d_o)+K_1e_f
$$

$d_r$是本状态允许继承的参考趋势，$\lambda$为旧趋势保留比例。$e_t$是允许进入趋势积分的频差，$e_f$仍为完整控制频差。没有趋势更新资格时保留$d$，只执行有效比例校频；已经执行的时间预测不再重复相加。

普通状态取$\lambda=1$、$e_t=e_f$。LongSlow取$\lambda=0.999$并将$e_t$限±0.1 Hz；Sensitivity取0.999并将$e_t$限±0.5 Hz。这些限制只作用于高阶噪声积累，不限制比例支路或真实物理Hz/s范围。固定FMS能否更新趋势须在状态交接时明确授权。

$K_1,K_2$使用当前策略的离散增益，已包含更新周期的影响。未配置显式增益时，才按带宽$B$计算：令$w=B/0.53$，取$K_1=1.414wT$、$K_2=(wT)^2$。正式策略使用芯片系数还原的增益，不能只凭表中的带宽重新算一组系数替换。

### 7.4 PLL：相位修正与开放条件

PLL使用第5章的相位观察，独立于FLL保存积分状态。设相位误差为$\phi$ cycle，PLL带宽为$B$，$w=B/0.7845$，更新周期为$T$：

$$
r\leftarrow r+T w^3\phi
$$

$$
i\leftarrow i+T(r+1.1w^2\phi)
$$

$$
p=i+2.4w\phi
$$

$r$是PLL变化率积分，$i$是频率积分，$p$是PLL频率修正。相对于捕获移交多普勒的总载波修正为$f+p$；FLL、PLL不共用积分器。

每次载波校正只选择一路反馈：PLL观察有效且状态允许时，使用PLL更新$p$，不再用该次频差同时更新FLL；否则由FLL处理有效频差。FLL仍维护前级基频预测，频率观察仍送入监测。软件记录的FLL、PLL使用标志分别表示实际采用的校正支路，不表示观察是否存在。

计算示例：$B=2.4$ Hz、$T=0.020$ s、$\phi=0.01$ cycle，初始$r=i=0$。按先更新$r$、再更新$i$的顺序，本次得到$r\approx0.00573$ Hz/s、$i\approx0.00217$ Hz、$p\approx0.0756$ Hz。相位已经以cycle表示，递推中不再乘额外的$2\pi$。

普通状态只有ShortSlow允许PLL，并须同时满足下列条件。

| 条件 | 要求 | 用途 |
|---|---|---|
| 同步 | 已独立确认锁定 | 保证符号处理正确 |
| 当前策略C/N0 | 有效且≥30 dB-Hz，当前实现的ready确认计数达到3；计数节拍见8.2.3节 | 避免在弱信号下直接使用相位噪声 |
| 最近频率观察 | 有效 | 保留频率观察有效性要求，不按单次频差幅值拒绝PLL |
| 频率监测 | 有效；ShortSlow的频率抖动RMS≤4 Hz | 确认载波已经稳定 |
| 相位观察与监测 | 本次有效，监测已成熟，有效率≥0.8 | 避免用少数偶然有效的相位驱动PLL |

PLL使用观察器输出的原始相位误差，不增加最近频差乘观察延迟的相位外推项；数据按半周、导频按一周周期回绕。PLL是否更新由表中的状态、同步和质量条件决定，不另设单次频差幅值门限。45°相位RMS只用于诊断，不作为首次PLL开放条件。频率观察的中心时刻补偿保持不变。

相位观察已成熟但未通过有效性检查、同时FLL有有效观察时，将当前控制频率转入FLL基频并清空PLL积分；相位观察尚未成熟时不执行该交接。

| 策略C/N0／dB-Hz | PLL带宽／Hz |
|---|---:|
| <36 | 2.4 |
| 36～<38 | 4.8 |
| 38～<42 | 7.2 |
| ≥42 | 9.6 |

仅调整PLL带宽、而FLL配置、模式和更新周期不变且允许保留趋势时，不清空已有积分。设新旧带宽比为$q$，切换前的PLL即时修正为$p$、积分为$i$，按下式映射积分，其余变化率和基频保持：

$$
i\leftarrow p-q(p-i)
$$

这里$p-i$是旧比例项。映射后比例项随带宽缩放，积分补偿其差额，使切换瞬间总修正$p$连续。例如$p=0.4$ Hz、$i=0.1$ Hz、带宽扩大两倍，映射后$i=-0.2$ Hz，新比例项为0.6 Hz，总修正仍为0.4 Hz。其他不兼容配置切换仍按7.6节重建状态。

相位未成熟时保持原控制状态；相位已成熟但明确无效、且本次有有效FLL观察时，将当前PLL修正吸收到FLL基值，再清PLL积分，避免控制频率突变。所有普通Long状态和专用弱状态均不注入相位误差。

### 7.5 DLL：剩余码率与载波辅助

DLL处理局部细码误差，不接收BOC粗方向。令积分状态为$i$，新有效码误差为$e_c$，剩余码率修正为$u$：

$$
i\leftarrow\lambda i+K_i e_c
$$

$$
u=i+K_p e_c
$$

$i,u$的单位为chip/s；$K_i,K_p$为当前更新周期对应的离散增益。普通状态$\lambda=1$，Sensitivity取0.95。没有新有效细码误差时，保持积分和剩余码率，不对旧积分执行额外衰减。

设标称码率为$R_0$、射频载频为$F_0$、载波环给出的物理多普勒为$f_d$，码NCO命令为：

$$
R=R_0+\frac{R_0}{F_0}f_d+u
$$

第二项是载波辅助，第三项是DLL残余修正。即使本次没有码观察，载波辅助仍可随$f_d$更新。G1的$F_0$取当前FDMA频道载频。BOC有限调码期间还临时叠加11.3节的码率偏置。

DLL实际更新周期不超过600 ms。长统计窗不等于长控制周期；例如专用弱信号码观察可使用更长历史，但仍按其独立更新节拍发布。

### 7.6 换档与异常处理

状态切换先选择目标策略、发出目标边界命令，后续PDI确认命令实际生效后才提交新状态。软件写出命令，不等于硬件已经切换；寄存器与边界执行细节由硬件方案规定。

| 事件 | 保留内容 | 清除或重建内容 |
|---|---|---|
| 正常积分配置切换 | 连续NCO相位；兼容且已确认的同步边界 | 不兼容的积分、鉴别和监测窗口 |
| 同周期仅调整PLL带宽 | FLL基频及变化率、PLL即时修正及变化率 | 按比例项变化映射PLL积分，不清空 |
| 其他载波参数切换 | 当前总控制频率；仅允许继承的可信变化率 | PLL积分与不兼容趋势 |
| DLL参数切换 | 按状态边的规则处理码率与积分，不重装码相位 | 需要重置的剩余码率积分 |
| 无新观察／观察无效 | 当前控制及已获准的预测 | 不生成有效零误差 |
| PDI缺口、重复或溢出 | 不由清窗直接跳变NCO | 跨断点积分与时间资格，重新锚定时间 |
| 命令迟到或编号不符 | 不提前宣布目标状态生效 | 取消待提交状态，进入相应恢复 |
| 同步候选失败 | 按入口保持已有牵引 | 候选及对应未完成同步统计 |

普通同步失败和通道时间轴故障不是同一种事件：LongFast同步重试保持LongFast；全局PDI或命令故障另走安全恢复。局部恢复不等于已实现任意范围重捕获，当前五抽头不能承担通用大范围码搜索。

### 7.7 正式离散增益与单位换算

#### 7.7.1 物理增益

FLL输入频差为Hz，输出频率修正为Hz，$K_1,K_2$均为无量纲。DLL输入码差为chip，输出码率修正为chip/s，$K_p,K_i$的单位均为s⁻¹。正式策略直接保存这些物理增益的双精度浮点值，不在运行时换算芯片整数系数、右移位数或Q格式。

增益已经包含对应的更新周期，递推时不再重复乘20／160／320 ms。改变积分长度或更新周期时，应整体核对对应状态的增益，不将同一组数值任意套到其他节拍。

#### 7.7.3 控制量到硬件字

载波命令由物理多普勒$f_d$换算为32 bit相位步进：

$$

$$

$f_s$是当前采样率，舍入采用最近整数，恰在半整数时远离零。负多普勒按模$2^{32}$表示。码率则使用硬件码NCO格式模块换算，不能照搬上述载波公式；定点格式、抽头字和生效边界沿用硬件设计方案。整个转换只改步进，不重装正在运行的载波或码相位。

### 8.1 载噪比估计与结果选择

#### 8.1.1 三条路径与共同输入

C/N0估计接收默认闭环分量的1 ms Prompt。已有可用边界时，先按该边界擦除公开符号；未知导航bit不跨位相加。载噪比只描述信号质量，不能代替同步判决或码居中判决。

<p class="figure-caption" style="text-align: center;">图8-1 同一批相关结果形成不同用途的质量量；显示结果不反馈控制。</p>

| 路径 | 计算对象 | 输出用途 |
|---|---|---|
| M2M4／浮点NWPR | 单条Prompt功率，或完整20 ms块的窄宽功率 | 物理诊断；正式环路质量尚不可用时的结果来源 |
| 环路质量 | 每个20 ms块先求窄宽功率比，再作浮点平均和对数换算 | 状态选择、PLL参数和普通码鉴别策略 |

“窄带功率”指先加复数再取功率；“宽带功率”指每条先取功率再相加。两者取自同一批样本。下文的C/N0均以1 ms输入为基准，换算为dB-Hz时加30 dB。

#### 8.1.2 M2M4：未对齐时也可工作的物理诊断

每条Prompt取功率$p=|P|^2$，保存最近200项；首次收满200 ms后，每20 ms更新一次。设这些功率的平均值为$M_2$，功率平方的平均值为$M_4$：

$$
S=\sqrt{2M_2^2-M_4},\qquad N=M_2-S
$$

$S,N$分别是信号和噪声功率估计。根号内数值、噪声功率必须为有限正数，否则本窗无效，不添加下限。

$$
C=10\log_{10}(S/N)+30
$$

$C$为dB-Hz。首个有效值直接初始化；之后在dB域按“旧值×0.9＋新值×0.1”平滑。无效估计不推进平滑，PDI缺口或非有限输入清除功率历史和平滑状态。

#### 8.1.3 浮点NWPR：先汇总功率，再求比

数据边界可用后，从合法20 ms块首收数。数据型在候选确认阶段即可按候选边界统计；导频须有可用擦码输入。每块同时保存：复数和的功率$a$，以及块内20条1 ms功率之和$b$。

保留最近50个完整块，即1 s；每新增一个20 ms块重算。将50个$a$相加得到$A$，50个$b$相加得到$B$：

$$
\gamma=\frac{A-B}{20B-A},\qquad C=10\log_{10}\gamma+30
$$

$\gamma$为1 ms参考的线性信噪比。分子、分母必须为有限正数。有效结果在dB域按“旧值×0.8＋新值×0.2”平滑；断点、边界改变或边界不可用时清窗并重新对齐。

这条诊断内部先用M2M4，NWPR首次有效后改用NWPR；NWPR单窗无效不在两种方法间反复跳转。其结果选择与8.1.6节的跟踪引擎最终选择是两个层次。

#### 8.1.4 环路质量：先逐块求比，再平均

每个完整20 ms块先计算自己的窄／宽功率比$r=a/b$，再对窗口内的$r$作浮点平均，得到$\bar r$。不能先将所有$a,b$分别相加后再求比；两种方法对强弱不同的块赋予了不同权重。

$$
\gamma=\frac{\bar r-1}{20-\bar r},\qquad C=10\log_{10}\gamma+30
$$

$\gamma$是1 ms参考的线性信噪比，$C$单位dB-Hz。功率比、平均、SNR及对数计算均采用浮点，不进行Q10／Q11截断，也不按0.1 dB-Hz量化。

| 数值情况 | 环路质量输出 | 解释 |
|---|---|---|
| 块内功率非有限、窄功率为负或宽功率非正 | 该块比值记为0 | 沿用异常块统计规则 |
| $\bar r<1$ | 有效10 dB-Hz，线性SNR=0.01 | 异常哨兵，不是物理测量 |
| $\bar r\ge20$或非有限 | 无效 | 无法形成有限正噪声估计 |
| $\bar r=1$或正常换算结果低于8 dB-Hz | 有效8 dB-Hz，并相应改写线性SNR | 环路质量下限 |

8 dB-Hz下限及10 dB-Hz异常哨兵属于环路质量规则，与浮点数值格式无关。该质量量不能用于验证8 dB-Hz以下的物理测量精度。

统计节拍与选择规则如下。

| 时刻／条件 | 处理 |
|---|---|
| 首次收齐10个20 ms块 | 发布一次200 ms启动结果，不重置1 s计数 |
| 首次1 s及以后每1 s | 同时计算最近200 ms、1 s和最多5 s结果 |
| 尚未积满5 s | 长窗使用已有完整块逐步增长，不等待5 s才首报 |
| 当前使用长窗，1 s结果≥22 dB-Hz | 改选1 s结果 |
| 当前使用短窗，1 s结果≤18 dB-Hz | 改选长窗结果 |
| 1 s结果在18～22 dB-Hz之间 | 保持上一次长／短选择 |
| 使用长窗，长窗≥20 dB-Hz且比1 s结果高至少4 dB | 输出两者dB值的平均，减轻信号下降时的滞后 |

初始化选择长窗。200 ms只用于启动和诊断，不是另外一档持续控制模式。长窗可以重叠，正常更新仍为1 s，不是每20 ms重新计算一次5 s质量量。

#### 8.1.5 只读显示的统计方法

显示使用完整10 s数据，每1 s形成新结果。除B1C外，最近最多15个有效报告取中值；首次10 s报告即可显示，不额外等满15个。重复历元、无效或未成熟报告不进入中值历史，时间轴或统计方法失效时按事件清除显示缓存。

| 信号与入口 | 显示基础块 | 10 s计算方法 |
|---|---|---|
| 数据型自主入口 | 20 ms | E/P/L窄宽功率分离，再拟合三抽头峰值 |
| 数据型显式辅助入口 | 100 ms，逐PDI擦外部bit | 同上；辅助无效立即清显示窗 |
| L5/B2a/E5a/E1普通状态 | 100 ms已擦码Prompt | 汇总窄宽功率后求比 |
| L5/B2a/E5a/E1的Sensitivity | 连续10 s相位补偿 | 搜索局部相位模型，按E/L幅度恢复峰值功率 |
| B1C | 100 ms已擦码Prompt | 独立1／5／10 s物理统计；10 s值直接显示，不加15点中值 |

数据型显示的100 ms选择由显式辅助入口配置决定，不是自动进入BitAiding后就必然更改显示路径。

对于一个含$M$条PDI的相干块，汇总若干块的窄、宽功率为$A,B$，先分离：

$$
S=\frac{A-B}{M(M-1)},\qquad N=\frac{MB-A}{M(M-1)}
$$

数据型分别对E/P/L计算。在±0.5 chip、0.001 chip步长的网格上，用三角相关峰的平方拟合三抽头信号功率，选残差最小的非负峰值；用该峰值除以三抽头平均噪声，再换算C/N0。分离出的单个抽头信号功率可为负，不先截零；最终峰值和平均噪声须为有限正数。这里估计的是显示峰值，不把拟合码位置交给DLL。

B1C每100条连续、已擦码PDI形成一个原子。首次锁定PDI不计入，等待下一个完整10 ms主码首段；取最近10／50／100个原子，每秒形成1／5／10 s结果。上述分离式再除以原子数即可得到单PDI平均信号与噪声功率，二者比值不变。原子内部不重叠，5／10 s尾窗每秒更新、彼此重叠；非物理解保持无效，不设置8／10 dB下限。

Sensitivity的10 s导频显示使用8.5.3节同类相位拟合，但粗网格为41个频率×31个变化率，步长0.1 Hz和0.02 Hz/s；再作11×11局部细化。固定模型后对E/P/L相干并除以PDI数，设平均复相关为$E,P,L$、信号目录给出的单边幅度增益为$g$：

$$
S=\left(\frac{|E|+|L|}{2g}\right)^2,\qquad N=\operatorname{mean}(|P_{1\mathrm{ms}}|^2)-|P|^2
$$

该补偿使用实际抽头配置和信号目录增益，结果只显示。它不改变导频码环、载波频点或同步状态，B1C不经过该10 s相位拟合显示路径。

#### 8.1.6 引擎中的结果选择与新鲜度

| 使用者 | 选择顺序 | 失效处理 |
|---|---|---|
| 当前对外C/N0与PLL参数缓存 | 最终同步已锁定且最近环路质量有效、年龄≤1000 ms时用环路质量；否则用有效M2M4 | 两者均不可用则本次无选中值；参数缓存过期后清除 |
| FSM的C/N0证据 | 优先使用年龄≤1000 ms的环路质量；无此结果时，可用当前已锁定同步结果携带的正线性C/N0 | 未满足来源条件则无效，不读取显示结果 |
| 普通码鉴别的标准／双差选择 | 使用本次环路质量，缺失时使用最近缓存 | 当前实现不在这一选择点单独检查1000 ms年龄；不得据此宣称所有消费者完全相同 |
| 用户显示 | 仅使用8.1.5节的显示结果 | 显示无效不等于闭环失锁 |

结果是否为“新窗口”以末历元是否推进判断，不只看非零数值。当前引擎转发最近环路质量时保留其`ready`，因此下游的“3次ready计数”不天然等价于三个独立1 s窗口；PLL当前计数行为见8.2.3节。

数据+导频移交灵敏度采用复合总C/N0，单导频比总值低约3 dB。上述估计直接使用所选分量的相关，不自动给导频加3 dB；不能把两种口径混入同一门限解释。

### 8.2 稳定性监测

监测器用一段历史判断稳定程度，控制器仍使用本次有效误差；不能把“等监测成熟”理解为环路停止更新。

<p class="figure-caption" style="text-align: center;">图8-2 一次观察分别用于当前控制和历史监测；两者不相互替代。</p>

#### 8.2.1 频率批次与变化率拟合

每到一个载波观察发布点，批次计数加1。观察成熟但无效时只计入时间，不填入零频差；有效且具有物理频率含义时才保存残差、参考时刻及“观察NCO＋物理残差”。按当前控制NCO统一残差参考，拟合仍使用原始观察中心的绝对频率，不混入控制重定时后的预测量。

| 状态 | 观察间隔 | 独立批次跨度 | 批次观察数 | 去均值RMS上限 |
|---|---:|---:|---:|---:|
| ShortFast／ShortNormal／ShortSlow | 20 ms | 400 ms | 20 | 4 Hz |
| LongFast | 160 ms | 480 ms | 3 | 2 Hz |
| LongNormal | 160 ms | 2560 ms | 16 | 1.5 Hz |
| LongSlow | 320 ms | 1280 ms | 4 | 1 Hz |
| Sensitivity | 320 ms | 1280 ms | 4 | 0.6 Hz |
| BitAiding | 600 ms | 1800 ms | 3 | 0.3 Hz |
| OutdoorBitAiding | 300 ms | 900 ms | 3 | 1 Hz |
| MidDynamic／HighDynamic | 320 ms | 960 ms | 3 | 4 Hz |

设批次共有$n$个成熟观察，其中$k$个物理有效。有效率为$k/n$，须≥0.4且至少有一个有效观察。对这$k$个残差求均值$m$，再计算：

$$
R=\sqrt{\operatorname{mean}[(e_f-m)^2]}
$$

$R$不超过表中上限时，批次稳定。这个RMS描述围绕均值的抖动，不包含均值偏差。例如所有频差均为2 Hz，均值为2 Hz，而本项RMS为0。

变化率拟合需要至少3个有效、不同时间的频率点。先将时间和频率分别减去自身均值，得到$t_i,f_i$，再计算：

$$
r=\frac{\sum t_i f_i}{\sum t_i^2}
$$

用拟合残差$v_i=f_i-rt_i$估计变化率标准差：

$$
\sigma=\sqrt{\frac{\sum v_i^2}{(k-2)\sum t_i^2}}
$$

$r,\sigma$均为Hz/s。时间能量接近0或结果非有限时，变化率无效；不能把返回数值0当成已证明静止。批次发布后清空样本，下一批独立积累；PDI故障或成熟观察节拍中断时清除旧批次及结论。

#### 8.2.2 DLL的连续历史

DLL保留覆盖至少400 ms的最短连续有效观察后缀。20 ms观察需20次，160 ms观察需3次共480 ms，320 ms观察需2次共640 ms；单个600 ms观察本身即可满足跨度。

用各观察声明的时长作权重，计算码误差均值和对零的RMS：

$$
m=\frac{\sum T_i e_i}{\sum T_i},\qquad R=\sqrt{\frac{\sum T_i e_i^2}{\sum T_i}}
$$

这里$e_i$为chip，$T_i$为观察时长。RMS包含偏差；若每次码差都为0.1 chip，则均值与RMS均为0.1 chip。成熟但无效的细码观察或时间轴故障立即清历史，未成熟观察只等待。

监测有效仅表示连续数据跨度足够，具体码居中限制由使用者检查。BOC首次居中使用均值绝对值和RMS均≤0.10 chip。对600 ms历史、320 ms更新等重叠观察，监测权重沿用声明时长，不能将其解释为相互独立的噪声样本数。

#### 8.2.3 相位监测与PLL确认计数

只有允许相位控制的ShortSlow运行相位监测；其他状态清除相位监测和PLL载噪比计数。监测保存最近5个20 ms相位槽，共100 ms；无效相位占槽，但不以0进入RMS。

有效相位比例≥0.8且对零RMS≤0.125 cycle，即45°时，发布相位收敛诊断。PLL首次开放只使用监测已成熟及有效比例条件，不要求已经满足45°，具体条件见7.4节。

当前PLL载噪比计数在选中C/N0的`ready`为真时推进：值有效且≥30 dB-Hz则加1，最多3；不满足则清零。引擎转发最近环路质量时会保留`ready`，同一末历元的缓存值可能连续推进计数。因此当前代码的“3次”不能解释为三个不同的1 s统计窗，也不能据此承诺3 s确认时长。本方案描述当前行为，不新增独立窗口门限。

#### 8.2.4 动态量、预测许可与交接资格

动态分类另用当前实际送入FLL且物理有效的频差$e$，按1/8系数更新两个量：

$$
m\leftarrow m+(e-m)/8,\qquad a\leftarrow a+(|e|-a)/8
$$

$m$是有符号平滑均值，$a$是平滑绝对误差。它们不是频率批次的去均值RMS；代码中沿用RMS名称的动态字段实际保存$a$。固定数据FMS缺少物理标定时不进入这条统计。

| 资格 | 建立条件 | 用途与清除 |
|---|---|---|
| 逐PDI预测许可 | 变化率拟合有效且数值有限；在此基础上，批次稳定或$\lvert r\rvert\ge3\sigma$ | 允许FLL既有趋势按时间推进；LongFast同步前不建立该许可 |
| 普通Long链趋势交接资格 | 完整有效批次，预测条件成立；$\lvert r\rvert\ge\max(3\sigma,0.05)$，且FLL当前变化率与$r$相差不超过同一上限 | 标记对应批次末历元；新批次无效或不一致时撤销，过期不继承 |
| 固定FMS趋势校正许可 | 目标为FMS，前级预测许可有效，继承变化率绝对值≥0.1 Hz/s | 换档时决定FMS是否可改写高阶趋势；不限制比例校频 |

L1CA、B1I、G1的ShortFast可在一次实际使用、物理有效的相邻Prompt鉴频观察后开放预测。八种信号处于ShortNormal且当前允许FLL校正时，一次实际使用、物理有效的频率观察也可直接开放预测，不必等待完整监测批次；该次观察处理前尚无许可时，不追溯增加补偿。预测许可与Long链交接历元是两个状态：普通无效批次撤销交接历元，不必然撤销已经获得的预测许可；PDI硬故障清除趋势和两种资格，禁止跨缺口外推。

频率中心时刻补偿与逐PDI趋势预测共用预测许可，但只有当前阶段允许载波校正、频率观察成熟有效、参考时间差有效且非负时，才将补偿后的观察送入FLL。中弱LongFast尚未建立可用同步对齐时不建立许可；L5、B2a、E5a首次同步锁定前保持移交频率，不用该项驱动载波校正。同步后、高灵敏度、已知bit辅助及动态状态均按已建立或合法继承的许可执行，不按C/N0或窗口长度新增开关。数据候选进入独立确认可供对齐，导频要求锁定。

0.05 Hz/s交接容差下限和0.1 Hz/s的FMS趋势校正条件都不是频率中心时刻补偿的开关。禁止FMS改写高阶趋势，不等于禁止用已经确认并保留的趋势作时间补偿；保持趋势数值也不自动建立预测许可。

#### 8.2.5 证据时效

| 证据 | 当前使用边界 |
|---|---|
| 环路质量／PLL参数缓存 | 末历元年龄≤1000 ms |
| FSM码有效性 | DLL监测有效、确有有效DLL更新，距该更新不超过当前码更新周期＋20 ms |
| 普通Long趋势交接 | 信任历元不早于源状态一个完整频率监测窗 |
| 目标快照频率预览 | 目标载波更新周期＋20 ms；只属于显式测试快照检查 |
| 快照中的相位有效性 | 距最近相位结果≤20 ms；不是自动FSM的额外相位门限 |

较长的监测窗不会阻止正常FLL／DLL更新。反过来，最近一次控制成功，也不能替代一个尚未成熟的监测结果。

### 8.3 普通状态链与参数

#### 8.3.1 观察周期与带宽

强入口按ShortFast→ShortNormal→ShortSlow收敛，中弱入口按LongFast→LongNormal→LongSlow收敛。名称中的Fast、Normal、Slow主要表示环路策略，不是重新选择捕获强、中、弱等级。

| 状态 | 载波更新周期 | FLL标称带宽 | DLL基础带宽 | PLL许可 |
|---|---:|---:|---:|---|
| ShortFast | 20 ms | 3.0 Hz | 2.0 Hz | 无 |
| ShortNormal | 20 ms | 2.0 Hz | 0.8 Hz | 无 |
| ShortSlow | 20 ms | 1.0 Hz | 0.1 Hz | 满足7.4节才开放 |
| LongFast | 160 ms | 1.6 Hz | 1.0 Hz | 无 |
| LongNormal | 160 ms | 0.8 Hz | 0.5 Hz | 无 |
| LongSlow | 320 ms | 0.35 Hz | 0.1 Hz | 无 |

表中带宽不是鉴频搜索范围，积分方式也不能只由带宽推出。第9～11章给出实际观察配置；尤其BOC ShortFast的细码观察为160 ms，而非20 ms。

状态变化与同步事件分别处理：数据型强入口可由ShortFast先转ShortNormal，在ShortNormal等待确认；导频ShortFast在二次码未锁定时不换档；LongFast等待独立确认和有效码证据。同步边界建立只切换观察，不凭该事件强制升档。自动递进的驻留配置为ShortFast 400 ms、ShortNormal 1000 ms、LongFast 800 ms、LongNormal 1600 ms；ShortNormal与LongFast等待同步结束后重新计时，不把之前的等待折算为收敛时间。

#### 8.3.2 自动递进与候选确认

| 转换 | 当前自动路径条件 | 驻留 | 候选确认 |
|---|---|---:|---|
| ShortFast→ShortNormal | 数据型可在最终锁定前递进；导频须已锁定 | 400 ms | 一次状态监督 |
| ShortNormal→ShortSlow | 最终同步锁定 | 锁定后1000 ms | 一次状态监督 |
| LongFast→LongNormal | 最终同步锁定、码监测与最近DLL更新有效且新鲜 | 锁定后800 ms | 一次状态监督 |
| LongNormal→LongSlow | 同步仍锁定 | 1600 ms | 一次状态监督 |

自动递进按正常载波观察边界推进，不要求先完成一个目标状态的长窗口，也不把测试快照的频差、码差限制当成通用自动门限。切换后目标窗口重新收数，首次输出时刻按第9～11章的积分配置决定。

其他普通候选默认要求连续400 ms、至少2次监督及1000 ms最小驻留。候选改变或条件不满足时清除该候选确认。动态候选不受普通驻留限制，但要求至少4次监督且确认时长达到400 ms。C/N0专用计数一旦达标就生成待提交状态，不再重复叠加普通确认。

正常状态监督在载波观察成熟时进行，允许使用仍新鲜的C/N0；故障和辅助失效可在PDI监督节拍处理，不必等长积分成熟。当前导频ShortFast未锁定时直接保持该状态，输入模块仍独立处理故障与清窗。

#### 8.3.3 完整自动出口

下表列正常自动路径。所有状态均可保持自身；全局故障请求ShortFast的规则另见8.6节。

| 当前状态 | 正常自动出口 | 原因 |
|---|---|---|
| ShortFast | ShortNormal | 自动收敛 |
| ShortNormal | ShortSlow | 锁定后收敛 |
| ShortSlow | LongSlow、HighDynamic | 低SNR；低SNR转长环时同时满足动态条件 |
| LongFast | LongNormal | 锁定且码证据有效 |
| LongNormal | LongSlow | 自动收敛 |
| LongSlow | ShortSlow、Sensitivity、HighDynamic | 强恢复、进一步变弱、动态增加 |
| Sensitivity | ShortSlow、LongSlow、BitAiding | 强恢复、普通弱恢复、外部辅助 |
| BitAiding | ShortSlow、LongSlow、Sensitivity | 强恢复、普通弱恢复、辅助失效 |
| OutdoorBitAiding | ShortSlow、LongSlow、Sensitivity、BitAiding | 专用强弱计数或辅助失效 |
| MidDynamic | ShortSlow、LongSlow、Sensitivity | 强弱变化或动态下降 |
| HighDynamic | ShortSlow、Sensitivity、MidDynamic | 强弱变化或动态下降 |

LongSlow可直接进入HighDynamic；恢复才经过MidDynamic。ShortSlow满足低SNR转LongSlow时，若同一次监督也满足HighDynamic条件，直接形成HighDynamic候选，不先提交一个短暂的LongSlow。

邻接校验接口还允许MidDynamic→HighDynamic，但当前自动分类函数不主动生成这条边。OutdoorBitAiding不自动进入动态档。允许显式测试的状态边与正常运行实际产生的状态边分开解释。

### 8.4 信号变化时如何选择状态

状态选择依据观测证据，而不是单次噪声或等待时间。主要策略如下。

| 源状态与判据 | 达标次数 | 达标后 | 不满足时的计数处理 |
|---|---:|---|---|
| ShortSlow，本次有效20 ms中心频点线性SNR<0.631 | 4 | LongSlow，或同次动态分类给出的HighDynamic | SNR有效但不低则减1；本次无有效SNR则不计 |
| LongSlow／MidDynamic／HighDynamic，C/N0≤18 dB-Hz且本次频率观察用于控制 | 6 | Sensitivity | 18～32 dB-Hz减1，>32清零；频率无效不计 |
| LongSlow／Sensitivity／BitAiding／动态状态，C/N0≥32 dB-Hz | 21 | ShortSlow | 有效但不足32则减1 |
| Sensitivity，C/N0>24 dB-Hz | 26 | LongSlow | 有效但≤24则减1 |
| Sensitivity，C/N0≤13 dB-Hz | 16且辅助有效 | BitAiding | 有效但>13则减1 |
| BitAiding，C/N0>15 dB-Hz | 6 | LongSlow | 有效但≤15则减1 |
| OutdoorBitAiding，C/N0≥32 dB-Hz | 6 | ShortSlow | 有效但不足32则减1 |
| OutdoorBitAiding，C/N0≤13 dB-Hz | 6 | BitAiding | 有效但>13则减1 |

所有减计数均止于零；生成专用切换目标后清除专用计数。没有有效C/N0时不推进依赖它的计数。优先级为通道／同步故障、辅助失效、ShortSlow本次低SNR、强恢复、进一步变弱、Sensitivity或辅助恢复，最后才是普通自动递进与动态候选确认。

这些为累积计数，不全部是“连续N次”：相关C/N0条件不满足时通常减1至零，弱化计数在C/N0>32 dB-Hz时清零。ShortSlow使用新的20 ms SNR结果；其他计数可在载波观察更新边界使用仍在有效期内的最近C/N0，因此计数次数不等于独立C/N0窗口数。不能按每1 ms重复推进本应按载波观察节拍更新的计数。

动态分类只在同步已锁定、C/N0有效且>16 dB-Hz时进行。LongSlow在“残差均值绝对值／平均绝对误差>0.8，且平均绝对误差>4.6875 Hz”，或可信频率变化率在320 ms内引起的变化>4.6875 Hz时，可进入HighDynamic。恢复时，该比例<0.2且变化率条件不再成立，按HighDynamic→MidDynamic→LongSlow退回。

BitAiding辅助失效直接请求Sensitivity。OutdoorBitAiding辅助失效时，若当前C/N0有效且≥32 dB-Hz，请求ShortSlow；有效且18～<32时请求LongSlow；更低或无有效C/N0则请求Sensitivity。这些失效出口不等待600／300 ms辅助观察完成，但仍须按8.6节确认命令。

### 8.5 极弱、动态与外部辅助边界

#### 8.5.1 专用状态的分工

| 状态 | 基础载波配置 | 控制周期 | FLL／DLL基础带宽 |
|---|---|---:|---|
| Sensitivity | 数据型20 ms×16功率、固定三频点FMS | 320 ms | 0.2／0.15 Hz |
| BitAiding | 已知bit下120 ms×5功率、固定三频点FMS | 600 ms | 0.05／0.025 Hz |
| OutdoorBitAiding | 已知bit下100 ms×3功率、11点DFT | 300 ms | 0.4／0.1 Hz |
| MidDynamic | 数据型20 ms×16功率；普通导频连续320 ms | 320 ms | 0.5／0.1 Hz |
| HighDynamic | 同上，采用动态带宽 | 320 ms | 0.7／0.1 Hz |

这些状态都只用FLL，不允许PLL相位控制。普通动态状态主要改变FLL带宽，数据型仍为20 ms×16功率，导频仍为连续320 ms及匹配的频率网格；不同信号的码观察继续按第9～11章分块。

#### 8.5.2 Sensitivity载波与码观察

| 信号类别 | 载波处理，均320 ms更新 | 码观察跨度／更新 | 抽头E/L、VE/VL |
|---|---|---|---|
| L1CA／B1I／G1 | 20 ms位内相干×16块功率，0与±5 Hz固定FMS | 20 ms块幅度，最近600 ms／320 ms | ±1/6、±1/3 chip |
| L5／B2a／E5a | 已擦码连续320 ms，0与±1.5625 Hz解析FMS | 5 s相位补偿长相干／320 ms | ±1/6、±1/3 chip |
| E1／B1C | 已擦码连续320 ms，0与±1.5625 Hz解析FMS | ASPeCT主码点积，最近600 ms／320 ms | 固定±0.25、±0.50 chip |

数据型FMS使用5.4节的固定控制增益，导频使用相干时间匹配的解析换算。导频码环带宽均为0.025 Hz，但BOC在码观察路由上优先使用ASPeCT，绝不因此改成5 s跨主码复相干。

这些是已同步后的专用路径。进入Sensitivity不免除同步或符号条件；数据位未知正负仍不能跨位直接相加，导频擦码失效则丢弃长相干窗口。

#### 8.5.3 L5类Sensitivity的5 s码观察

该模块在L5／B2a／E5a已经锁定且处于Sensitivity时工作。它使用已擦码1 ms五抽头和实际NCO参考，拟合当前5 s内的载波相位，使五抽头可以在较长时间内相干相加。它输出码误差，不把搜索得到的频率和变化率回写FLL。

<p class="figure-caption" style="text-align: center;">图8-3 极弱导频的长窗只生成码误差；载波仍由独立320 ms FMS控制。</p>

处理顺序如下。

1. 保存最近5000条连续、已擦码PDI。以窗口中央PDI为相位和时间参考；已有预测许可时使用FLL变化率作为搜索中心，否则以0变化率为中心。
2. 将历史NCO频率按该变化率换算到窗口中心，再求平均，得到中心频率。
3. 在中心附近枚举21个频率与13个变化率：频率步长0.2 Hz、范围±2 Hz；变化率步长0.05 Hz/s、范围±0.30 Hz/s。
4. 每个候选只对Prompt恢复相位并作5 s复相干，取功率。选粗峰后再用11×11局部网格细化；两维细步长分别为0.02 Hz和0.005 Hz/s，覆盖粗峰两侧半个粗间隔。
5. 固定获胜模型，对五抽头使用相同相位补偿，分别连续相干5 s，再形成一次局部码误差。

设距参考PDI的时间为$t$秒，候选频率、变化率为$f,r$，候选相位为：

$$
\theta=ft+\tfrac12rt^2
$$

$\theta$以cycle表示。每条相关乘以“该PDI的NCO参考相位相对窗中心的变化，减去$\theta$”对应的复旋转。补偿使用PDI记录和软件已知的NCO参考，不读取原始IQ或硬件内部状态。

五抽头长相干后计算精确浮点幅度，直接送入公共码鉴别器，不再缩放到整数容器或舍入为Q11。该路径固定采用标准E−L和局部峰选择，不使用普通慢状态的双差选择。Prompt功率通过有效性检查且码鉴别有效才发布码误差。

首次结果必须收满5 s，此后每新增320 ms重算最近5 s，窗口重叠。PDI不完整、历元中断或NCO参考非有限时清窗。它与普通Long状态的20 ms码块、160／320 ms更新不是同一配置，不能从普通状态表推出。

#### 8.5.4 外部已知bit辅助

外部接口必须为每条PDI给出±1符号及时间映射有效标志。先由正常同步擦除公开覆盖码，再将同一外部导航符号乘到五抽头；辅助不应重复擦除NH或meander。

| 状态 | 单块相干 | 载波合并 | 码合并 | 首次完整观察 |
|---|---:|---|---|---:|
| BitAiding | 120 ms | 5块功率，固定0与±5 Hz FMS | 5块幅度 | 600 ms |
| OutdoorBitAiding | 100 ms | 3块功率，11点×5 Hz DFT | 3块幅度 | 300 ms |

从合法20 ms数据边界开始。辅助有效且最终同步锁定，才允许跨导航bit连续相干；任一PDI缺少有效±1符号、时间轴中断或锁定失效，立即丢弃未完成辅助块与对应历史。等待恢复时不假设缺失符号为+1，也不用前一bit代替。

数据型通道还并行维护120 ms和100 ms辅助预热观察，失效时两路一起清除。这是代码保留的辅助预览能力；当前自动FSM不调用辅助目标预热检查作为必经门限，提交辅助状态后仍按目标窗口重新收数。

BitAiding控制采用窄抽头±1/6、±1/3 chip；OutdoorBitAiding使用普通±1/3、±2/3 chip。退出条件、计数和辅助失效的C/N0分流见8.4节。仅锁定导航bit边界不能产生外部已知符号，普通导频公开二次码擦除也不称为bit辅助。

#### 8.5.5 能力与资格边界

严格已知bit辅助保持的设计目标为L1CA −167 dBm、G1 −166 dBm；按$N_0=-170$ dBm/Hz分别为3、4 dB-Hz。这是待独立资格验证的目标，不是当前已通过能力声明。普通自主同步和跟踪的实现不等于已经完成极弱辅助资格验证。

### 8.6 生效边界与恢复

#### 8.6.1 一次自动换档的顺序

状态机先形成待提交状态；硬件命令确认后，软件才采用目标策略。目标观察预览和单状态测试的入口限制不是正常自动换档的统一前置步骤。

![[90-附件/图STSW-28_状态交接与首次观察_v01.svg]]

<p class="figure-caption" style="text-align: center;">图8-4 候选选择、命令确认和首个新观察是三个不同时间点。</p>

以在历元K选择新状态为例：

| 时刻 | 行为 |
|---|---|
| K的观察与控制处理结束 | 旧策略完成当前观察，FSM选择待提交状态；保持当前有效状态不变 |
| K末生成命令 | 命令编号递增，目标生效历元为K+1；携带目标抽头／分量配置，但不装载相位 |
| K+1输入到达 | 先核对PDI健康和实际命令编号；确认后提交目标状态，再重建软件积分与环路配置 |
| K+1的观察处理 | 正常交接的本条PDI可按目标配置收数；需要数据位／完整主码首段的路径仍等待合法边界 |
| 目标窗口收满 | 发布第一条目标观察，才使用新测量校正；窗口未满不注入零误差 |

码步进在确认PDI上保留交接前的值一次，后续命令再使用新码环配置；已到期的粗码斜坡撤销优先，不被“保持旧步进”延长。同步搜索在PDI处理中途产生的新边界是另一种事件：触发它的PDI已经属于旧观察，不能重复作为新积分首条，见第9～11章。

#### 8.6.2 载波、码环和监测各保留什么

所有普通载波参数切换先把当前FLL＋PLL总频率吸收到FLL基值，再清PLL积分，所以频率控制值连续。趋势保留按下表，保留数值不等于自动获得逐PDI预测许可。

| FLL趋势允许保留的路径 | 额外说明 |
|---|---|
| ShortFast→ShortNormal；ShortNormal→ShortSlow | 保持短周期载波连续性 |
| ShortSlow→HighDynamic | 保留直接动态交接趋势 |
| LongFast→LongNormal；LongNormal→LongSlow | 必须有8.2.4节的普通Long链信任历元，且未超过源状态一个监测窗 |
| LongSlow→Sensitivity | 继承当前变化率；固定FMS能否继续修改它另按0.1 Hz/s条件决定 |
| Sensitivity→LongSlow、BitAiding或OutdoorBitAiding | 保留来源趋势 |
| LongSlow→OutdoorBitAiding | 保留来源趋势 |
| 动态状态→另一个动态状态、LongSlow或Sensitivity | 保留来源趋势 |
| OutdoorBitAiding→非HighDynamic目标 | 保留来源趋势 |
| 同状态同步对齐重建 | 只有旧预测许可有效时保留 |

未列出的普通自动路径清除趋势，例如LongSlow→HighDynamic和普通慢状态→ShortSlow不能假定一定继承。候选邻接关系本身不保证趋势继承。进入新更新周期时保留的是Hz/s，重新乘新周期形成离散趋势步进，不复制旧步进字。

DLL先应用目标增益，然后按以下顺序处理积分：动态状态→Sensitivity清除；Sensitivity→LongSlow保留；其他涉及动态状态的边保留；OutdoorBitAiding退出保留；其余清除。清除DLL残差不重装码相位，载波辅助仍由当前多普勒生成。

| 软件对象 | 正常换档行为 |
|---|---|
| 已确认同步边界 | 兼容时保留；普通回ShortFast按恢复流程重建同步 |
| 相干积分与DFT／局部鉴频历史 | 清除旧配置窗口，新配置重新收数 |
| 频率批次、相位监测、DLL监测 | 重建；最近频差、相位和码证据时标清除 |
| PLL的C/N0确认计数 | 清零 |
| 动态均值／绝对误差平滑 | 四条Fast→Normal→Slow自动递进边清除；普通C/N0与动态换档保留 |
| 数据联合诊断 | 丢弃跨策略的未完成符号 |
| C/N0历史 | 普通换档不一概清空；边界、显示分支或辅助条件改变时由各估计器清除不兼容部分 |

#### 8.6.3 时间轴异常与持续故障

| 事件 | 当前处理 | 不允许的处理 |
|---|---|---|
| 移交首条不足1 ms的partial PDI | 不进入观察，但不单独判为通道故障 | 当成完整相关使用 |
| epoch不符、gap、overflow、命令迟到 | PDI无效，清跨断点窗口；当前频率保留、趋势清零并重新锚定时间 | 跨缺口相干或继续外推旧趋势 |
| 普通换档期间命令未确认 | 取消普通待提交状态，回到当前状态重新积累候选 | 提前宣布目标状态已经生效 |
| 安全回ShortFast期间命令未确认 | 保留安全候选，重发过渡标记，等待健康PDI确认 | 将未确认命令当成已应用 |
| 健康PDI确认编号却与待提交编号矛盾 | 报告逻辑错误，不静默提交 | 猜测硬件执行了哪一条命令 |
| 一次普通观察无效 | 跳过该观察的校正，继续当前窗口节拍 | 立即按“弱信号”换档或注入零误差 |
| 数据LongFast同步搜索穷尽 | 重建同步与牵引观察，保留LongFast和已有NCO | 转成强入口ShortFast |
| BOC局部细码／外峰检查失败 | 按11.3节回粗码，保留捕获入口 | 绕过粗码独立确认 |

故障候选不受普通最小驻留时间限制，但通常仍需连续400 ms及至少2次监督；持续故障按1 ms监督推进，单个缺口本身不是立即重捕。已有待提交安全候选保持到命令真实确认。ShortFast已经是安全入口时保持自身；导频ShortFast未锁定时，状态监督保持该状态，输入与局部模块照常执行故障清窗。

已跟踪后的同步丢失按当前状态的故障路径处理，不与“首次LongFast还在搜索”混淆。当前没有通用宽码搜索或返回捕获模块的完整运行时重捕协议，不能把局部恢复描述成任意码误差重捕获。

#### 8.6.4 显式测试入口与自动流程的界限

单状态测试可从健康通道截取入口快照，再固定一个目标状态。快照保存同一PDI的物理频率、码率、相位、同步、辅助和命令时标，不复制未完成观察窗。

测试入口校验版本和时间身份，再检查合法邻接、新鲜频率／码证据、适用同步与C/N0。固定Sensitivity／BitAiding时残差限制为±5 Hz，OutdoorBitAiding为±25 Hz；码均值通常限0.10 chip，BitAiding为0.15 chip，ShortNormal码RMS放宽到0.20 chip。这些用于防止测试从不合法入口直接冻结状态，不是自动FSM额外的运行门限。

目标频率预览可补充测试快照的频率证据；维护辅助预热缓存不表示正式自动换档必须等待该缓存。普通自动换档仍按8.3、8.4和8.6.1节执行，测试中固定状态的接口不属于生产自动流程。

## 9 数据型信号跟踪方案

L1CA、G1和B1I共同采用“载波与码环并行牵引→频率居中后搜索位边界→候选校频→独立确认→按位积分跟踪”。三种信号的导航bit均为20 ms，区别主要在bit内部的公开符号。

| 信号 | 一个20 ms bit内的结构 | 牵引灵敏度 |
|---|---|---:|
| L1CA | 无附加翻转 | 22 dB-Hz |
| G1 | 前后10 ms的meander符号相反 | 22 dB-Hz |
| B1I D1 | 每1 ms一个NH码片，共20个 | 24 dB-Hz |

强、中弱入口分别由捕获强档和捕获中／弱档选择。表中的信号专属牵引灵敏度不是强档门限。码环从入口开始独立运行，不等待位同步。

### 9.1 强信号载波牵引

![[90-附件/图STSW-07_数据型强信号载波牵引_v01.svg]]

#### 9.1.1 L1CA与G1：相邻1 ms的asin鉴频

使用5.2.1节的方法，输入相邻1 ms Prompt，连续20个间隔等权平均后发布一次频差。空状态需要21条连续PDI，随后保留末端Prompt，每新增20条发布一次。

频差使用该窗口自身的NCO参考，交给ShortFast FLL；不直接覆盖载波NCO。未知bit或meander翻转的影响由相邻间隔平均处理，本阶段不判定导航bit。

#### 9.1.2 B1I：平方Prompt后asin鉴频

使用5.2.2节的方法。先将每条1 ms Prompt复平方，再逐对asin鉴频、除以二倍角尺度，最后平均20个间隔。复平方消除NH和导航bit的正负号；此路径不搜索NH相位。

### 9.2 中弱信号载波牵引

![[90-附件/图STSW-08_数据型中弱载波牵引_v01.svg]]

<p class="figure-caption" style="text-align: center;">图9-3 L1CA、G1采用短相干功率DFT；B1I采用平方Prompt频差平均。</p>

#### 9.2.1 L1CA与G1：短相干功率DFT

按5.3节，在每个候选内先作短块相干，再跨块累加功率。

| 信号 | 单块相干 | 块间合并 | 观察跨度／更新周期 | 候选频率 |
|---|---:|---|---:|---|
| L1CA | 10 ms | 16块功率相加 | 160／160 ms | 11点，12.5 Hz间隔，±62.5 Hz |
| G1 | 5 ms | 32块功率相加 | 160／160 ms | 同上 |

短块用于减轻未知边界造成的相消，但并未与真实bit或meander对齐，仍可能跨符号。每窗使用160条新PDI，不重叠；统一窗内NCO参考后，逐候选旋转、相干、累加功率、寻峰插值。

牵引允许边缘频点发布，插值偏移限±0.5频点，输出限制在±62.5 Hz；不另加旁峰比拒绝条件。空数据、非有限结果及时间错误仍无效。

例如G1依次对第0～4、5～9、……、155～159条Prompt相干，再加32个块功率。不是先对160条取功率，也不是160 ms连续相干。NCO参考统一使用本窗实际频率的平均值，并按相邻NCO频率平均累积相位补偿。

#### 9.2.2 B1I：160个间隔的平方Prompt平均鉴频

沿用9.1.2节，仅将平均长度改为160个间隔。首次需要161条PDI，后续每160 ms发布一次；前置Prompt保留到下一窗，断点时连同窗口一起清除。观察参考取这些相邻间隔中心NCO的平均值。该载波牵引不使用DFT，也不搜索NH相位。

两条中弱路径均由LongFast FLL每160 ms更新。同步前不建立逐毫秒频率变化率外推，两个有效观察之间保持最近控制量。

### 9.3 码环牵引

![[90-附件/图STSW-09_数据型码环牵引_v02.svg]]

<p class="figure-caption" style="text-align: center;">图9-4 强入口先鉴别再平均，中弱入口先积累再鉴别；码误差统一送入载波辅助DLL。</p>

使用5.6节的五抽头局部鉴别，位置固定为−2/3、−1/3、0、+1/3、+2/3 chip。

| 信号／入口 | 单块处理 | 块间处理 | 观察跨度／更新周期 |
|---|---|---|---:|
| 三种信号强入口 | 1 ms五抽头功率并鉴别 | 按固定20 ms分母平均误差 | 20／20 ms |
| L1CA中弱入口 | 10 ms五抽头相干，取浮点幅度 | 16块幅度相加后鉴别 | 160／160 ms |
| G1中弱入口 | 5 ms五抽头相干，取浮点幅度 | 32块幅度相加后鉴别 | 160／160 ms |

### 9.4 位同步

![[90-附件/图STSW-10_数据型位同步模块_v01.svg]]

<p class="figure-caption" style="text-align: center;">图9-5 联合搜索频率与边界，搜索通过后校频，再用新数据确认边界。</p>

#### 9.4.1 开放条件

每次有效载波观察用自己的NCO参考恢复绝对频率。最近三次有效绝对频率的最大值与最小值之差≤15.625 Hz，且当前残余频差绝对值≤15.625 Hz时，允许同步器从下一条完整PDI开始收数。

普通无效频率观察不计入三次统计，也不撤销已成立的开放资格；未锁定时的PDI硬故障清除资格。资格通过只代表可以开始搜索，不保证后续整个同步窗口始终满足同样残差。

#### 9.4.2 搜索与评分

三种信号都枚举20个毫秒边界和11个频率，共220个组合。频率网格为12.5 Hz间隔、±62.5 Hz，与L1CA／G1载波牵引一致。

同步器使用独立Prompt窗口和独立频率旋转，不共享牵引DFT的复积分或功率谱。B1I仅在这里使用频率候选，其同步前载波牵引仍是平方Prompt鉴频。

每个组合按6.2节作20 ms位内相干、位间功率相加，公开符号如下。

| 信号 | 候选bit内符号处理 |
|---|---|
| L1CA | 全部乘+1 |
| G1 | 前10条乘+1，后10条乘−1 |
| B1I | 按NH20：`00000100110101001110`；0为+1，1为−1 |

例如边界候选为7，就积分第7～26、27～46条等完整bit。B1I每个候选bit从NH第0项开始；导航bit正负仍未知，所以bit之间只累加功率。

全局选峰后固定获胜边界，按12.5 Hz网格三点插值。质量检查使用离散获胜频率上的原评分：峰值比≥1.18、质量积≥370；L1CA／G1还检查两侧局部峰形，B1I不检查峰形，定义见6.4节。

#### 9.4.3 搜索、校频与独立确认

| 阶段 | 有效统计时长 | 额外边界数据 | 频率候选 | 不通过时 |
|---|---:|---:|---|---|
| 首次搜索 | 1 s | 19 ms | 11点 | 清窗，改用2 s新数据 |
| 第二次搜索 | 2 s | 19 ms | 11点 | 清窗，改用4 s新数据 |
| 最长搜索 | 4 s | 19 ms | 11点 | 本轮失败，按入口重启 |
| 独立确认 | 成功搜索时长的2倍，限2～4 s | 19 ms | 仅0 Hz | 延长到4 s；仍失败则重启 |

搜索通过后保存边界，并将搜索残余频差吸收到NCO一次，保持相位连续，清除未经独立确认的频率变化率。随后丢弃搜索数据，从新的NCO中心建立确认窗口。

确认仍比较20个边界，使用相同质量判据。与候选一致即完成“一次搜索＋一次独立确认”；确认得到另一有效边界时保存新边界，重新收取独立确认数据。1、2、4 s重试窗口与搜索／确认窗口均不复用Prompt。

正常同步失败后，强入口回ShortFast，中弱入口保持LongFast，继续使用已有载波和码控制重新牵引；不把失败解释为零误差。

### 9.5 边界建立后的积分与鉴别器切换

#### 9.5.1 候选成立与锁定是两个切换时刻

| 时刻 | 载波处理 | 码处理 |
|---|---|---|
| 尚无有效候选 | 使用9.1／9.2节牵引观察 | 使用9.3节牵引观察 |
| 搜索候选成立 | 校频一次，按候选边界形成20 ms位内DFT观察 | 仍用牵引码观察 |
| 独立确认锁定 | 保持已确认的20 ms边界，不重复校频 | 改用边界对齐的20 ms相干块 |

L1CA直接积分，G1先擦meander，B1I先擦NH20。三者仍有未知导航bit，不能跨bit连续复相干。候选改变时清窗并重新对齐；候选与最终边界一致时不再次移动网格。边界事件本身保留当前状态；强入口此时可能已处于ShortNormal，中弱入口仍为LongFast，后续按第8章换档。

#### 9.5.2 强、中弱状态的观察配置

| 状态 | 载波单块相干 | 载波块间合并 | 载波跨度／更新 | 码观察组成／更新 |
|---|---:|---|---:|---|
| ShortFast／Normal／Slow | 20 ms | 一个块功率 | 20／20 ms | 一个20 ms块幅度，20 ms更新 |
| LongFast／Normal | 20 ms | 8块功率相加 | 160／160 ms | 8块20 ms幅度相加，160 ms更新 |

普通载波统一采用11点功率DFT与三点插值，间隔10 Hz、搜索±50 Hz，控制输出限±25 Hz，细节见5.3.2节。不继续使用同步前的1 ms asin或平方Prompt鉴频，也不串联FMS。

三种信号对20 ms相干Prompt采用Costas鉴相。只有ShortSlow满足7.4节条件后才使用PLL；普通Long和动态状态始终FLL-only。Sensitivity另用20 ms×16功率、0和±5 Hz的固定FMS，不由同步成功自动开启。

#### 9.5.3 首次输出与异常

从后续合法bit边界收数，不把切换触发PDI重复计入。Short需要1个完整块，LongFast／Normal需要8块，LongSlow需要16块，收满前不发布新观察。PDI缺口或边界失效丢弃未完成积分；正常NCO连续换字仅更新参考解释，不视为数据缺口。

### 10.5 二次码锁定后的积分与鉴别器切换

#### 10.5.1 锁定时的统一动作

搜索候选不能开启擦码闭环。独立确认锁定后，按绝对主码周期逐条擦除导频五抽头；只有本条有效且已经正确擦码的PDI才进入新积分。

保持原Fast状态和连续NCO，清除旧统计。锁定触发PDI不重复使用，从下一条有效PDI开始；导频不必等待导航bit或二次码第0码片。载波候选直接处理逐1 ms擦码Prompt，码环另行形成20 ms五抽头块。

#### 10.5.2 强信号跟踪

| 状态 | 主鉴频器 | 数据跨度／更新周期 | 码观察 |
|---|---|---|---|
| ShortFast | 20 ms功率DFT＋插值，11点×10 Hz，±50 Hz | 20／20 ms | 一个20 ms块幅度 |
| ShortNormal／ShortSlow | 相邻20 ms擦码块atan2，中心间隔20 ms | 首次40 ms，之后20 ms更新 | 同左 |

相邻块观察检查连续性、有限数值、正功率和0.10质量下限。每个周期DFT支路仍运行，提供中心信噪比及有效回退结果：本周期DFT成熟时，优先使用成熟有效的相邻块结果，否则使用DFT结果；两者都无效则不作新FLL校正。

鉴相使用20 ms块的四象限atan2；只有ShortSlow满足7.4节条件后开放PLL。相邻块鉴频和单块鉴相是两种计算，不共用取角结果。

#### 10.5.3 中弱信号跟踪

| 状态 | 载波单块相干 | 频率候选 | 码块与合并 | 观察／更新周期 |
|---|---:|---|---|---:|
| LongFast／Normal | 连续160 ms | 11点，3.125 Hz间隔，±15.625 Hz | 20 ms×8块浮点幅度相加 | 160／160 ms |
| LongSlow／普通动态状态 | 连续320 ms | 11点，1.5625 Hz间隔，±7.8125 Hz | 20 ms×16块浮点幅度相加 | 320／320 ms |

按5.3节先逐PDI补偿候选，再对整窗连续相干，最后取一次功率。160／320 ms候选间隔均为相干时长倒数的一半；信号在覆盖范围内时，距最近候选最多四分之一个自然频点。不能先将未补偿的160／320条Prompt相加，再做候选计算。

码环不使用载波候选旋转后的长相干结果。它每20 ms形成五抽头复相关，转为幅度后累加8／16块。普通Long状态始终FLL-only，不把长DFT复数和的相位直接送入PLL。

#### 10.5.4 首次输出、重配和异常

若锁定发生在历元K，后续数据连续，则K+1～K+20形成首个码相干块；LongFast在K+160得到首次载波观察和8块组成的码观察。进入新LongSlow窗口后须收满320 ms。

正常换档保留已确认二次码位置，重新建立目标观察。PDI断点或擦码无效时丢弃未完成统计；保留边界不代表可以拼接缺口两侧数据。显式同步复位后重新搜索。Sensitivity及外部辅助按8.5节的专用配置处理。

#### 10.5.5 数据边界继承

三种信号数据和导频具有共同码历元。导频二次码锁定后，数据支路直接继承时间基准，不单独搜索或确认，不另设数据同步峰值比。

| 数据分量 | 完整符号长度 | 数据块首位置 |
|---|---:|---|
| L5I | 10 ms | 导频边界模10 |
| B2a-D | 5 ms | 导频边界模5 |
| E5a-I | 20 ms | 导频边界模20 |

这里的导频边界是绝对主码周期的模位置，不是软件20 ms积分网格。例如L5导频边界为17，数据边界为7；主码周期号模10等于7时开始一个完整符号。中途锁定先丢弃残段，等待下一个完整边界。

继承只确定起止，不表示导航bit正负已知或完成帧同步。导频边界改变、PDI或主码周期中断时清除未完成数据符号；即使取模后的边界相同，也重新从完整符号起步。

#### 10.5.6 只读联合诊断

每个完整数据符号分为判决段与评价段：L5为5＋5 ms，B2a为2＋3 ms，E5a为10＋10 ms。两分量擦除各自公开符号并统一固定相位后，前段分别积分为$D,P$，用$\operatorname{Re}(DP^*)$的正负得到符号判决$s$，置信度为$|\operatorname{Re}(DP^*)|/(|D||P|)$。

后段独立形成$D_e,P_e$，计算联合结果：

$$
U=P_e+sD_e
$$

输出数据、导频和联合功率，判决与评价不共用噪声。零幅度或非有限结果无效。该支路不反馈同步、C/N0控制口径、状态机或NCO；数据支路失败不影响有效导频闭环。

#### 11.1.1 完整主码与平方复积

只使用导频完整BOC副本。五抽头分别在同一主码内相干，E1收齐4条PDI，B1C收齐10条；PRN-only不加入载波Prompt。主码内片段必须完整连续、周期号一致，且相关命令已确认。

同一抽头的相邻主码记为$A,B$，按5.2.2节形成$U=(A^*B)^2$。先用各主码对自身的NCO参考补偿，再合并各抽头、各间隔；等效参考采用相邻复积幅度加权。

强入口在本组20 ms内将所有有效平方复积相加，得到$C$，取一次角度：

$$
e_f=\frac{\operatorname{atan2}(\operatorname{Im}C,\operatorname{Re}C)}{4\pi T}
$$

| 信号 | 一组完整主码数 | 组内相邻间隔数 | 数学无模糊半范围 | 观察／FLL更新 |
|---|---:|---:|---:|---:|
| E1 | 5 | 4 | 62.5 Hz | 20／20 ms |
| B1C | 2 | 1 | 25 Hz | 20／20 ms |

#### 11.1.2 有效性与调码暂停

| 检查 | 定义与要求 | 作用 |
|---|---|---|
| 复积集中度 | 全部$U$之和的模／全部$U$的模之和≥0.65 | 避免相互抵消的复积形成不可靠角度 |
| 主码内相干比 | 五抽头主码相干功率总和／“主码PDI数×逐PDI功率总和”≥0.14 | 检查主码相干数据质量 |
| 数值和时间 | 有限、分母为正、复积非零、主码及时间连续 | 排除无法解释的观察 |

#### 11.3.1 固定抽头与处理分工

| 副本与阶段 | VE | E | P | L | VL |
|---|---:|---:|---:|---:|---:|
| BOC／PRN-only，牵引及跟踪全过程 | −0.50 | −0.25 | 0 | +0.25 | +0.50 |

单位chip。两副本使用相同抽头位置，不随粗细阶段切换硬件间距。粗码判断相关峰大致方向，细码形成局部连续误差；粗码转细码仍须命令确认和清窗。

粗码和首次细码采用160 ms基础观察，独立于强入口载波的20 ms节拍。E1粗方向还累加8个基础窗。

#### 11.3.2 E1粗功率：去除噪声底

对一个抽头，将4 ms主码复相关和记为$Z$，4条1 ms功率之和记为$S$：

$$
W=\frac{4}{3}(|Z|^2-S)
$$

在主码内信号近似恒定、毫秒噪声独立的模型下，$W$保留相干信号功率并去除噪声底均值。它允许为负，不截零、不取绝对值。五抽头分别累计。

同时计算噪声功率和方差估计：

$$
B=\max\left(0,\frac{4S-|Z|^2}{3}\right),\qquad V=\frac{4}{3}B^2
$$

功率$W$与方差$V$使用相同数据范围累加。累计$V$开方得到标准差；同侧两个抽头分组时用两者标准差的平均作为保守上界。获胜方向功率还须≥自身标准差的4倍，避免噪声起伏触发调码。

#### 11.3.3 B1C粗功率：双副本组合

将一个完整10 ms主码的BOC复相关记为$A$，PRN-only记为$B$：

$$
W=|A|^2-2|B|^2
$$

两副本先各自主码相干再取功率，不能先在复数域相减。修改功率保留负值；每160 ms累加16个主码。B1C使用此功率及方向对比度，不套用E1去噪声底和4倍标准差检查。

#### 11.3.4 三方向判决与独立确认

将五抽头粗功率分为Early、Center、Late：Early为VE与E平均，Center为P，Late为L与VL平均。最大组记为$A$，其余两组的较大值记为$B$，方向对比度为：

$$
q=\frac{A-B}{|A|+|B|}
$$

三组须有限、最大组唯一且>1.0、分母为正、$q\ge0.10$。1.0是当前软件相关尺度下的正功率下限，不是C/N0门限。E1另检查11.3.2节的统计显著性。

| 信号 | 每次方向判决的数据 | 独立同向确认 | 从空窗起步最早发布 |
|---|---|---:|---:|
| E1 | 160 ms×8 | 2次 | 2560 ms |
| B1C | 160 ms×1 | 2次 | 320 ms |

第一窗保存候选方向，第二个独立窗有效且同向才发布。无效窗清候选，方向改变则从新方向重新计数；每次判决清空累计，不使用重叠窗充当独立证据。

可靠Center允许试探细码，不直接宣布居中；可靠Early／Late请求有限调码；无效方向不产生码修正。

#### 11.3.5 有限调码与细码试探

一次修正量$\Delta c$不超过0.10 chip，通过160 ms码率偏置完成：

$$
r=\frac{\Delta c}{0.160},\qquad |r|\le0.625\ \mathrm{chip/s}
$$

偏置叠加到正常码率及载波辅助，不直接装载码相位。修正从下一命令开始，按绝对历元到期；到期发送零偏置停止命令，收到PDI确认后才算完成，等待或缺口不延长斜坡。

粗方向可靠返回Center，或完成同向调码次数达到E1的4次／B1C的3次时，请求细码试探。计数只统计已经执行且停止命令已确认的非零斜坡，不是每个案例必须执行的次数，也不代替细码检查。

方向反转重新计数；时间断点、未同步策略重建、细码回粗码时撤销不兼容计数；普通同向调码后的粗窗重建保留完成次数。斜坡和停止确认期间不让细DLL积分代替粗调。

#### 11.3.6 细码检查与居中

细码入口命令确认后，从新的完整主码收数，按5.7节分别累加双副本点积和Prompt功率。每160 ms得到一次细码误差；首次细码检查中，只有成熟、有效且$|e_c|\le0.20$ chip的观察进入DLL。

超过0.20 chip时不作本次DLL纠偏，但原始有效误差仍进入监测。码监测保留覆盖至少400 ms的有效历史，160 ms更新时首批需3次、共480 ms。其均值按观察时长加权，RMS相对零计算，包含偏差。

均值绝对值和RMS均≤0.10 chip才开放同步。0.20限制本次局部纠偏，0.10判断持续居中；两者不是重复的门限。细码期间同时复核粗方向，可信外峰优先，防止局部小误差掩盖主峰偏离。

#### 11.3.7 保持与回退

| 情况 | 处理 |
|---|---|
| 细观察或监测尚未成熟 | 继续积累，不用0代替 |
| 首次细码试探形成无效观察 | 撤销试探，回粗码 |
| 已开放同步后单次细观察无效 | 重建码监测，不仅凭这一次撤销已开放资格 |
| 重新成熟的监测超过0.10 chip条件 | 撤销居中与同步窗口，回粗码 |
| 可信外峰重现 | 撤销细码资格，回粗码 |
| PDI、命令或主码时间轴断点 | 清除跨断点观察、资格和不兼容计数 |

首次居中通过的PDI不回填同步窗口，从后续完整主码开始搜索。搜索和确认期间细DLL、居中监测与外峰复核继续工作。正常局部失败保持原捕获入口，LongFast不因此改为ShortFast。

### 11.4 导频二次码同步

![[90-附件/图STSW-19_BOC二次码同步_v01.svg]]

<p class="figure-caption" style="text-align: center;">图11-5 居中后搜索二次码位置，不增加频率候选或同步校频旁路。</p>

#### 11.4.1 输入与评分

输入为通过载波有效资格及细码居中后的完整主码Prompt。绝对主码周期号按6.3节查候选二次码符号，在20 ms内擦码相干，再累加各段功率。

| 参数 | E1 | B1C |
|---|---:|---:|
| 候选位置 | 25 | 1800 |
| 一个20 ms段的主码数 | 5 | 2 |
| 一个搜索窗的主码数 | 250 | 1800 |
| 功率累加段数 | 50 | 900 |
| 搜索时长 | 1 s | 18 s |
| 独立确认时长 | 1 s新数据 | 18 s新数据 |
| 主峰／其他位置最大峰 | ≥1.18 | ≥1.18 |

E1用64点FFT加速25位置相关；B1C用双主码功率查表，计算方法见6.6节。二者都只寻找二次码位置，不重新搜索主码码相位，也不生成载波校频量。

#### 11.4.2 确认、滑动与失败

搜索通过后清空历史，确认窗重新比较全部位置。同一位置通过才锁定；得到另一有效位置则清窗重新确认；确认无效则清候选回搜索。强、中弱均使用1.18门限。

失败搜索可以滑动：E1删除5个主码、补入20 ms新数据；B1C删除100个主码、补入1 s新数据。成功搜索与确认必须独立。该搜索滑动不改变载波20／160 ms非重叠观察。

同步器检查完整主码首末PDI与绝对主码周期连续性。正常NCO连续换字不清同步窗口；居中资格撤销、粗细阶段交接、PDI或命令时间断点则清除不能继续解释的数据和候选。搜索候选与正常鉴频同时成熟时，不覆盖鉴频结果、不增加一次NCO校正。

### 11.5 二次码锁定后的积分与鉴别器切换

![[90-附件/图STSW-20_BOC同步后跟踪_v01.svg]]

<p class="figure-caption" style="text-align: center;">图11-6 载波改用擦码观察，码环继续按完整主码形成双副本鉴别量。</p>

#### 11.5.1 锁定时的动作

确认锁定后清除同步前主码平方鉴频和未完成载波窗口，不再送入FLL。锁定事件本身不产生频差或相差修正，保留连续NCO和当前Fast状态。

触发锁定的PDI不进入新窗，后续逐PDI按已确认二次码位置擦码。载波从有效擦码PDI建立窗口；码环仍用原始双副本，从下一完整主码建立点积统计。两支路分别判断成熟，不互相等待。

#### 11.5.2 强信号载波与鉴相

| 状态 | 主鉴频器 | 观察跨度／更新 |
|---|---|---|
| ShortFast | 20 ms连续相干DFT＋插值，11点×10 Hz，±50 Hz | 20／20 ms |
| ShortNormal／ShortSlow | 相邻20 ms擦码块atan2，不复平方 | 首次40 ms，随后20 ms更新 |

相邻块时间差为20 ms，按5.2.3节除以$2\pi T$，不沿用同步前$4\pi T$尺度。局部观察保留0.10质量下限、功率和完整性检查。DFT仍提供中心信噪比；本周期DFT成熟且相邻块有效时优先局部结果，否则使用DFT有效结果。

导频鉴相采用四象限atan2，按一周回绕。只有ShortSlow满足7.4节条件后才开放PLL，其余普通状态不注入相位。BOC Long共享积分器可提供160 ms相位诊断，但载波320 ms DFT不代表开启320 ms PLL。

#### 11.5.3 中弱信号载波

| 状态 | 单块连续相干 | 频点数与间隔 | 搜索范围 | 观察／FLL更新 |
|---|---:|---|---:|---:|
| LongFast／Normal | 160 ms | 11点×3.125 Hz | ±15.625 Hz | 160／160 ms |
| LongSlow／普通动态状态 | 320 ms | 11点×1.5625 Hz | ±7.8125 Hz | 320／320 ms |

方法与10.5.3节相同：保存逐1 ms擦码Prompt，逐候选补偿后整窗相干、取功率、寻峰插值。不是20 ms×8／16功率积累，也不是同步前39／15个主码频差平均。边缘峰向内半点，不外插。普通DFT不串联FMS，专用弱状态另按8.5节处理。

#### 11.5.4 码环继续保持主码分块

码环继续使用5.7节的ASPeCT点积方法。共同二次码正负在每个主码的点积与功率中消除，无须跨主码直接相加复相关。

| 状态 | E1主码相干×块数 | B1C主码相干×块数 | 块间累计量 | 细码观察／DLL更新 |
|---|---|---|---|---:|
| ShortFast | 4 ms×40 | 10 ms×16 | 双副本点积与Prompt功率 | 160／160 ms |
| ShortNormal／ShortSlow | 4 ms×5 | 10 ms×2 | 同上 | 20／20 ms |
| LongFast／LongNormal | 4 ms×40 | 10 ms×16 | 同上 | 160／160 ms |
| LongSlow | 4 ms×80 | 10 ms×32 | 同上 | 320／320 ms |

抽头全程保持±0.25／±0.50 chip。ShortFast载波20 ms更新时，细码仍为160 ms；进入ShortNormal／ShortSlow后才改为20 ms。载波辅助持续更新码率，DLL只在新的有效细码观察到来时纠偏。

二次码位置决定擦除哪个符号，软件20 ms网格决定怎样形成载波块，两者不能直接用来推断BOC数据分量的导航bit边界。阶段交接和异常处理沿用11.3节及7.6节，不通过清窗改写NCO相位。

## 12 计算与存储资源

### 12.1 先区分数据窗口与实际内存

以下按单通道列出当前算法保存的主要历史。记录中除复相关外还有时间、实际NCO和有效标志，因此不能只用“一个复数16字节”估算整个观察器。

| 模块 | 主要保留数据 | 窗口结束后的处理 |
|---|---|---|
| 普通载波频点观察 | 最多600条PDI及对应辅助符号、有效性 | 按当前配置取20～600 ms后缀评分，历史仍可保留 |
| 数据位同步 | 最长4019条PDI，即4 s＋19 ms边界余量 | 成功搜索与独立确认清窗；不同时保存两套完整窗口 |
| L5／B2a／E5a二次码同步 | 1000条完整1 ms主码记录 | 搜索失败保留980条；成功转确认则清窗 |
| E1二次码同步 | 250条完整4 ms主码记录 | 失败推进5条主码；成功转确认清窗 |
| B1C二次码同步 | 1800条完整10 ms主码记录 | 失败推进100条主码；成功转确认清窗 |
| 普通码观察 | 最近5 s基础相干块，以及当前观察后缀副本 | 对幅度累计；重配按当前实现重新建立历史 |
| BOC细码观察 | 最近600 ms主码点积统计及当前后缀 | E1最多150个主码，B1C最多60个主码 |
| L5类Sensitivity码观察 | 最近5000条PDI | 每320 ms重算后缀5 s |
| 环路C/N0 | 最多500个20 ms浮点功率比（double约4 kB），另有显示窄宽功率 | 每1 s选择1／5 s控制窗及10 s显示窗 |
| B1C物理C/N0 | 100个100 ms窄宽功率原子 | 每1 s计算1／5／10 s后缀 |
| 极弱导频相位拟合显示 | 最近10000条PDI | 每1 s重算10 s窗口 |

例如单个600条PDI历史的数据载荷为$600\times\operatorname{sizeof}(PdiData)$，不是600×16字节。实际峰值还要加对象、临时旋转数组、评分数组、多个观察器的并行历史和容器容量。

当前部分容器采用`vector`末尾追加、超长后删除首项；先追加再删除可能触发容量增长，删除元素也不会自动释放容量。因此“保留600条”不是内存峰值上限，也不能当成已实现环形缓存或零拷贝。

### 12.2 主要运算量

下表是按代码循环结构计算的算法工作量，不是CPU指令数或运行时间。复旋转包含三角函数或旋转系数生成、复乘与累加，其成本不能等同于一次实数加法。

| 路径 | 一次完整观察的主要工作 | 稳态发布节拍 |
|---|---|---|
| 20 ms、11点载波DFT | 220次候选-PDI旋转累加，11个频点功率及寻峰 | 20 ms |
| 160 ms、11点载波DFT | 1760次候选-PDI旋转累加 | 160 ms |
| 320 ms、11点载波DFT | 3520次候选-PDI旋转累加 | 320 ms |
| 数据Sensitivity三频点FMS | 3×320=960次候选-PDI旋转累加，再按20 ms块取功率 | 320 ms |
| 1 s数据位同步搜索 | 20边界×11频率×1000 PDI=220000次候选处理 | 完整搜索窗结束 |
| 4 s数据位同步搜索 | 880000次候选处理 | 完整搜索窗结束 |
| 2／4 s数据位同步确认 | 20边界×单频率×2000／4000 PDI，即40000／80000次 | 独立确认窗结束 |
| B1C二次码评分 | 900段各算2个功率，再作900×1800=1620000次查表累加 | 首次18 s；失败搜索每1 s重算 |
| L5类Sensitivity的5 s码模型 | 21×13粗模型＋11×11细模型，共394个；约1970000次Prompt旋转累加，再对五抽头累计25000条 | 320 ms |
| 10 s极弱导频显示模型 | 41×31＋11×11=1392个模型；约13920000次Prompt旋转累加，再累计E/P/L | 1 s |

11点DFT的每信号秒候选处理数均约11000；相干时间从160 ms变320 ms，会增大单次计算量并降低发布次数，不能简单声称总旋转量减半。块间功率次数、历史复制和额外支路仍会影响实际耗时。

L5、B2a、E5a、E1二次码评分采用分段FFT。每个20 ms段一次前向、一次逆向，整次评分额外作一次码表前向变换；1 s包含50段，因此共101次FFT。

| 信号 | FFT长度 | 单次FFT基2蝶形数 | 一次1 s评分蝶形数 |
|---|---:|---:|---:|
| L5、E1 | 64 | 192 | 19392 |
| B2a、E5a | 256 | 1024 | 103424 |

该表未计逐点复乘、折叠、功率和候选比较。FFT缓存不等于频率候选：这些FFT只计算二次码位置相关。B1C采用两主码功率查表，不使用该FFT路径。

### 12.3 处理预算与实时性边界

普通PDI处理与成熟窗口计算要分别评估。当前实现在窗口成熟的那次调用集中执行DFT、同步评分或相位模型搜索；不能用160／320 ms平均耗时，替代最坏一次PDI处理的延迟。

| 预算项 | 必须计入的内容 |
|---|---|
| 单次PDI峰值 | 本历元恰好同时成熟的载波、码、同步和显示计算 |
| 单通道每秒总量 | 不同发布周期的平均计算量，加逐PDI输入、控制和历史维护 |
| 多通道资源 | 各通道窗口同相成熟的叠加，不只计算均匀错峰的理想情况 |
| 内存峰值 | 容器实际容量、临时数组、并行观察器与输出对象，不仅是算法窗口长度 |
| 命令截止时间 | 下一生效边界前的计算与传输延迟；迟到须按命令异常处理 |

5 s码观察和10 s只读显示是主要的重计算路径；后者不影响控制结论，但在当前同线程调用中仍消耗时间，不能因“只读”就忽略它的调度成本。正文说明当前实现，不默认已经把这些计算拆到后台或完成嵌入式实时调度。

已有资源实验`docs/knowledge/pilot_resource_20260905.json`只测过指定旧构建中的孤立观察器：11点导频载波约4.5 ms CPU／信号秒，申请内存峰值约571～573 kB；它包含600 ms历史维护，但不包含信号生成、硬件仿真、FSM、其他观察器和日志。该数据不能直接作为当前全部八信号的RAM预算或目标处理器实时性证明。
