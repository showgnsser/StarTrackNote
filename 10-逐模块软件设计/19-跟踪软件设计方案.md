# 跟踪算法与软件设计方案

## 软件接口记号

本文使用以下记号描述软件接口、物理量和时间范围。

| 记号 | 含义 |
|---|---|
| $Z=I+jQ$ | 一条复相关结果，$I$为同相分量，$Q$为正交分量 |
| $[n_0,n_1]$ | 包含首尾历元的闭区间 |
| `ready` | 当前历元刚好形成一个完整观察结果 |
| `valid` | 已形成的结果通过该模块的数值和质量检查 |
| chip | 码相位、码间距和码误差单位 |
| cycle | 载波相位单位，1 cycle等于一个完整载波周期 |
| Hz | 载波频率或频率误差单位 |
| Hz/s | 载波频率变化率单位 |

`ready`和`valid`必须分开解释。`ready=false`表示观察窗口尚未成熟；`ready=true, valid=false`表示窗口已经成熟，但结果没有通过门控。数值0不能代替“尚未成熟”或“无效”。

本文所称PDI（Pre-Detection Integration，预检测积分）均指硬件形成的1 ms复相关结果，不是软件日志的20 ms输出周期。

## 1 设计范围

本方案重点描述“如何从1 ms复相关结果得到载波、码和同步控制量”。软件模块划分只用于承载这条算法链，不在本文展开硬件寄存器、命令号或日志协议。

跟踪算法的处理范围包括：

1. 接收硬件输出的各支路1 ms复相关结果；
2. 完成数据符号、覆盖码和导频二次码同步；
3. 将连续1 ms结果组合成所需的相干积分或功率累加；
4. 形成载波频率、载波相位和码误差观察；
5. 更新载波FLL/PLL和载波辅助DLL；
6. 根据C/N0和环路稳定性选择后续跟踪策略；
7. 输出载波频率修正量、码速率修正量以及观察和同步结果。

软件不访问原始ADC I/Q样点，也不重新完成载波混频、本地码生成或逐样点相关。ADC至1 ms PDI之间的处理由[[09-逐模块定点化/18-跟踪逻辑定点化设计方案|跟踪逻辑定点化设计方案]]规定。

### 1.1 通道初始化参数

一个跟踪通道建立时，只需一次确定下列信号常量：

- 载波频率和标称码速率；
- 主码周期、数据符号周期和导频二次码；
- 数据、导频分量的调制方式、功率比和固定载波相位；
- 当前信号实际具有的相关支路。

这些都是通道建立后不变的参数，不随每条1 ms结果重复输入。

### 1.2 每1 ms输入

跟踪算法每1 ms只接收当前资源池定义的复相关结果。例如：

- 单分量信号输入VE/E/P/L/VL；
- 数据+导频信号输入导频VE/E/P/L/VL和数据P；
- BOC信号输入导频BOC五抽头、导频PRN-only五抽头和数据BOC Prompt。

外部符号辅助是可选输入。启用时，每条PDI同时提供与该PDI严格对齐的$+1/-1$导航符号及其有效标志；未启用时符号为未知状态，软件不得假定数据正负号。

### 1.3 软件输出

软件每1 ms输出两类结果。

第一类是供后续软件和日志使用的当前历元结果，包括：

- 载波频率、载波相位和码误差观察；
- 数据bit或导频二次码同步状态；
- C/N0和环路稳定性监测结果；
- 载波环、码环和当前跟踪状态；
- 哪些观察在本历元真正进入闭环控制。

第二类是后续跟踪使用的控制量，包括：

- 载波NCO频率控制字；
- 码NCO频率控制字；
- E/L与VE/VL抽头间距；
- 下一阶段需要的相关分量、副本和VE/VL使能策略。

## 2 跟踪软件数据链总览

每条1 ms复相关结果按照下列算法链处理。

![[90-附件/图STSW-00_跟踪软件数据链总览_v01.svg]]

图中从左到右给出跟踪算法主线。观察器从相关结果中提取物理误差，环路保存并更新控制状态，监测与状态策略决定后续使用哪组积分时间和鉴别方式。

| 阶段 | 输入 | 处理过程 | 主要输出 |
|---:|---|---|---|
| 1 | 硬件1 ms复相关 | 输入各相关支路，选择默认闭环分量并统一分量固定相位 | 统一复相关组 |
| 2 | 统一复相关组、可选辅助符号 | 搜索数据符号或导频二次码边界，完成符号擦除 | 同步状态和符号对齐相关 |
| 3 | 连续1 ms结果 | 按当前策略相干相加或累加功率 | 相干块和非相干观察窗 |
| 4 | 相干块或功率窗 | 执行鉴频、鉴相、码鉴别和C/N0估计 | 频率、相位、码误差和C/N0观察 |
| 5 | 有效观察、上一次环路状态 | 更新载波环和载波辅助码环 | 载波频率、频率变化率、相位和码率修正量 |
| 6 | 同步、C/N0和环路稳定性 | 选择下一阶段的积分时间、鉴别器和环路带宽 | 跟踪策略和环路控制输出 |

完整处理链为：

```text
1 ms复相关
  -> 硬件相关结果输入与默认分量统一
  -> 同步与符号擦除
  -> 相干积分与非相干积累
  -> 载波、码和C/N0观察
  -> 载波环与载波辅助码环
  -> 频率、相位、码和动态监测
  -> 跟踪状态选择
  -> 载波、码和相关策略控制输出
```

### 2.1 软件模块分层

| 层级 | 输入 | 输出 | 职责 |
|---|---|---|---|
| 硬件相关输入 | 1 ms复相关 | 统一复相关组 | 选择闭环分量并统一分量固定相位 |
| 同步 | 原始1 ms复相关 | 同步状态、符号已处理相关 | 确定数据符号或二次码边界，统一符号 |
| 积分 | 连续1 ms复相关 | 相干块或功率积累 | 按当前策略组织观察数据 |
| 观察器 | 1 ms相关或积分结果 | 频率、相位、码误差、C/N0 | 从相关结果提取物理测量 |
| 环路 | 有效观察、历史控制状态 | 载波和码率控制状态 | 完成预测、校正与状态记忆 |
| 环路监测 | 多次观察和环路结果 | 稳定、动态和锁定证据 | 汇总证据，不生成NCO控制 |
| 状态机 | 环路监测、同步、C/N0 | 当前跟踪策略 | 只选择策略，不实现鉴别器 |
| 控制输出 | 状态策略、环路输出 | 载波、码和相关策略控制量 | 向后续跟踪提供当前控制结果 |

观察器、环路、环路监测和状态机的职责必须分开：

- 观察器只回答“从当前数据测到了什么”；
- 环路只回答“根据测量，下一步控制量是多少”；
- 环路监测只回答“测量与控制是否已经稳定”；
- 状态机只回答“下一阶段应采用哪套观察与控制策略”；
- 日志只记录事实，不能反馈闭环。

### 2.2 每历元结果的有效性

软件每1 ms先建立一份安全默认结果。某个模块只有在本历元收齐完整窗口时才置`ready=true`，只有通过该模块的数值和质量检查时才置`valid=true`。因此同一历元可能出现以下组合：

- 频率观察成熟并进入FLL；
- 相位观察成熟但当前状态禁止进入PLL；
- 码观察仍在积累，DLL只保持或预测；
- 同步仍在搜索，长相干积分尚未开放；
- C/N0沿用最近的新鲜结果，但本历元没有发布新值。

观察是否进入环路必须另行记录。`valid=true`只表示测量通过观察器门控，不等于该测量一定被当前状态用于控制。

## 3 硬件相关结果输入

### 3.1 模块功能

本模块接收当前资源池输出的1 ms复相关结果，并转换成后续同步、积分和观察器共同使用的统一形式。它只做三件事：

1. 将相关整数转换到软件数值域；
2. 保留全部相关支路，同时选出默认闭环分量；
3. 消除数据与导频分量之间已知的固定载波相位差。

![[90-附件/图STSW-01_硬件相关结果输入_v03.svg]]

图中从左到右给出硬件1 ms复相关进入跟踪算法的处理过程。默认闭环分量只是为载波环和码环建立统一入口，不删除数据P支路或BOC的PRN-only副本。

本模块不执行符号同步，不做长积分，不形成频率、相位或码误差观察。

### 3.2 输入

| 输入 | 单位或格式 | 作用 |
|---|---:|---|
| 1 ms复相关 | 复整数 | 当前资源池的全部有效相关支路 |
| 默认闭环分量 | 通道初始化参数 | 指定单分量数据或双分量导频驱动载波环和码环 |
| 分量固定载波相位 | cycle | 统一数据与导频的已知固定相位差 |

### 3.3 输出

| 输出 | 单位 | 含义 |
|---|---:|---|
| 完整相关矩阵 | 浮点复数 | 全部有效分量、副本和抽头，数值尺度不变 |
| 默认环路五抽头 | 浮点复数 | 已选择默认分量并消除固定载波相位 |

### 3.4 相关值转换

资源池0、2和3输出s18复相关，资源池1输出s20复相关。软件将每个有效$I/Q$整数直接转换为浮点数：

$$
I_{sw}=I_{hw},\qquad Q_{sw}=Q_{hw}
$$

这里不除以积分样点数，不执行幅度归一化，也不补偿前端增益。整数到浮点的转换不改变相关值之间的幅度比例和复相位关系。

例如某条Prompt相关为：

$$
I_{hw}=-1200,\qquad Q_{hw}=350
$$

软件得到：

$$
Z_P=-1200+j350
$$

后续模块可以直接用该复相关计算功率、相位、叉点积或码鉴别量。

### 3.5 默认环路分量

单分量信号使用唯一的数据分量。双分量信号保留数据与导频结果，但默认载波环和码环使用导频分量。

| 信号 | 分量0 | 分量1 | 默认环路分量 | 固定相位 |
|---|---|---|---:|---:|
| GPS L1 C/A | 数据 | 无 | 0 | 0 cycle |
| BDS B1I | 数据 | 无 | 0 | 0 cycle |
| GLONASS G1 | 数据 | 无 | 0 | 0 cycle |
| GPS L5 | L5I数据 | L5Q导频 | 1 | -0.25 cycle |
| BDS B2a | B2a数据 | B2a导频 | 1 | +0.25 cycle |
| Galileo E5a | E5a-I数据 | E5a-Q导频 | 1 | +0.25 cycle |
| Galileo E1 | E1B数据 | E1C导频 | 1 | +0.5 cycle |
| BDS B1C | B1C-D数据 | B1C-P导频 | 1 | +0.25 cycle |

选择默认环路分量只建立一组方便后续共用的VE/E/P/L/VL，不删除其他分量或副本。数据解调、双分量诊断和BOC双副本鉴别仍可访问完整相关矩阵。

### 3.6 固定载波相位统一

设默认环路分量的固定载波相位为$\phi_0$，该分量原始复相关为$Z$，统一到同相参考后的复相关为：

$$
Z'=Ze^{-j2\pi\phi_0}
$$

展开I、Q：

$$
\begin{aligned}
I'&=I\cos(2\pi\phi_0)+Q\sin(2\pi\phi_0)\\
Q'&=Q\cos(2\pi\phi_0)-I\sin(2\pi\phi_0)
\end{aligned}
$$

同一分量的VE/E/P/L/VL必须使用完全相同的旋转角度，保证载波环和码环使用一致的相位参考。

以GPS L5Q为例，固定相位为$-0.25$ cycle：

$$
\cos(-\pi/2)=0,\qquad \sin(-\pi/2)=-1
$$

因此：

$$
I'=-Q,\qquad Q'=I
$$

这次旋转同时作用于L5Q导频的VE/E/P/L/VL。L5I数据相关仍保持自己的原始分量相位，供独立数据处理使用。

### 3.7 1 ms结果的可用性

算法只消费连续、完整的1 ms复相关结果。移交后不足1 ms的首段积分，以及中间缺少的1 ms结果，不进入相干积分、鉴别器或C/N0估计。

一旦1 ms结果中断，尚未完成的相干块和观察窗立即放弃，后续从新的完整1 ms边界重新累加。接口层如何识别移交残段或硬件异常，不属于本算法模块。

E1和B1C在一个完整主码内分别含有4个和10个1 ms片段。片段位置由后续同步模块根据通道初始相位和每毫秒计数内部维护，不作为每条1 ms复相关的重复输入参数。

### 3.8 处理过程

本模块对每组1 ms复相关按以下顺序执行：

1. 接收当前资源池的1 ms复相关结果；
2. 将全部有效$I/Q$相关整数转换到软件数值域；
3. 保留完整相关矩阵；
4. 选择默认闭环分量；
5. 对该分量的相关抽头执行固定载波相位对齐；
6. 将统一复相关组送入同步、积分和观察模块。

### 3.9 设计约束

- 软件不访问原始ADC I/Q样点；
- 硬件相关整数转换到浮点域时不改变数值尺度；
- 默认环路分量选择不得删除或覆盖其他分量和副本；
- 同一分量的五个码抽头必须使用同一个固定载波相位旋转；
- 不足1 ms或不连续的相关结果不得进入相干块；
- 本模块不执行bit或二次码擦除；
- 本模块不形成频率、相位、码误差或C/N0观察；
- 本模块不更新载波环、码环、环路监测或状态机。
