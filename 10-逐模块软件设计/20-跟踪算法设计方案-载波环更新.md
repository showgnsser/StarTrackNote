# 跟踪算法设计方案——载波环更新

## 1 设计范围

本文规定最新实验候选的载波环更新方法，包括频率预测、FLL与PLL反馈选择、积分递推、参数配置和控制量交接。各信号使用统一的处理流程，按数据或导频处理方式采用两档PLL带宽。本文作为[[10-逐模块软件设计/20-跟踪算法设计方案|跟踪算法设计方案]]的独立专题，候选已完成隔离仿真，尚未替换正式代码。

软件使用双精度浮点数处理频差、相差和积分状态。硬件继续完成逐样点混频、相关及标称1 ms结果输出。环路输出频率控制量，经硬件接口转换为频率控制字，不直接改写载波相位累加器。硬件接口由[[09-逐模块定点化/18-跟踪逻辑定点化设计方案|跟踪逻辑定点化设计方案]]规定。

| 缩略语 | 英文全称 | 中文含义 |
|---|---|---|
| FLL | Frequency-Locked Loop | 频率锁定环，依据频差修正载波 |
| PLL | Phase-Locked Loop | 相位锁定环，依据相差修正载波 |
| NCO | Numerically Controlled Oscillator | 数控振荡器 |
| FCW | Frequency Control Word | 频率控制字，决定NCO相位的逐样点步进量 |
| PDI | Pre-Detection Integration | 预检测积分；本文指硬件标称1 ms相关输出 |
| C/N0 | Carrier-to-Noise Density Ratio | 载波功率与噪声功率谱密度之比，单位dB-Hz |

## 2 工作模式与参数

### 2.1 反馈选择

FLL负责牵引和相位失效后的频率保持；PLL在短周期稳定状态ShortSlow下工作。中弱信号状态不将相位误差用于载波控制。状态由原状态机选择，捕获移交等级仍决定初始入口。

| 本次观察与模式 | 环路更新 | 历史状态处理 |
|---|---|---|
| FLL模式，有新且有效的频差 | 更新FLL，不使用相差 | 继承频率及趋势状态 |
| PLL模式，有新且有效的相差 | 更新PLL，不同时注入FLL频差 | 继承PLL两级积分状态 |
| PLL模式，相位明确失效且有有效频差 | 接回FLL | 先将已有PLL修正并入FLL基频，再清除PLL积分 |
| PLL模式，尚无新相差但有有效频差 | 更新FLL基频 | 保留PLL积分和已有频率修正 |
| 两路均无可用的新观察 | 不执行误差校正 | 保留状态，按原条件执行频率预测 |

“尚无新相差”表示积分窗口尚未完成，不等于相位失效。每个鉴别器结果只在新形成时消费一次，不能将上次误差在每条PDI到达时重复积分。

### 2.2 带宽配置

| 信号 | PLL标称带宽 | PLL期间连续FLL辅助带宽 |
|---|---:|---:|
| GPS L1CA、BDS B1I、GLO G1 | 4.8 Hz | 0 Hz |
| GPS L5、BDS B2a、GAL E5a、GAL E1、BDS B1C | 2.4 Hz | 0 Hz |

辅助带宽0 Hz只表示PLL更新时不连续注入鉴频误差，不表示停用牵引FLL、已确认的频率趋势预测或相位失效回退。FLL带宽仍按原状态配置。上述PLL参数用于本轮已验证的短周期路径，不直接套用于160或320 ms长周期环路。

带宽较窄有利于降低相位噪声，但会减慢动态响应。实际滤波效果还取决于递推系数、积分时间、有效分量功率和控制延迟；标称带宽相同，不代表不同实现的等效噪声带宽相同。

### 2.3 PLL使用条件

当前状态允许相位控制、同步已锁定，并且当前相差有效时，还需满足以下原有确认条件：

| 项目 | 候选配置 |
|---|---|
| C/N0许可 | 相位观察和确认计数两处统一采用28 dB-Hz |
| C/N0确认 | 连续三次独立有效结果达到许可值 |
| 相位观察比例 | 监测结果已形成，且有效比例不低于0.8 |
| 频率观察比例 | 不低于原ShortSlow配置的0.4 |
| 单次频率有效性 | 保留原观察器判决及前级有效频率要求 |

候选取消频率批次RMS上限对PLL的否决，避免将鉴频噪声造成的抖动直接解释为不能锁相。频率监测在其他状态判决中的用途不变。28 dB-Hz指软件选用的跟踪分量C/N0估计值，不是捕获强档门限，也不改变同步门限。

## 3 环路更新方法

### 3.1 参数与状态

| 符号 | 含义 | 单位 |
|---|---|---|
| $p$ | 当前鉴相误差 | cycle |
| $T$ | 当前PLL配置的更新周期 | s |
| $B$ | PLL标称带宽 | Hz |
| $w$ | 带宽换算系数，$w=B/0.7845$ | s⁻¹ |
| $f_0$ | FLL保存的频率控制基值 | Hz |
| $v$ | FLL已确认的物理频率变化率 | Hz/s |
| $r$ | PLL高阶积分状态 | Hz/s |
| $b$ | PLL频率积分状态 | Hz |
| $c$ | PLL频率修正 | Hz |
| $u$ | 载波环输出的频率控制量 | Hz |

$u$与$f_0$使用相同的频率参考，由既有接口换算到硬件FCW。$r$是按PLL递推缩放的内部状态，不能直接作为FLL的物理趋势$v$相加或交接。

### 3.2 频率预测

每个控制边界先执行原频率预测，再处理本次新形成的鉴别器结果。设距上一个控制边界的时间为$\Delta t$，已确认趋势且原预测条件满足时：

$$
f_0\leftarrow f_0+v\Delta t
$$

预测可以每1 ms执行，误差校正则只在新观察形成时执行。趋势尚未确认时，不将其作为每PDI的物理频率预测量。频差继续使用原频率中心时刻补偿；相差使用鉴相结果，不增加相位中心时刻外推。

### 3.3 PLL积分与频率修正

每次有效PLL更新按以下顺序执行，箭头表示将计算结果写回同一个状态变量：

$$
r\leftarrow r+Tw^3p
$$

$$
b\leftarrow b+T\left(\frac{r}{4}+0.55w^2p\right)
$$

$$
c=b+2.4wp
$$

$$
u=f_0+c
$$

第二式使用第一式刚更新的$r$。第一、二式在旧积分状态上累加，保存历史相差的影响；第三式叠加当前相差的比例修正。PLL工作时$f_0$仍可按3.2节预测，但本次新频差不另外更新FLL，避免两路独立校正重复作用于同一控制输出。

本递推采用实验中的SDR式内核，将参考实现第二级状态的一半保存为$b$，保留对应的系数缩放。$b$对应实现中的`pll_i_hz_`，$r$对应`pll_rate_hz_s_`。积分系数和状态定义必须配套使用。

例如，$B=4.8$ Hz、$T=20$ ms、$p=0.01$ cycle（3.6°），更新前$r=b=0$。此时$w\approx6.11855$ s⁻¹，更新后$r\approx0.045812$ Hz/s、$b\approx0.004347$ Hz，得到$c\approx0.151192$ Hz。输出为$f_0+0.151192$ Hz；下一次更新继续使用本次$r$、$b$，不重新从零计算。

### 3.4 FLL更新与状态交接

没有使用PLL且有新有效频差时，沿用原FLL递推：先校正频率趋势积分，再将趋势增量和频差比例项加入频率基值。FLL的频率及趋势状态保留历史频差影响，不是将最新频差直接作为FCW。原FLL系数、趋势更新许可及弱状态处理不在本候选中改动。

PLL相位明确失效、且本次有有效频差可以接回FLL时，先将已有PLL修正吸收到基频：

$$
f_0\leftarrow f_0+c
$$

随后保留原FLL趋势，将$r$、$b$、$c$清零，再执行本次FLL校正。吸收步骤保持校正前的总控制量连续；后续频率变化来自正常FLL校正。没有新相差时不执行这次清零。

仅更换PLL带宽且FLL配置、更新周期和状态兼容时，沿用比例项差额转入$b$的交接方式，保持总频率修正连续。其他状态或周期切换按原实现吸收总控制量并重建积分状态，不新增切换条件。

## 4 积分离散化

当前候选使用当前误差更新历史积分状态，没有对前后两次误差进行梯形平均。以单位增益积分器说明，当前累加形式为：

$$
I_k=I_{k-1}+Te_k
$$

式中，$e_k$为本次输入误差，$I_k$为更新后的积分状态。历史误差已包含在$I_{k-1}$中，但本次增量没有使用上一次误差。梯形积分则为：

$$
I_k=I_{k-1}+\frac{T}{2}(e_{k-1}+e_k)
$$

实际PLL包含3.3节的两级顺序更新，不能仅以一个积分器公式替代整个滤波器。实验参考代码中的两处0.5属于递推系数与状态缩放，不表示对新旧输入取平均，因此不能称为梯形积分。

本轮没有进行当前累加方式与梯形积分的同条件对照。现有带宽及性能结论只适用于已测试的递推，改变积分离散化后需重新验证，不能直接沿用原结论。

## 5 验证依据

本方案依据StarTrack代码仓库提交`d6ec3f8`的实验结果。实验共完成3868次候选闭环运行，基础输入包含185条解析场景、24条IQ训练场景和48条独立IQ验证场景；候选重复运行及追加对照不作为新的独立种子。

推荐候选和基线的独立IQ控制通过数均为47/48，相位精度标记由21/48增加为27/48。三个数据型信号的相位误差明显下降，频率抖动有所增加，码相位精度基本不变。连续0.25或1 Hz的FLL辅助未显示跨信号普遍收益，因此未列入推荐设置。

共同失败的B1C案例发生在PLL启用之前，部分BOC案例仍需更长时间完成同步或进入PLL。TCXO、多径、干扰、纯噪声虚警、严格bit辅助极限及梯形积分对照均不在本次已验证范围内，不据此扩大灵敏度资格。
