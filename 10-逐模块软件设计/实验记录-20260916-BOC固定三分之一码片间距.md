# BOC固定1/3 chip抽头间距对照实验

## 结论

本轮只验证E1/B1C五抽头从固定0.25改为固定1/3 chip是否有收益，不采用候选。正式算法仍为`d409600`，两信号仍保持−0.50、−0.25、0、+0.25、+0.50 chip。

±0.35 chip以内稳定通过由0.25对照的2500/2592降为1/3候选的2478/2592；同输入恢复35例，新增失败57例。E1中弱总27 dB-Hz、±0.35 chip由95/144降至84/144；B1C中弱总32 dB-Hz同一码差由138/144降至135/144。更大的±0.50 chip压力组为5/864→4/864，不能通过扩大抽头间距解决范围外牵引。

本轮两组都使用共同的1/12 chip噪声网格重新运行，因此0.25基线不是实验64的原噪声实现。不能将本轮1/3的84/144与旧实验E1的80/144相比而判断有收益；正确成对比较是95/144→84/144。

## 改动与不变项

| 项目 | 0.25对照 | 1/3候选 |
|---|---|---|
| 五抽头位置，chip | −0.50、−0.25、0、+0.25、+0.50 | −2/3、−1/3、0、+1/3、+2/3 |
| E/L完整距离，chip | 0.50 | 2/3 |
| BOC与PRN-only副本 | 两路使用同一抽头位置 | 同左 |
| 码鉴别 | 两副本点积组合，β=2 | 同左 |
| 小误差归一化增益 | 7 | 22/3 |
| 状态期间的间距 | 固定 | 固定 |
| PDI噪声生成 | 共同1/12 chip网格 | 使用同一网格、相同随机序列 |

令d为E到P的单边距离，当前点积鉴别的小误差增益为g=6+4d。d=1/4时g=7；d=1/3时g=22/3。候选同时校准这个增益，不能扩大间距却沿用旧单位换算，否则会混入DLL有效增益变化。

鉴频器、频率候选、载码环带宽、相干及非相干策略、Normal的3.2 s收敛、同步1.18门限、同步总时限、载噪比估计、失锁规则和最终通过判据均不变。没有增加间距切换、粗码搜索、码差门限或候选选优的运行时分支。全部候选修改只存在于临时Git副本，正式源代码常量未改。

## 噪声模型与公平性检查

原BOC模型把白噪声按1/4 chip区间积分，不能直接用于1/3间距。实验共同网格覆盖−2/3至+5/3 chip，共28个1/12 chip区间；每个本地码片覆盖12份，BOC后6份取反，PRN-only同号相加。单份I/Q各自方差为1/24，每个抽头I/Q方差仍为1/2。

两臂在每条PDI中抽取相同数量、相同顺序的高斯噪声，随后按各自副本区间组合。两布局P位置不变，其两种Prompt的噪声组合完全相同；E/L位置不同，噪声的变化按实际波形重叠计算，不用独立噪声冒充相关噪声。闭环演化不同后，信号均值可以不同，这是控制结果，不是改变发送功率。

独立几何积分检查两布局全部十抽头的10×10协方差矩阵，误差小于1e−14；其中1/4布局与原四分网格的协方差完全相同。它们具有相同噪声分布，但细分后随机数调用数改变，旧种子不再生成旧的具体噪声轨迹。因此两臂均重新仿真，不混用历史成绩。新增CTest检查协方差、Prompt共用噪声和矩阵数量。

## 用例与处理过程

| 项目 | 输入 |
|---|---|
| 信号 | GAL E1、BDS B1C |
| 强入口 | 原始总32和35 dB-Hz |
| 中弱入口 | E1原始总27、B1C原始总32 dB-Hz |
| 初频差 | −62.5、−31.25、−12.5、+12.5、+31.25、+62.5 Hz |
| 初码差 | ±0.125、±0.25、±0.35 chip；另加±0.50 chip压力 |
| 运动 | 从移交起静态、−1和+1 Hz/s，静态仍有非零初频差 |
| 导航位辅助 | 无；公开二次码仅在真实独立确认后擦除 |
| 每例时长 | 90 s；退出或同步超时按正式通道停止 |
| 同步时限 | E1 20 s，B1C 60 s |
| 随机种子 | 复用实验63/64的两批输入编号，每个频差、斜率、功率组合每批2个种子；跨码差复用 |
| 组合 | 信号×入口功率×频差×码差×斜率×种子全交叉 |
| 执行数量 | 每臂3456例，两臂共6912次 |

接收机只消费生成的PDI，发送端频码真值只用于输入与离线计量。原始总功率不改变导频比例：E1为50%，B1C为75%。

“同步”要求实际边界正确；“稳定”另要求无超时、无重捕退出、完整末段数据及末段频差RMS<5 Hz、码差RMS<0.20 chip。BOC统计末20 s，沿用已有牵引判据。同步通过不能替代稳定通过；表中的±0.50是压力，不合并进±0.35以内结论。

## 原因与适用边界

当前理想BOC(1,1)模型下，保持相同两副本点积组合，1/4的纠偏方向反转位置约为±0.393652 chip，1/3为±0.385643 chip。两者小误差斜率均已校准为1，但扩大间距没有扩大正确纠偏区间；真实码差+0.35时，无噪声输出由约+0.08947降至+0.08081 chip。

这个分析与本批±0.35成功率下降方向一致，但不能据此把所有失败都归于某一条曲线。P位置没有改变，BOC Prompt接近相关零点时的载波与同步观察损失也没有消失。当前VE/VL不参与ASPeCT点积码误差，外抽头扩大不会自动提供消歧能力。

因此本轮不采用1/3。下一步若继续优化，应针对码鉴别的正确恢复范围及Prompt低谷期间的载波观察做独立对照，而不是仅扩大固定抽头间距。

本轮是理想相关PDI模型实验，没有执行新的带限CBOC/QMBOC量化IQ、多路径、TCXO、极弱长保持或高动态矩阵；不能外推为实际硬件下所有间距的最优结论。其他六信号的抽头与生产算法未修改，也没有把常规CTest作为它们的新性能矩阵。
