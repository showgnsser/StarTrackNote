# 鉴频质量门与PLL许可消融

## 1 目的与基线

以`35cfae5`的共享FLL辅助PLL、统一预同步趋势候选为基线，检查历史遗留的观察拦截是否必要。辅助带宽0.25 Hz，PLL数据型4.8 Hz、导频型2.4 Hz，纯FLL增益、积分、同步及状态策略不变。实验不把候选合入正式源码，也不新增在线门限。

本轮分别回答：相位监测是否真正拦截PLL、频率结果是否不必要地连带否决PLL、鉴频器的统计质量门是否影响结果。误差预算只做离线核对，不把经典3σ跟踪门限直接当成单次鉴别结果的剔除门限。

## 2 芯片与当前调用链

最新完整参考为`/home/showskills/SN770/PowerPoint/track_full_rebuilt.c`，9,012行，SHA-256为`f97b37fd2d0af5c2bfcbaf20e832ace079c5b9c3eba41484c306a30bd9e7426e`，与前轮逐行审阅版本一致。

| 位置 | 实际行为 | 与本轮门控的关系 |
| --- | --- | --- |
| `carrier_freq_detector`，2205行；`get_freq_error` | 搜索峰值、插值并限幅，正常路径返回鉴频量 | 没有当前通用峰值比、集中度有效比例组合；另有条件编译的连续错误频点退捕获 |
| `carrier_freq_detector_fms`，2356行 | 功率差和比形成鉴频量 | 未见逐次质量比例许可，不表示所有状态都无条件跟踪 |
| `carrier_pll_detector`，1843行 | 相位连续性处理、±67.5°限幅后更新积分 | 限幅不是丢弃整次相位观察 |
| 同函数约2151行 | 累计相位平方统计超限后回退FLL | 芯片存在相位检测，不能概括成完全“不判” |
| `carrier_loop_filter`，2447行 | 同步后根据频差绝对值统计与分系统C/N0连续确认，进入PLL | 是模式进入条件，不等于逐次相位与频率有效比例联合许可 |
| `signal_tracking_normal`，约4750行 | 状态更新允许后调用载波滤波器 | 仍存在状态级退出和恢复处理 |

芯片中名为`ul_carrier_freq_rms`的量实际累加绝对频差，不是平方均根；相位统计、限幅和模式切换也不能混称为单次鉴别结果无效。本文只比较源码行为，不移植其整数尺度、数值门限或独立FLL/PLL输出方式。

芯片`phase_err_check()`检查的是码相关峰偏移，不是载波相位观察的有效性；不能仅按phase这一名称把两类检测混在一起。

芯片本文的系统与鉴别器路径不等于本项目E1/B1C的五抽头平方鉴频。不能因为芯片普通DFT或FMS没有同名质量门，就推断BOC该门一定没有作用；需要本轮同输入删除对照。

当前基线`PhaseMonitor`仍计算100 ms窗口的相位RMS、0.8有效比例和45°诊断标志。但是`phase_status.locked`仅用于日志，PLL入口不读取它。真正生效的是相位窗口成熟与0.8比例、最近频差有效性、频率批次0.4比例，以及28 dB-Hz相位许可与三次C/N0确认。此前仅看监测器实现而将45°称为当前PLL拦截原因不准确，本轮沿调用链和真实使用日志纠正这一点。

旧EXP-043/047/048及2026-09-10实验确实发现取消单次频差门或频率RMS否决可改善相位精度；EXP-048也记录了进一步解除频率依赖的动态反例和首次PLL提前接管。既有收益和反例均保留，不将旧结论直接外推到新的共享状态结构。

## 3 六臂消融与输入

| 标识 | 相对基线的唯一修改范围 |
| --- | --- |
| baseline | 无；重放上一轮统一预同步趋势候选 |
| phase_open | 取消PLL入口对相位窗口成熟及0.8有效比例的要求 |
| link_open | 取消最近频差有效性及频率批次0.4比例对PLL的连带否决 |
| both_open | 同时取消上面两组条件 |
| cn0_open | 在both_open上，再取消相位专用28 dB-Hz重写及三次确认许可 |
| freq_open | 仅取消六种鉴频观察实现中的峰值比、集中度、存在度等统计质量比较 |

所有版本保留`ready`、真实相位观察的基础有效性、位同步、符号处理、正功率及分母要求、频率无歧义范围、边缘峰策略，以及弱状态禁相位。频率趋势许可保持不变；`freq_open`不等于把未完成或没有物理意义的结果强行标成有效。频率质量变化会影响已有DFT/FMS回退选择，这属于该消融的后续效应。完整被取消表达式随机器摘要保存。

`cn0_open`未取消状态机本身的C/N0/SNR转档条件，也未强迫中弱入口使用PLL。三次确认的缓存事件语义在本轮基线中仍可复用旧结果，本轮不将其改为数秒等待，不把该计数称为三次已验证独立测量。

主矩阵为185例L1CA解析×六臂、48例八信号真实IQ×六臂，共1,398次候选运行。沿用上一轮输入：非零初始频码差、不同种子及PRN、32/35 dB-Hz强入口、专属中弱入口；L5频段强入口只用35 dB-Hz。解析包含静态、±1/±5/±50/+166 Hz/s、变化率斜坡及15例20～30 s下降12 dB的衰落。每例六臂独立闭合反馈，共用连续IQ激励并记录字节指纹，不落盘原始IQ。一例末端传输长度差异通过第6节的完整广播补跑解决，原始标志不覆盖。

控制判据沿用同步正确、保持率≥90%、无PDI/命令时序错误、末20 s频差绝对P95≤10 Hz和码差绝对P95≤0.2 chip；相位P95≤15°另作离线标记，不改变控制判据。真实IQ逐PDI检查弱状态是否误用PLL，末20 s审计半周/整周二义性跨越；有混叠时不记为零次跨越。

## 4 结果

| 候选 | 解析控制通过/185 | 解析相位达标/185 | IQ控制通过/48 | IQ相位达标/48 |
| --- | ---: | ---: | ---: | ---: |
| baseline | 170 | 145 | 48 | 28 |
| phase_open | 170 | 145 | 48 | 28 |
| link_open | 169 | 144 | 48 | 28 |
| both_open | 169 | 144 | 48 | 28 |
| cn0_open | 169 | 144 | 48 | 28 |
| freq_open | 170 | 145 | 46 | 27 |

本轮统一预同步趋势候选已完整重跑48例，不再只有父实验的18例局部回归。与父实验重叠的185例解析及18例IQ基线指标逐字段一致；全部48例的连续IQ输入均与父实验核对，尾部传输例另附完整补跑证明。

`phase_open`的185例解析完整指标与baseline完全一致，48例IQ的完整PDI日志也逐字节一致。在本轮覆盖范围内，相位窗口成熟与0.8比例没有提供额外控制作用，可以列为入口依赖精简候选；这不是删除鉴相器本身，也不是证明所有噪声环境都不需要锁定监测。

`freq_open`的185例解析完全一致；IQ中40例指标及PDI日志完全一致，变化的8例全部为BOC强入口。其中两条E1失败，E1其他强例同步时刻有提前也有延后，不能只列有利结果。四条BOC中弱案例与基线一致。部分配置原本已将峰值比或集中度要求设为不构成限制的数值，因此“无变化”也可能表示本路径本来没有实际拦截，不能解释成所有删除项均已通过边界压力验证。

`link_open`、`both_open`及`cn0_open`在IQ中仍为48/48，但解析均新增`pdi_025`失败。其余共同相位达标案例的逐例RMS比值中位数接近1：IQ的link_open为1.00032，both_open为0.99953，未形成明显的稳态精度收益。允许一定失败率并不要求每项都优于基线，但仍须把提前接管的代价与代码精简收益分别报告。

`cn0_open`与both_open的185例解析完全一致，IQ只在两条32 dB-Hz E1强例发生差异，PLL分别多使用4次和11次，末窗仍为LongSlow。因此本轮不能把这个组合消融解释成28 dB-Hz门限或三次确认各自的独立效果，也未证明删除后得到稳定PLL精度收益。

15条12 dB衰落案例六臂均通过原末窗判据；不是完全遮挡资格。选定的`pdi_170`在信号恢复后，以20 ms均匀抽样连续覆盖1 s、频差≤1 Hz且折叠相差≤15°作为离线恢复诊断，baseline为9.161 s、link_open为8.921 s、both_open为8.741 s。这个局部恢复改善与另一条动态失败同时保留，不参与在线控制。

全部IQ日志未发现弱状态使用PLL；相位达标案例的末20 s未发现半周/整周二义性边界跨越或展开混叠。FLL-only区间不作为PLL相位资格，失稳例的混叠保留为无法计数，不记作零次周跳。

### 首次接管定位

固定选择正常`pdi_000`、动态反例`pdi_025`、衰落`pdi_170`进行只读插桩，三例×六臂共18次，与未插桩完整指标逐字段一致。动态反例为32 dB-Hz、+50 Hz/s、种子591000625，首次位同步均为3.259 s。

| 候选 | 首次PLL更新 | 当时频率批次有效比例 | 末20 s频差绝对P95 |
| --- | ---: | ---: | ---: |
| baseline、phase_open、freq_open | 4.664 s | 1 | 0.856 Hz |
| link_open | 4.364 s | 0 | 15.294 Hz |
| both_open、cn0_open | 4.284 s | 0 | 15.399 Hz |

首次接管已发生变化，不应把这条反例解释为稳态必须永久保留0.4门。基线首次启用PLL时，监测RMS约50.3°，仍然允许更新并最终收敛，直接证明45°诊断不是当前入口拦截。删除后的反例不证明0.4是最佳数值，只表明不能把启动准备和连续工作许可不加区分地一起删除。

为分离原因，追加三例首批准备诊断：以cn0_open为基础，只要求当前状态的第一批频率统计已经形成，即`freq_status_.last_epoch>0`；不再检查比例数值或最近频差是否有效，不新增计时参数。三例均通过，首次PLL时刻和全部原指标与基线逐字段一致。动态反例恢复到4.664 s接管、频差P95 0.856 Hz。这个结果支持先区分首批准备与持续许可，不证明新条件已在185/48全矩阵验证，更不自动成为正式新策略。

### BOC鉴频质量对照

`e1_0_v0`为32 dB-Hz强入口，PRN 11，初始频差+31.25 Hz、码差+0.25 chip、动态−1 Hz/s、种子711885142，持续120 s。baseline在7.784 s同步，freq_open未同步且频差持续发散，PLL使用次数均为0。这不是相位监测或PLL辅助导致的差异。

两版日志首次差异发生在44 ms，鉴频量均为−28.224 Hz、集中度均为0.386、信号存在性指标均为0.374。原强入口要求集中度≥0.65、存在性指标≥0.14，只有前者未通过；原版不使用本次观察，取消版更新FLL。这定位了首次不同的判断，但不能据此断言这次鉴频量本身一定错误，或把0.65当成理论最优值。

补充对照仅恢复五抽头集中度比较，其他取消的质量比较仍然关闭；使用同一条E1 IQ复验，不引入新门限。该例恢复通过，全部物理指标及完整120 s的PDI日志与baseline逐字节一致，日志SHA-256为`c28c01c8b93e8b522d1fb9aab195f8856ad5bd71538d0284b9e0ffb398c6fd3e`。因此这项比较在当前BOC强入口确实影响闭环，不能与相位窗口许可一起归类为无作用代码；这仍不是0.65最优、不可替代或所有BOC场景均已验证的证明。

第二条反例`e1_1_v1`为35 dB-Hz、PRN 9、频差+11.71875 Hz、码差−0.375 chip、动态−1 Hz/s、种子742989871。baseline在27.301 s同步，freq_open在120 s内未同步，末窗频差P95为10.448 Hz。该例尚未单独运行恢复集中度对照，不把第一条的逐字节恢复结论外推到第二条。

## 5 误差预算的离线核对

以20 ms相干、4.8 Hz带宽作为经典PLL热噪声参考，跟踪分量28/32/35 dB-Hz分别得到一倍标准差5.10°/3.18°/2.24°。代入前先将dB-Hz转换为线性量。此公式没有计入本实验DFT辅助噪声、动态应力和振荡器，不是共享联合环的完整误差预测。

本轮真值仅用于离线计量。只读日志按均匀20 ms抽样区分真实相位的均值、标准差与原始观察RMS；不能把监测器原始RMS当成教材闭环抖动，也不能因真实误差预算超限就在线剔除当前观察。有限窗、相位折叠和反馈相关性均需保留证据边界。

| 解析案例与候选 | 真实相位标准差 | 3倍真实标准差＋均值绝对值 | 相位观察窗口RMS |
| --- | ---: | ---: | ---: |
| 正常pdi_000，baseline | 3.877° | 11.885° | 8.248° |
| 动态pdi_025，baseline | 3.933° | 12.343° | 8.310° |
| 动态pdi_025，link_open | 51.514° | 154.999° | 末窗已在FLL状态，不报告PLL统计 |

表中真实相位在末20 s按20 ms等间隔抽样，共1000点；不是把PLL工作点和非PLL区间混合加权。反例失锁后的折叠相位不再服从小误差高斯模型，154.999°只说明真实误差很大，不解释为精确失锁概率。稳定案例的观察RMS与真实跟踪标准差明显不同，不能互相替代。

TCXO在本矩阵中关闭；没有振荡器Allan偏差、振动、多径及干扰的完整新验证。热噪声计算和本轮消融只能支持逐步整理许可，不能直接产生全信号最终跟踪门限。

### 工程结论

优先精简相位窗口与PLL入口的连接，保留鉴相和必要的只读统计。频率依赖应拆分首次接管准备与持续许可，三例诊断支持这一方向，但尚不将首批形成条件作为全矩阵采用方案。BOC强入口集中度比较在当前结构中有明确闭环作用，暂不与其他冗余许可一起删除；若希望取消，应另外验证该鉴频器噪声与环路增益的匹配，不能用“芯片无同名门限”作为充分理由。

本轮没有新增在线阈值或正式策略。六个版本只是消融工具，不保留为六种产品运行模式；正式`src/`、`include/`及CMake与`35cfae5`一致。
