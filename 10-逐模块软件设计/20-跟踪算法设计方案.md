# 跟踪算法设计方案

## 缩略语

| 缩略语 | 英文全称或名称 | 中文含义 |

| GNSS | Global Navigation Satellite System | 全球卫星导航系统 |
| GPS | Global Positioning System | 全球定位系统 |
| BDS | BeiDou Navigation Satellite System | 北斗卫星导航系统 |
| GAL | Galileo | 伽利略卫星导航系统 |
| GLO | GLONASS | 格洛纳斯卫星导航系统 |
| ADC | Analog-to-Digital Converter | 模数转换器，将模拟信号转换为数字样点 |
| I/Q | In-phase / Quadrature | 同相／正交分量，共同表示复数信号 |

| C/A | Coarse/Acquisition | 粗捕获码；L1CA为本文对GPS L1 C/A信号的简写 |

## 1 设计范围

本文规定GNSS接收机从捕获结果移交到持续跟踪的算法处理，包括相关结果积分、载波与码误差估计、位同步与二次码同步、环路滤波、跟踪质量监测和状态控制。算法以硬件相关结果为输入，更新本地载波频率和码率，保持本地信号与接收信号的频率、相位及码位置对齐，并确定导航数据或导频二次码的时间边界。

### 1.1 适用信号

本方案覆盖以下八种信号，按跟踪处理方式分为三类。Galileo和GLONASS后文分别简写为GAL和GLO。

数据分量承载导航数据符号，导频分量不承载导航数据。主码是相关器使用的周期性伪随机码；覆盖码或二次码是叠加在主码上的已知正负序列，其序列内容与当前序列位置分别确定。

| 类型 | 信号 | 主要处理特征 |
|---|---|---|
| 数据型信号 | GPS L1 C/A、BDS B1I D1、GLO G1 | 处理未知数据符号及覆盖码引起的符号翻转，建立数据位边界 |
| 数据与导频信号 | GPS L5、BDS B2a、GAL E5a | 分别处理数据与导频相关结果，利用导频二次码同步建立连续积分条件 |
| BOC类信号 | GAL E1、BDS B1C | 同时处理数据与导频结构、二次码同步及BOC相关峰的多峰特性 |

E1和B1C同样包含数据与导频分量，因其码鉴别和相关峰选择具有独立要求，单独说明跟踪方案。

### 1.2 算法输入与输出

通道初始化使用捕获移交的信号标识、卫星编号、多普勒频率、码相位、参考时刻和捕获等级。GLO G1同时使用频率频道。捕获等级决定初始采用强信号入口或中弱信号入口。

连续输入为硬件输出的标称1 ms预检测积分结果，简称PDI。每条PDI包含有效支路的同相、正交复相关值，以及对应的时间标识、完整性信息和本地信号参考。软件在PDI基础上组织更长时间的积分，不直接读取原始IQ样点。

算法输出包括载波频率与码率控制量、数据位或二次码同步结果，以及跟踪质量和状态信息。控制量用于更新本地数控振荡器（NCO）；同步结果用于确定积分边界和消除已知符号翻转。

### 1.3 软硬件处理边界

硬件完成载波NCO、码NCO、混频、本地码生成、相关和标称1 ms预检测积分。软件完成PDI组合、符号处理、鉴频、鉴相、码鉴别、环路滤波、同步、质量监测及状态管理。

本文规定软件算法的计算方法、参数含义、数据依赖和状态转换条件。硬件位宽、缩放、寄存器编码及命令装载时序由《跟踪逻辑定点化设计方案》规定；本文仅说明算法计算与硬件接口之间必要的转换关系。

捕获搜索、导航电文译码和定位解算不属于本文设计范围。

### 1.4 数值与单位约定

软件积分、误差鉴别、质量估计和环路滤波统一采用双精度浮点数，直接使用物理量。定点数值转换仅位于PDI解码和硬件控制字编码边界。历元、计数器、数组索引及码符号等离散量使用整数。

| 物理量 | 单位 | 约定 |
|---|---|---|
| 频率、频差 | Hz | 频差相对于对应观察的本地载波参考定义 |
| 载波相位、相位误差 | cycle | 1 cycle表示一个完整载波周期 |
| 码相位、码误差 | chip | 1 chip表示一个主码码片 |
| 码率 | chip/s | 表示本地码每秒推进的码片数 |
| 时间 | s、ms | 参数表可使用ms，代入以秒为时间单位的公式前须完成换算 |
| 载噪密度比 | dB-Hz | 采用对数形式表示，记为C/N0 |

相关结果以复数$I+jQ$表示，I为同相分量，Q为正交分量，j为满足$j^2=-1$的虚数单位。PDI历元表示一条记录在连续PDI序列中的编号，用于标识数据先后顺序。各公式的其余符号在对应计算步骤中定义；观察值同时保留其积分时段和参考时刻。

## 2 总体架构与处理流程

跟踪算法由载波处理、码处理和同步处理三条协同支路组成。载波支路估计并修正频率、相位误差；码支路估计并修正本地码位置；同步支路确定数据位边界或二次码位置。三条支路使用同一时间基准，各自完成积分和结果判决，由跟踪状态统一选择处理方法与参数。本文将根据一段相关数据形成的测量结果称为观察，观察同时记录其有效性和时间参考。

### 2.1 闭环处理结构

硬件输出PDI后，软件按信号分量、符号条件和当前策略组织相关结果，分别形成载波观察、码观察及同步统计。载波环和码环将有效误差转换为控制量，更新硬件NCO；更新后的本地信号参与后续混频和相关，形成下一批PDI。

相干积分是将多条复相关的I、Q分量分别相加；功率累加则是将各相干块的I²+Q²作为功率，再将这些非负值相加。详细计算见第4章。

图中实线表示主要数据与控制关系，虚线表示同步结果对积分和符号处理的配置作用。各支路的积分长度可以不同，载波与码控制不要求在同一历元更新。

载波支路以频率锁定环（FLL）修正残余频差；满足相位控制条件后，允许相位锁定环（PLL）参与载波控制。码支路以延迟锁定环（DLL）修正剩余码率，并利用载波多普勒提供码率辅助。FLL、PLL和DLL的计算关系在第7章规定。

同步候选是由当前数据选出的边界或码位置假设；独立确认使用另一段不重叠的数据验证该假设。同步结果用于确定合法积分边界，并为符号擦除提供位置参考。符号擦除也称擦码，即将已知正负符号乘回复相关，消除该符号引起的翻转。同步支路不代替载波环或码环；同步搜索期间，其他支路仍按当前入口策略运行。

### 2.2 功能模块与职责

测量计算、环路控制和策略选择分别承担独立职责。观察模块输出误差及其时间参考，环路模块更新控制状态，状态管理模块根据监测结果选择后续策略。

| 模块 | 主要处理 | 输出 |
|---|---|---|
| 输入处理 | 解码PDI，选择相关支路，检查时间与数据完整性 | 带时间参考的浮点复相关结果 |
| 积分与符号处理 | 组合相关结果，按可用边界对齐积分，消除已知符号翻转 | 复相干结果、功率或幅度统计 |
| 误差鉴别 | 计算频率误差、相位误差和码误差 | 带有效性及参考时刻的观察值 |
| 同步处理 | 构造边界或二次码位置候选，完成搜索和独立确认 | 同步候选、确认边界及符号位置 |
| 环路滤波 | 根据有效观察更新载波频率、相位修正和码率 | 本地载波与码NCO控制量 |
| 质量监测与状态管理 | 估计信号质量和稳定程度，选择积分、鉴别器及环路参数 | 当前处理策略和状态转换结果 |

同步统计与环路观察分别保留所需的数据历史。同步窗口的长度不直接决定载波环或码环的更新周期；共用PDI也不表示共用同一组累加结果。

### 2.3 跟踪状态概述

跟踪状态是一组积分、鉴别和环路参数的组合，用于规定当前通道的处理方式。Short和Long分别表示短周期与长周期策略组，不直接表示单次相干积分长度；Fast、Normal和Slow分别表示快速响应、过渡收敛和稳定跟踪策略，不代表捕获强、中、弱等级。

除普通状态外，另设高灵敏度、已知bit辅助和动态状态。已知bit辅助是由外部提供导航数据位的正负值及可信时间映射，用于消除数据翻转；动态在此指接收信号频率随时间变化的程度。

下表以L1CA说明各状态的载噪比使用范围，单位为dB-Hz。范围用于描述策略分工，不表示已通过验证的跟踪灵敏度；状态转换还需满足同步、观察有效性、驻留时间及确认条件。

| 状态名称 | 中文名称 | L1CA载噪比范围与条件 | 主要用途 |
|---|---|---|---|
| ShortFast | 短周期快速状态 | 强档移交，载噪比不低于捕获强档门限（32～35） | 强信号入口的初始处理，承担快速牵引及同步建立期间的控制 |
| ShortNormal | 短周期收敛状态 | 通常沿用强入口范围，不另设载噪比分档 | 承接快速处理，逐步转入稳定跟踪 |
| ShortSlow | 短周期稳定状态 | 通常约28及以上；从长周期恢复需达到32 | 强信号稳定跟踪，满足条件后允许PLL参与载波控制 |
| LongFast | 长周期快速状态 | 22至捕获强档门限之间，典型为22～32 | 中弱信号入口的初始处理，利用较长统计支持牵引与同步建立 |
| LongNormal | 长周期收敛状态 | 通常沿用中弱入口范围，不另设载噪比分档 | 同步建立后的中弱信号收敛阶段 |
| LongSlow | 长周期稳定状态 | 通常18～32 | 低动态中弱信号的稳定跟踪 |
| Sensitivity | 自主高灵敏度状态 | 降至18及以下时进入；回升后可在24及以下保持 | 更低信号强度下的自主跟踪，不依赖外部导航bit辅助 |
| BitAiding | 低动态bit辅助状态 | 通常13及以下；13～15为恢复迟滞区，须有可信bit辅助 | 利用可信导航bit消除数据翻转，支持低动态弱信号积累 |
| OutdoorBitAiding | 动态bit辅助状态 | 无独立进入范围；降至13及以下转低动态辅助，升至32及以上转短周期稳定状态 | 通过显式辅助入口启用，采用适应动态的辅助积分与环路参数 |
| MidDynamic | 动态恢复状态 | 动态判别要求大于16，不单独按载噪比分档 | 高动态状态退出后的恢复过渡 |
| HighDynamic | 高动态状态 | 动态判别要求大于16，不单独按载噪比分档 | 残余频率变化较大时增强载波跟随能力 |

强、中弱入口以捕获移交等级为准。22 dB-Hz是L1CA牵引灵敏度目标，不是LongFast的运行下限；牵引期间载噪比变化也不直接改变入口。Fast与Normal的递进主要由同步和收敛条件决定。

稳定跟踪采用不同的降档与恢复门限，形成迟滞区，避免在门限附近反复切换。ShortSlow的低信号退出实际使用每次20 ms观察给出的、折算到1 ms的线性信噪比；门限0.631等效约28 dB-Hz，不直接用长期载噪比估计与28比较。LongSlow降至18及以下时请求Sensitivity，Sensitivity回升至大于24时才请求LongSlow。Sensitivity降至13及以下且bit辅助有效时可请求BitAiding，BitAiding回升至大于15时请求LongSlow；无可信bit辅助时不进入辅助状态。上述请求均需完成相应确认，不能由一次越限立即切换。

普通强信号状态按ShortFast、ShortNormal、ShortSlow逐步收敛；普通中弱信号状态按LongFast、LongNormal、LongSlow逐步收敛。专用状态按适用条件进入，不是所有信号都必须依次经历全部状态。

跟踪状态与同步进度分别维护。同步进度描述边界是否已经找到并通过确认；跟踪状态描述当前采用的处理策略。各状态的具体参数、适用条件和转换规则在第8章规定。

### 2.4 捕获移交与同步建立

捕获移交提供初始频率、码位置及参考时刻。捕获强档采用强信号入口，初始状态为ShortFast；捕获中、弱档采用中弱信号入口，初始状态为LongFast。入口由移交等级确定，后续状态调整由跟踪质量决定。

同步前按信号结构选择初始处理方法。频率居中指残余频差进入当前同步方法允许的范围；码居中指本地码已进入目标相关主峰附近、能够进行局部码跟踪的范围。

| 信号 | 同步前载波处理 | 码处理与同步关系 |
|---|---|---|
| L1CA、B1I、G1 | 持续估计残余频差并执行载波牵引 | 码环独立运行，载波满足频率居中条件后开放位同步 |
| L5、B2a、E5a | 在温启动频差范围内保持移交频率 | 码环与导频二次码搜索并行，二次码确认后建立擦码载波观察 |
| E1、B1C | 基于完整主码相关结果持续执行载波牵引 | 先完成相关峰选择和码居中检查，满足条件后开放二次码同步 |

L5、B2a和E5a采用温启动，即利用已有频率先验限制移交残差；本方案规定其移交频差绝对值不超过12.5 Hz。同步前保持载波频率时，NCO相位仍连续推进；该阶段不利用未知二次码相关结果产生载波闭环修正。

数据型信号可按候选边界临时对齐积分，但仍需继续确认；导频二次码用于闭环擦除前须完成锁定确认。

同步建立后，根据符号可用性调整积分与鉴别方法。未知导航数据仍按数据位边界组织相干积分；已确认的导频二次码可以逐符号擦除，支持跨二次码符号积分。具体积分长度由当前跟踪状态决定，不因同步成功直接切换到最长积分或最窄环路。

### 2.5 观察节拍与结果有效性

每条完整PDI到达后，各模块更新自身统计；只有相应观察窗口收满且达到发布时刻，才形成一次新结果。硬件PDI周期、软件相干积分长度、观察跨度和环路更新周期是不同的时间量。

例如，20 ms相干积分与8次功率累加构成160 ms载波观察时，软件每完成一个20 ms块更新功率统计，收齐8块后才输出一次鉴频结果。其间硬件仍持续输出标称1 ms PDI，载波NCO和码NCO连续运行。

| 观察情况 | 处理原则 |
|---|---|
| 数据尚未收满 | 继续累积，不向环路发布新误差 |
| 窗口完成但结果无效 | 不使用该结果修正环路，按对应方法重启或更新统计 |
| 窗口完成且结果有效 | 结合参考时刻及当前策略形成控制更新 |

没有新观察不表示误差为零。环路保留已有控制状态；若当前策略允许可信的频率变化率预测，则按该预测推进。旧观察不能作为新误差重复进入环路滤波。

### 2.6 策略切换与跟踪连续性

质量监测根据相关结果和有效误差形成载噪比、频率稳定性、码稳定性及相位质量等信息。状态管理据此选择积分时长、鉴别方法、环路增益和相位控制许可。同步进度与跟踪状态分别维护，同步锁定不等于载波相位锁定。

中弱信号状态以频率控制保持载波，不将相位误差注入载波NCO。强信号也只有在状态许可、稳定性和信号质量条件满足后，才开放PLL控制。

正常策略切换保留连续载波相位和码相位，并按新配置处理积分历史。时间边界、符号解释或积分方式不兼容时，丢弃未完成统计，从新的合法边界重新收数；不将旧配置下的半个积分块拼入新配置。

同步候选未通过确认时，按该信号的重试规则重新搜索或确认，并保留适用的牵引策略。中弱入口的正常同步失败不转入强信号入口。PDI缺失、时间不连续或硬件命令异常属于独立的输入与控制故障，按相应恢复规则处理，不能与普通同步重试混为同一事件。

## 3 输入数据与时间基准

输入处理将硬件PDI转换为带有统一数值和时间参考的软件相关结果。各支路必须明确其所属信号分量、本地码副本、相关抽头及积分时段，保证后续积分、同步与误差鉴别使用相互一致的数据。

### 3.1 PDI数据组成

一条PDI对应一个标称1 ms码片段。硬件在该片段内完成混频与相关，软件读取片段结束后的复相关累加值，不读取片段内部的原始IQ样点。

| 数据类别 | 主要内容 | 算法用途 |
|---|---|---|
| 复相关结果 | 各有效分量、副本和抽头的I、Q累加值 | 形成载波、码环及同步观察 |
| PDI历元 | 当前记录在连续PDI序列中的编号 | 检查前后顺序，推进毫秒处理节拍 |
| 样点范围 | 首样点编号及实际累加样点数 | 确定输入数据覆盖的物理时间 |
| 主码标识 | 主码周期号、周期内片段号及每周期片段数 | 识别主码边界，组织完整主码相关 |
| 本地信号参考 | 本PDI实际使用的载波频率、相位及码时间参考 | 解释残余误差和历史相关相位 |
| 完整性与控制标识 | 完整片段标志、数据缺口、溢出及已生效命令标识 | 排除不可用于连续观察的记录 |

采样率、主码长度、分量定义和公开码序列属于通道配置，不需要在每条PDI中重复保存。PDI中的动态参考必须对应形成该相关结果时实际生效的硬件配置，而不是软件最新写出的配置。

### 3.2 相关支路与闭环分量

相关结果按“信号分量—本地副本—码抽头”组织。信号分量区分数据与导频；本地副本区分含副载波的调制副本与不含副载波的主码副本；码抽头表示本地码相对于Prompt位置的不同偏移。不叠加BOC副载波、只保留主码的本地副本称为PRN-only。

五抽头按VE、E、P、L、VL排列。P为Prompt相关，E、L位于其两侧，VE、VL为更外侧的两个抽头。每个抽头均保留独立的I、Q值，具体间距由各信号的码跟踪方案规定。

| 信号 | 算法使用的相关支路 | 默认闭环分量 |
|---|---|---|
| L1CA、B1I、G1 | 数据分量五抽头 | 数据分量 |
| L5、B2a、E5a | 导频分量五抽头、数据分量Prompt | 导频分量 |
| E1、B1C | 导频调制副本五抽头、导频PRN-only副本五抽头、数据调制副本Prompt | 导频分量 |

E1、B1C的两组导频相关用于构造码鉴别量，属于同一导频分量的不同本地副本，不能作为两路独立接收信号处理。

选择默认闭环分量只确定通用载波环、码环和同步处理的数据来源，不删除其他有效相关支路。原始分量与副本结果继续保留，供双副本码鉴别和数据符号处理使用。

### 3.3 浮点解码与固定相位统一

硬件相关值按其规定的有符号格式解码后，直接转换为双精度浮点数。输入处理不除以样点数，不执行幅度归一化，也不补偿前端增益。例如，I=−1200、Q=350的相关结果转换后仍表示−1200+j350，各抽头间的幅度比例保持不变。

不同数据与导频分量具有固定的调制相位关系。默认闭环分量进入通用观察器前，先消除该固定相位，使各信号采用一致的相位参考。表中的L5Q、B2a-P、E5a-Q、E1C和B1C-P均为对应信号的导频分量名称。

| 信号 | 默认闭环分量 | 固定相位a／cycle |
|---|---|---:|
| L1CA、B1I、G1 | 数据分量 | 0 |
| L5 | L5Q | −0.25 |
| B2a | B2a-P | +0.25 |
| E5a | E5a-Q | +0.25 |
| E1 | E1C | +0.50 |
| B1C | B1C-P | +0.25 |

表中相位采用本方案的本地载波和分量符号约定。设转换前复相关为Z，固定相位为a，统一参考后的复相关为X：

$$
X=Z\,e^{-j2\pi a}
$$

其中，Z=I+jQ，a以cycle为单位。复数旋转改变I、Q所表示的相位而保持幅度不变；同一分量的五抽头采用相同旋转，保持抽头间的相对关系。

计算示例：L5Q取a=−0.25，旋转后同相分量为−Q，正交分量为I。若输入Z=100−j40，则输出X=40+j100，旋转前后功率均为11600。该处理只消除分量固定相位，不估计未知载波初相，不补偿残余频差，也不消除数据位或二次码翻转。符号擦除在第4章单独规定。

### 3.4 PDI历元与主码分段

PDI历元描述相关结果的先后顺序，主码周期号与片段号描述结果在本地主码中的位置。两者共同确定连续关系，不能仅按接收到的记录数量推断主码边界。

| 信号 | 标称主码周期 | 每周期PDI数 | 周期内片段号 |
|---|---:|---:|---|
| L1CA、B1I、G1、L5、B2a、E5a | 1 ms | 1 | 0 |
| E1 | 4 ms | 4 | 0～3 |
| B1C | 10 ms | 10 | 0～9 |

需要完整主码相关时，E1使用同一主码周期内的4条连续PDI，B1C使用同一主码周期内的10条连续PDI。片段必须从0开始，按顺序收齐；不能将前一周期的末段与后一周期的首段拼成一个完整主码。

若捕获移交发生在片段中间，首条PDI只包含该片段的剩余数据，不进入正常积分。恢复接收后，逐1 ms处理可从下一条完整PDI开始；需要完整主码的支路则等待下一次合法片段0。

主码边界不等于数据位或二次码边界。主码周期号是本地连续计数，二次码序列中的当前位置仍需由同步处理确定。

### 3.5 样点时间与载波参考

本节分别规定相关结果的时间定位、载波参考换算和频率观察到控制时刻的补偿。时间定位说明测量对应何时，参考换算说明频差相对于哪个本地载波，频率时刻补偿则估计测量形成后信号频率发生的变化。相位观察保留其原始误差，不作时间外推。

#### 3.5.1 相关结果的参考时刻

标称1 ms表示码片段长度。码NCO步进随跟踪调整时，一个片段实际包含的ADC样点数可能变化。因此，PDI历元用于毫秒处理节拍，首样点编号与样点数用于定位实际采样时段，两者通过通道起始参考关联。

设一条PDI的首样点编号为n，包含N个样点，采样率为$f_s$。以ADC样点编号0为时间原点，该PDI的样点中心时刻为：

$$
t_c=\frac{n+(N-1)/2}{f_s}
$$

$t_c$单位为s，N必须为正整数。软件读取PDI的时刻不是相关结果的观察时刻，传输和处理延迟不应进入鉴频时间间隔。

计算示例：采样率为10 MHz，首样点编号为10000000，一条PDI包含10000个样点，则样点中心时刻为(10000000+9999/2)/10000000=1.00049995 s。该记录描述约1.0005 s时的相关结果，而不是软件收到记录时的信号状态。

硬件若提供PDI首样点的载波NCO相位，软件使用本PDI实际生效的频率，将该相位推进到上述样点中心，得到与复相关对应的载波参考。相位以cycle表示并按一周回绕，频率以Hz表示。

跨多个PDI形成观察时，观察器根据实际参与计算的数据确定参考时刻。连续、等权窗口的参考时刻通常位于窗口中心；只使用部分有效间隔的方法按实际间隔确定，不能统一用“最后时刻减半个配置周期”代替。

#### 3.5.2 载波频率参考换算

跨多个PDI形成观察时，环路可能已经改变载波NCO频率。需要对历史相关进行频率搜索或相位比较的方法，应依据各条PDI的实际参考处理NCO变化，不能把整段历史都解释为由最后一次NCO命令产生。具体补偿方式由积分与鉴别方法规定。

设观察所用的本地载波参考为f，鉴频结果为d，当前控制边界的本地载波为u，三者均以Hz表示。先不考虑信号自身随时间变化，换算到当前NCO参考的频差e为：

$$
e=f+d-u
$$

f+d还原观察时刻的信号频率；减去u后，得到相对于当前本地载波的剩余误差。这里的频率均采用同一通道频率基准，不是将射频载频直接代入软件环路。

计算示例：f=1000 Hz、d=+2 Hz，表示信号频率估计为1002 Hz。若当前u=1001 Hz，则e=1000+2−1001=+1 Hz，不能把原来的+2 Hz直接再次加到当前NCO。

参考换算同时用于强、中弱入口和同步后跟踪，不以窗口长度或动态大小作为开关。

#### 3.5.3 频率观察的中心时刻补偿

一段数据形成的频率观察对应过去的参考时刻，环路则需要修正当前控制边界的频差。设两时刻之差为Δt，单位s；载波环已建立预测许可的频率变化率为r，单位Hz/s。将频率近似按线性变化推进后，送入FLL的误差为：

$$
e=f+d+r\Delta t-u
$$

式中，f、d、u沿用上节定义，rΔt为中心时刻补偿量。r来自载波环自身估计，不使用信号生成器真值或预设场景动态。没有预测许可时，补偿量取0，仍按上节完成NCO参考换算；有效频差仍可用于正常牵引。

计算示例：观察覆盖10.000～10.320 s，参考中心为10.160 s，当前控制边界为10.320 s，因此Δt=0.160 s。取f=1000 Hz、d=+2 Hz、u=1001 Hz，已确认r=+5 Hz/s，则补偿量为5×0.160=+0.8 Hz，送入FLL的频差为1000+2+0.8−1001=+1.8 Hz。若r=−5 Hz/s，补偿量为−0.8 Hz，相应频差为+0.2 Hz。

补偿量由变化率与观察延迟共同决定。下表按等权窗口在末端形成控制更新、Δt约为半个窗口时长计算，不包含额外命令延迟。

| 观察跨度 | 变化率 | 中心至末端的频率变化 |
|---|---:|---:|
| 20 ms | 5 Hz/s | 5×0.010=0.05 Hz |
| 320 ms | 5 Hz/s | 5×0.160=0.80 Hz |
| 20 ms | 50 Hz/s | 50×0.010=0.50 Hz |

长窗或较高动态下补偿量通常更大，但短窗也可能需要补偿；变化率估计误差同样会随Δt被放大。本方案不按信号强度、窗长或动态状态名称另设补偿开关。一次频率补偿用于控制，必须同时满足：当前阶段允许载波校正、本次频率观察成熟且有效、观察至控制边界的时间差有效且非负，以及当前状态具有预测许可。没有预测许可时仅作NCO参考换算；没有有效观察时不形成一次新的FLL校正。

预测许可可以由当前状态建立，也可以从兼容前级继承。它表示载波环允许使用自身估计的变化率，不等同于已完成同步，也不等同于进入了某个强信号或动态状态。

| 信号与阶段 | 频率时间补偿的使用方式 |
|---|---|
| L1CA、B1I、G1强入口牵引 | 相邻Prompt鉴频提供有效信号频率估计后，可建立预测许可，后续有效观察使用已有趋势补偿 |
| E1、B1C强入口牵引 | 正常执行主码鉴频；由独立频率监测建立预测许可后，对有效观察补偿 |
| L1CA、B1I、G1、E1、B1C的中弱LongFast，尚未建立可用同步对齐 | 不建立变化率预测，按原入口方法牵引，不对粗频率结果强行外推 |
| L5、B2a、E5a首次导频同步锁定前 | 保持温启动移交频率，不用频率观察及其时间外推驱动载波环 |
| 八种信号的ShortNormal，且当前允许FLL校正 | 一次实际用于FLL的物理有效频率观察可以建立许可，不必等待完整监测批次 |
| 建立可用同步对齐后的其他普通跟踪状态 | 由有效独立监测建立许可，或按换档规则继承已有许可；同步事件本身不直接开启补偿 |
| 高灵敏度、已知bit辅助及动态状态 | 同样按已有或合法继承的许可使用；有有效物理频率监测时也可按普通规则建立，不因C/N0低、使用FMS或进入辅助状态自动开启或关闭 |

数据型信号的可用同步对齐包括进入独立确认的有效候选边界，仍不等同于最终锁定；导频闭环擦码要求二次码锁定。普通路径建立预测许可时，独立变化率拟合及其标准差必须有效、数值有限；在此基础上，频率批次已满足现有有效率与RMS判据，或者拟合变化率的绝对值至少达到其标准差的3倍。实际补偿仍使用载波环自身的变化率r，不直接把拟合值写入控制量。

计算示例：频率批次尚未满足稳定性判据时，若拟合变化率为0.5 Hz/s、标准差为0.1 Hz/s，二者比值为5，满足3倍条件；若拟合变化率为0.05 Hz/s、标准差仍为0.1 Hz/s，比值仅0.5，不能据此建立预测许可。这里判断的是估计的可靠程度，不是设置0.5 Hz/s等固定动态门限。

当前状态的预测许可与换档时的趋势交接证据分别管理。兼容换档可以保留原许可，但只保留一个变化率数值并不自动建立许可；普通LongFast→LongNormal→LongSlow还要求新鲜且一致的独立频率批次证据。新批次不可靠时撤销这条普通慢链的交接资格，不等同于立即清除当前状态已有的预测许可；无效观察本身仍不得用于校正。

数据位同步的一次性校频、需要重建FLL趋势的观察模型或参数切换、不允许保留趋势的状态切换，以及PDI／命令时间轴中断，均清除相应旧许可，后续按同一规则重新建立。仅改变PLL带宽不因此清除FLL趋势。对静态或低动态也不额外强制关闭：若已确认的r接近0，补偿量rΔt自然接近0。

固定FMS能否继续校正高阶趋势，与是否使用已有趋势作时间补偿是不同权限。禁止FMS改写变化率时，仍可按已经保留的预测许可作频率补偿；不能把FMS趋势校正条件当成中心时刻补偿的开关。

#### 3.5.4 相位观察的控制使用

PLL使用鉴相器输出的原始相位误差，单位为cycle，不增加频差乘观察延迟的相位外推项。相位结果按所用鉴相器的周期回绕，并保留观察参考时刻。

计算示例：数据型鉴相结果按半周回绕，0.30 cycle转换为0.30−0.50=−0.20 cycle；已位于合法范围内的0.05 cycle保持不变。回绕只选择等价相位表示，不将测量外推到另一时刻。

该相位结果只有在同步已锁定、当前状态允许PLL、相位观察有效且所保存频差有效并满足绝对值不超过1 Hz时，才有资格用于相位控制；同时须满足载噪比连续确认、相位有效率及频率稳定性条件。中弱FLL状态不将相位误差注入载波NCO，不能因启用频率时间补偿而一并开放PLL。

#### 3.5.5 处理位置与时间连续性

频率中心时刻补偿位于软件载波控制的输入端：观察器先完成积分、鉴别和有效性判断，保留原始观察及参考；控制处理再将本次可用频率观察换算到当前边界，由FLL执行滤波。PLL独立使用通过门控的原始相位误差，两条支路共同形成硬件频率控制字。频率补偿不是新的鉴频器，不增加频率搜索候选，也不改变硬件PDI周期。

环路按已有趋势推进本地频率，与将新测量推进到当前时刻，是对预测状态和测量的分别处理。换算时必须使用当前控制边界的NCO频率，不能用窗口末端NCO冒充观察参考，再重复增加半窗趋势。观察副本完成换算后按对应节拍消费一次；状态切换预览使用相同的时刻与参考约定，不将预览结果再次叠加到控制结果。

时间差依据PDI及命令的控制时间轴确定，不使用程序运行耗时。观察无效、时间非有限或观察时刻晚于控制时刻时，不使用该结果校正；PDI或命令时间轴中断时撤销旧趋势预测，在恢复后的控制边界重新建立时间关系。

上述处理仅调整软件测量与控制量，不重装硬件载波相位，不回改已经形成的相关结果，也不能恢复积分期间已发生的相干抵消。具体环路递推关系在第7章规定。

### 3.6 数据有效性与连续性检查

输入检查区分记录故障与信号质量不足。记录完整只表示其时间和数值来源可以解释，不表示当前信号已经满足鉴频、码鉴别或同步条件。

| 输入情况 | 处理要求 |
|---|---|
| 首段不足一个完整码片段 | 不进入正常积分，从后续合法边界收数 |
| PDI缺失、重复或顺序错误 | 丢弃跨断点的未完成统计，重新建立连续时间关系 |
| 主码周期号或片段号不连续 | 当前主码组合失效，完整主码支路重新等待片段0 |
| 相关累加溢出 | 不使用该记录形成有效观察 |
| 命令迟到或实际生效标识异常 | 不按预期命令解释该PDI，交由控制恢复处理 |
| 浮点计算出现非有限结果 | 对应计算结果无效，不进入环路更新 |

正常命令号变化不构成数据断点。只要命令在规定边界生效，载波与码相位连续，观察器就按实际参考继续处理。

完整PDI中的零相关或低幅度结果不直接作为时间故障处理，其功率、分母和统计可靠性由后续观察器判断。输入层不额外增加信号强度门限。

## 4 积分与符号处理

积分用于将多条相关结果组合成可靠的载波、码环或同步观察。积分方式由符号可用性、残余频差和目标观察方法共同决定。延长相干积分能够提高理想条件下的信噪比，但要求积分期间的符号与载波相位保持一致；无法满足该条件时，采用短块相干与块间非相干累加。

### 4.1 积分处理流程

积分支路接收第3章定义的复相关结果和时间参考，先确定当前可用的边界及符号，再按配置形成相干块。相干块可以直接用于鉴别，也可以转换为功率或幅度后继续累加。

频率候选是用于比较的若干残余频差假设。需要候选补偿的观察器，对每个假设分别旋转各条复相关，再进行相干求和。各候选保留独立的统计结果。

对已经合成的一个复数旋转，不能恢复相干积分过程中因频差造成的抵消；候选频率的设置和鉴频方法在第5章规定。

### 4.2 相干积分

相干积分分别累加复相关的同相、正交分量，保留信号相位信息。设一个块内经过必要符号处理后的N条复相关为$X_1$至$X_N$，相干结果为Z：

$$
Z=X_1+X_2+\cdots+X_N
$$

计算示例：两条复相关为3+j4和1+j2，则Z=(3+1)+j(4+2)=4+j6；I、Q分别相加，不先取幅度或平方。

各条相关的信号分量相位一致时，信号幅度随累加条数增长。在等幅信号、独立零均值噪声的理想条件下，N条相加使信号功率增至单条的N²倍，噪声功率增至N倍，输出信噪比提高N倍。实际增益还受到残余频差、符号翻转、动态和相关噪声等因素影响。

残余频差使复相关相位随时间旋转。积分时间越长，同一频差产生的相位变化越大，复数相加时的抵消越明显。因此，相干时间的增加必须与频率收敛程度、频率补偿能力及符号可靠性相匹配。

未知符号翻转也会造成抵消。例如，两个等幅相干块分别为Z和−Z，直接相加为0。缩短相干块可以减少跨未知符号边界的影响，但在边界未知时，不能保证每一个短块都不跨边界。

### 4.3 功率累加与幅度累加

非相干累加先将每个相干块转换为非负实数，再合并多个块。设M个相干块的复数结果为$Z_1$至$Z_M$，两种合并方式如下。

| 合并方式 | 计算结果 | 保留的信息 |
|---|---|---|
| 功率累加 | $W=\lvert Z_1\rvert^2+\cdots+\lvert Z_M\rvert^2$ | 各块功率，不保留块间相位 |
| 幅度累加 | $A=\lvert Z_1\rvert+\cdots+\lvert Z_M\rvert$ | 各块幅度，不保留块间相位 |

W为功率和，A为幅度和。对一个复相关Z=I+jQ，其幅度为$\sqrt{I^2+Q^2}$，功率为$I^2+Q^2$。两者均采用浮点计算，不使用整数幅度近似。

计算示例：两个相干块分别为3+j4和−3−j4，各块幅度均为5、功率均为25。因此功率和W=25+25=50，幅度和A=5+5=10；若直接复数相加则为0。三种结果表示不同处理，不能混用。

功率和与幅度和都不受单个完整块整体取反的影响。对于Z和−Z，功率和为$2|Z|^2$，幅度和为$2|Z|$。但如果符号在某个块内部翻转，该块已经发生的相干损失不能通过后续非相干累加恢复。

功率累加与幅度累加具有不同的尺度和噪声统计特性，应与后续鉴别公式配套使用，不能相互替代。非相干累加也不等于直接累加原始1 ms功率：如果每块先做20 ms相干，则块内的相干处理仍然保留。

下表比较三种具有相同160 ms观察跨度的组织方式。

| 积分组成 | 160 ms内的处理 | 块间相位要求 |
|---|---|---|
| 连续160 ms相干 | 整段复相关相加，得到一个复数结果 | 整段符号和相位均须满足相干条件 |
| 20 ms相干、8块功率累加 | 每20 ms先求复数和，再将8个块功率相加 | 不要求8个块之间保持相位一致 |
| 20 ms相干、8块幅度累加 | 每20 ms先求复数和，再将8个块幅度相加 | 不要求8个块之间保持相位一致 |

三种方法不能仅以“积分160 ms”统称。载波观察和码观察可以采用不同组成，即使两者具有相同的更新周期。

### 4.4 符号擦除与未知符号处理

公开码序列已知，不代表当前相关结果对应的序列位置已知。擦除一个符号需要同时具备正确的符号值和时间映射。设当前相关结果为X，对应符号c取+1或−1，擦除后的结果为Y：

$$
Y=cX
$$

当X中的目标符号也是c时，由于c²=1，该符号引起的正负翻转被消除。符号擦除不改变相关幅度，也不补偿载波频差。

计算示例：X=−3−j4，已知当前符号c=−1，则Y=(−1)×(−3−j4)=3+j4；若符号本来就是+1，则相关结果保持不变。

B1I的NH20是由20个已知正负符号组成的覆盖序列，每个符号持续1 ms。G1的meander是每10 ms翻转一次、周期为20 ms的已知方波覆盖序列。两者的序列内容固定，当前符号位置仍需与同步边界对应。

| 信号 | 可消除的公开符号 | 擦除后仍需处理的符号 |
|---|---|---|
| L1CA | 无覆盖码 | 未知导航数据位 |
| B1I | NH20覆盖码 | 未知导航数据位 |
| G1 | meander覆盖码 | 未知导航数据位 |
| L5、B2a、E5a、E1、B1C的导频 | 对应导频二次码 | 导频不含导航数据位 |

B1I和G1的覆盖码按可用数据边界恢复。候选边界可以支持临时对齐和覆盖码处理，但仍需独立确认；候选改变或失效时，相应积分统计随之失效。导频二次码用于闭环擦除前必须完成锁定确认。

同一分量、同一历元的全部抽头和所需本地副本使用同一个擦除符号。数据与导频分别使用各自的码序列，不能将导频二次码直接用于数据分量。擦除结果与未擦除结果应保持清楚的数据关系，避免同一符号被重复擦除。

位同步只确定数据位边界，不确定每个数据位的正负。普通L1CA、B1I和G1在消除可用覆盖码后，仍将相干积分限制在一个完整20 ms数据位内，位间通过功率或幅度等方式合并。跨多个数据位的相干积分需要额外可信的已知bit辅助，不能仅凭位同步成功启用。

已擦除二次码的导频可以跨二次码符号或周期连续相干，但相干时长仍须满足载波相位条件。二次码锁定消除的是符号限制，不消除频差和动态限制。

对需要抑制未知正负符号影响的鉴频方法，还可以使用复平方。令X=I+jQ，则：

$$
X^2=(I^2-Q^2)+j\,2IQ
$$

计算示例：X=3+j4，则X²=(9−16)+j(2×3×4)=−7+j24；−3−j4的复平方同样为−7+j24，而两者的功率均为25。复平方结果仍有I、Q两部分。

X和−X的复平方相同，因而不再包含整体正负号差异，但载波相位同时加倍，鉴频尺度也必须相应调整。复平方仍为带相位的复数，不是功率$I^2+Q^2$，也不能等同于非相干积分或已知符号擦除。

### 4.5 积分参数与观察时标

积分配置分别描述块内相干、块间合并、观察跨度和发布节拍，避免将不同处理条件压缩为一个“积分时间”。

| 参数 | 定义 | 示例 |
|---|---|---|
| 单块相干时长 | 一个复数和覆盖的数据时长 | 20 ms |
| 块间合并方式 | 相干块之间的处理运算 | 功率累加 |
| 合并块数 | 形成本次统计所需的完整相干块数 | 8 |
| 观察跨度 | 本次结果使用的数据覆盖时长 | 160 ms |
| 更新周期 | 相邻新结果的发布间隔 | 160 ms |
| 鉴频时间基线 | 相位比较使用的两个观测时刻之差 | 相邻20 ms块的中心间隔为20 ms |

连续、不重叠的M个等长相干块构成一次观察时，观察跨度为单块相干时长的M倍。相邻两个20 ms块联合鉴频需要40 ms数据，但相位中心间隔为20 ms；后续每增加一个完整块，可按对应方法形成下一次观察。观察跨度不能替代鉴频时间基线。

载波牵引、码环、同步搜索和质量监测分别规定是否保留历史，以及历史窗口与更新周期的关系。滑动统计只在相应方法明确允许时使用，不将同步或监测窗口的重叠方式套用于独立的环路观察。

### 4.6 边界对齐与统计更新

数据位内相干从可用位边界开始，并在下一位边界之前结束。例如，20 ms数据位从PDI历元1008开始，则1008～1027构成一个完整块，1028开始下一个块；1010～1029跨越数据位边界，不能按单个数据位直接相干。

若边界建立时当前数据已经位于一个数据位中间，新的位内积分等待下一个合法块首。缺失的前半块不补零，也不从上一配置的历史中任意拼接。

导频完成二次码擦除后，积分起点不必等待二次码序列第0个符号；其起点由当前观察配置和连续PDI决定。需要完整主码的处理仍遵守第3章的分段规则：E1收齐同一周期的4条PDI，B1C收齐10条，不能因已擦码而跨主码边界错误拼段。

| 事件 | 积分统计处理 |
|---|---|
| 相干块收满 | 发布一次完整结果，按配置启动下一块或推进块间统计 |
| 块间统计收满 | 发布本次观察，按该方法规定清空或保留历史 |
| 同步边界改变、符号位置失效 | 丢弃依赖旧边界或旧符号的未完成统计 |
| 相干长度、支路或符号处理方式改变 | 不兼容统计清空，从新配置允许的边界开始 |
| PDI时间断点或记录无效 | 丢弃跨断点统计，恢复连续输入后重新收数 |
| NCO正常连续更新 | 不仅因命令号改变而清窗，继续维护实际载波参考 |

用于触发策略切换的PDI若已计入旧窗口，不再作为新窗口的首条输入重复使用。清除积分状态只影响软件统计，不直接重装载波相位或码相位。

积分结果发布时保留起止历元、观察时长、NCO参考和符号可用性。后续观察器据此选择适用的鉴别方法，不从积分长度本身推断数据符号已知或同步已经锁定。
