# 跟踪代码整理与等价回归

## 结论

基线为`c834234`，生产算法与`d409600`一致；整理后提交为`c7a1504`。本次合并常量、删除无用代码、修正命名和注释，八信号的鉴频、鉴相、积分、带宽、状态和门限不变。

20,832个既有闭环用例全部重新执行，结果逐字段一致，包括同步时间、状态切换、PLL使用次数、退出和频码精度。原有失败同样保留；一致率不是性能通过率，本次不新增灵敏度或硬件资格。

## 代码变更

| 内容 | 处理 |
|---|---|
| 常量文件 | 适配格式并入唯一的`include/constants.h`，删除重复的池1采样率名称；信号表、二次码表、仿真和测试数据保留明确命名的头文件 |
| 状态参数表 | FLL、DLL、更新周期和收敛时间统一使用数字表达式，明确状态顺序，数值不变 |
| 无用计算 | 删除没有生产调用方使用的瞬时中心SNR输出及计算；保留M2M4、NWPR和失锁统计 |
| 无用方法 | 删除正式方法表从未选择的Hold分支；载波牵引继续正常鉴频和更新 |
| 命名与注释 | PLL和载噪比常量增加明确前缀，修正“六态”、辅助符号输入和BOC处理顺序说明，对齐成员注释 |
| 构建与检查 | 历史BOC测试明确使用自己的常量副本，不覆盖生产头文件；增加参数表混写及同名常量文件检查 |

上一轮已取消的Sensitivity专用1/6 chip间距实验6个未提交文件已清理，构建项和测试常量一起删除。源码先备份至`/home/showskills/SN770/CodexTmp/tmp/tracking-cleanup-EPRmub/cancelled-spacing-files.tar.gz`，原实验数据保留。正式BOC抽头仍固定0.25 chip，不增加状态间距切换。
