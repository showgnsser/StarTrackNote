# 当前跟踪方案总表

本文长期维护八种信号实际使用的积分、鉴别方法和重要门限。正文只保留当前值；每次采用新方法，原位更新对应表格，并在末尾记录修改原因、收益、代价和验证依据。实验候选单列，不混入已采用配置；本表不代替灵敏度资格报告。

## 1 实现基线与使用约定

| 范围 | 当前依据 |
|---|---|
| 信号积分、鉴别与已有门限 | StarTrack的`codex/sdr-engine-modes`，提交`cac4896`；第2、4、3.1节及第5节非PLL门限据此记录，尚未全部接入重构通道 |
| 当前重构实现 | `codex/tracking-rebuild`，提交`2230ad8`；已完成共享状态FLL辅助PLL、同步前M2M4／同步后NWPR、频相统计及PLL进入／回退／带宽调度；统一跟踪状态与完整通道尚未接入 |
| 旧完整引擎与重构的差异 | 旧完整引擎默认载波仍为独立FLL/PLL，不随重构提交自动改变；未接入项目见第6节 |

信号简称为GPS L1CA、BDS B1I/B2a/B1C、GLO G1、GAL E5a/E1及GPS L5。L5/B2a/E5a/E1/B1C默认以导频闭环。强档捕获进入`ShortFast`，中、弱档进入`LongFast`，不根据单次载噪比重新选择捕获入口。

硬件始终输出1 ms相关结果。下文“10 ms×16功率”表示每10 ms相干一次，再将16块功率相加；“连续160 ms”才表示整窗相干。DFT均指频率候选旋转、相干累加、取功率及寻峰；普通DFT采用三点插值，不与FMS串联。复平方为复数自乘，不是取功率。

## 2 同步前牵引与同步

### 2.1 载波牵引

| 信号 | 强入口：ShortFast，20 ms更新 | 中弱入口：LongFast，160 ms更新 |
|---|---|---|
| L1CA | 相邻1 ms相关值做asin鉴频，窗内平均 | 10 ms×16功率；11点DFT，间隔12.5 Hz、范围±62.5 Hz |
| G1 | 相邻1 ms相关值做asin鉴频，窗内平均 | 5 ms×32功率；11点DFT，间隔12.5 Hz、范围±62.5 Hz |
| B1I | 1 ms相关值复平方后做asin鉴频，结果除以2，窗内平均 | 同一鉴频方法，延长平均至160 ms；不使用载波DFT |
| L5、B2a、E5a | 保持温启动移交频率，等待二次码同步；不产生FLL校正 | 同左；160 ms为入口码环周期，不表示此时已有载波鉴频 |
| E1 | 4 ms主码相干、复平方；累加相邻共轭积后做atan2，结果除以2 | 4 ms主码相干、复平方；逐相邻主码间隔做atan2，再平均39个频差 |
| B1C | 10 ms主码相干、复平方；累加相邻共轭积后做atan2，结果除以2 | 10 ms主码相干、复平方；逐相邻主码间隔做atan2，再平均15个频差 |

BOC两条中弱路径也需将二倍相位换算回实际频差；五抽头在每个间隔内联合使用，20/160 ms载波窗口不重叠、不跨窗配对。E1调码及停止命令等待期间暂停这一路载波观察，B1C未采用相同的整段暂停。同步前均不使用PLL。

### 2.2 同步搜索与确认

| 信号 | 开放条件 | 搜索方法 | 独立确认 |
|---|---|---|---|
| L1CA、B1I、G1 | 先完成载波频率居中 | 11个频率×20个位边界；频率间隔12.5 Hz、范围±62.5 Hz；按20 ms模板相干、跨位累加功率 | 1/2/4 s分级搜索，确认另取新数据；使用相同边界质量判据 |
| L5 | 温启动移交频差在±12.5 Hz内 | 20个导频二次码位置，不设频率候选；20 ms×50功率 | 1 s搜索＋独立1 s确认 |
| B2a、E5a | 同L5 | 100个导频二次码位置，其余同L5 | 1 s搜索＋独立1 s确认 |
| E1 | 载波观察已建立、相关峰选择及细码居中完成 | 25个二次码位置，不设频率候选；20 ms×50功率 | 1 s搜索＋独立1 s确认 |
| B1C | 同E1，并保持宽峰载波资格 | 1800个二次码位置，不设频率候选；20 ms×900功率 | 18 s搜索＋独立18 s确认 |

数据型搜索可提供一次候选频率校正，经控制路径调整FCW并重建观察；确认阶段不重复校频。五种导频同步不提供校频量。同步失败后按原入口重试，中弱牵引不因此退成强入口。搜索与成功候选的确认数据不复用；导频失败搜索允许滑动，不等于载波窗口滑动。

## 3 同步后的载波与相位处理

### 3.1 各状态的鉴频器

| 状态与职责 | L1CA、B1I、G1 | L5、B2a、E5a、E1、B1C导频 | 载波更新 |
|---|---|---|---:|
| ShortFast：快速收敛 | 正常数据强入口先转ShortNormal再完成同步；入口／恢复处理见2.1节 | 连续20 ms，11点DFT，间隔10 Hz | 20 ms |
| ShortNormal：正常收敛 | 20 ms×1功率，11点DFT，间隔10 Hz | 相邻20 ms擦码块atan2；DFT并行保留作回退及中心信噪比统计 | 20 ms |
| ShortSlow：强信号精跟踪 | 同上 | 同ShortNormal | 20 ms |
| LongFast：中弱牵引／恢复 | 20 ms×8功率，11点DFT，间隔10 Hz | 连续160 ms，11点DFT，间隔3.125 Hz | 160 ms |
| LongNormal：中弱收敛 | 同LongFast | 同LongFast | 160 ms |
| LongSlow：弱信号保持 | 20 ms×16功率，11点DFT，间隔10 Hz | 连续320 ms，11点DFT，间隔1.5625 Hz | 320 ms |
| MidDynamic／HighDynamic：动态恢复／跟随 | 同LongSlow，使用各自环路系数 | 同LongSlow，使用各自环路系数 | 320 ms |
| Sensitivity：自主极弱保持 | 20 ms×16功率，固定0及±5 Hz三支路FMS | 连续320 ms，0及±1.5625 Hz三支路FMS | 320 ms |
| BitAiding：已知bit低动态辅助 | 擦除已知bit，120 ms×5功率，0及±5 Hz三支路FMS | 导频已有已知符号，通常使用自主长相干路径，不据此推定辅助资格 | 600 ms |
| OutdoorBitAiding：已知bit动态辅助 | 擦除已知bit，100 ms×3功率，11点DFT，间隔5 Hz | 同上 | 300 ms |

11点对称网格的范围为±5个间隔，例如10 Hz间隔对应±50 Hz。导频相邻20 ms块鉴频首次需要40 ms，随后每20 ms更新。数据型先擦G1的meander或B1I的NH码，仍不能跨未知导航bit连续相加；导频擦除二次码后才采用上述长相干。

### 3.2 鉴相器与环路控制

| 信号／条件 | 鉴相器 | 是否用于控制 |
|---|---|---|
| L1CA、B1I、G1，导航bit未知 | 20 ms位内相关值的Costas鉴相，半周周期 | 仅ShortSlow且PLL进入条件满足时参与 |
| 五种已同步导频 | 20 ms擦码相关值的四象限atan2鉴相，一周周期 | 同上；长窗相位诊断不等于开放长周期PLL |
| 已知bit辅助 | 擦bit后的atan2可形成相位观察 | 辅助状态仍只使用FLL，不注入相位 |

当前采用SDR式共享状态FLL辅助PLL，已写入重构模块6。未开放PLL时只使用FLL；开放且有新相差时，默认以0.25 Hz辅助FLL共同更新频率和变化率；辅助带宽设为0可使用纯PLL。无新相差但有新频差时使用纯FLL，两路均无新结果则保持。模式选择由上层提供，不在滤波器中新增门限或固定过渡时间。

共享状态在退出PLL、切换带宽时保留；删除旧逐PDI频率预测，避免重复推进趋势。`update_rate`保留“频差只校频／同时写入变化率”的已有选择，不按频差大小另设门限。同步校频同时修改频率积分和输出。旧完整引擎的独立环仍仅用于运行基线与历史对照。

PLL带宽按当前分量NWPR报告选择：小于36 dB-Hz为2.4 Hz，36～<38为4.8 Hz，38～<42为7.2 Hz，42及以上为9.6 Hz；不越过ShortSlow及PLL进入条件。重构模块7.2已实现自动选择并完成测量级联调，尚未接入完整真实PDI通道。芯片提供C/N0分档，四个浮点噪声带宽沿用本地映射；实验中的“数据固定4.8 Hz、导频固定2.4 Hz”不是当前调度方案。

## 4 码鉴别器与积分

| 信号／阶段 | 码鉴别方法与积分 | DLL更新 |
|---|---|---:|
| L1CA、B1I、G1、L5、B2a、E5a，同步前强入口 | 每1 ms先做归一化E/L功率鉴别，再平均20次 | 20 ms |
| L1CA，同步前中弱入口 | 10 ms相干后取幅度，累加16块，归一化E/L鉴别 | 160 ms |
| G1，同步前中弱入口 | 5 ms相干后取幅度，累加32块，归一化E/L鉴别 | 160 ms |
| B1I、L5、B2a、E5a，同步前中弱入口 | 160条1 ms功率相加，再做归一化E/L鉴别 | 160 ms |
| 前述六信号，同步后普通状态 | 20 ms块幅度累加；Short为1块、LongFast/Normal为8块、LongSlow及动态档为16块；E/L或五抽头双差 | 20／160／320 ms |
| E1、B1C，同步前后细码 | ASPeCT双副本点积鉴别；分别按4 ms、10 ms主码形成点积与功率，再跨块累加 | ShortFast及LongFast/Normal为160 ms；ShortNormal/Slow为20 ms；LongSlow及动态档为320 ms |
| L1CA、B1I、G1，Sensitivity | 20 ms块幅度，最近600 ms统计；E/L或双差 | 320 ms |
| L5、B2a、E5a，Sensitivity | 专用5 s相位模型补偿长相干，E/L幅度鉴别；不是普通20 ms分块路径 | 320 ms |
| E1、B1C，Sensitivity | 继续主码分块ASPeCT，最近600 ms统计 | 320 ms |
| 数据型BitAiding／OutdoorBitAiding | 擦bit后120 ms×5／100 ms×3块幅度，E/L或适用状态的双差 | 600／300 ms |

普通六信号在ShortSlow、LongSlow、Sensitivity、OutdoorBitAiding且环路C/N0>13.5 dB-Hz时选择五抽头双差，其余使用E/L；L5类Sensitivity专用码路径固定E/L。BOC不套用这项选择，抽头始终为−0.50、−0.25、0、0.25、0.50 chip。

BOC粗码先进行三方向比较、独立确认及有限调码，再进入细码。E1累加8个160 ms子窗后判断方向，B1C每160 ms判断方向，两者均需两次独立同向确认。以上保留了完整基线的功率／幅度差异；重构已选择的六信号统一幅度法尚未接入该基线。

## 5 重要门限

本节PLL条件已在重构模块7.2实现，其余同步开放、粗细码及跟踪状态条件仍列完整引擎基线。C/N0判据使用环路分量估计，不可直接拿复合信号总功率代入；L5类单导频与复合总量相差约3 dB。

重构载噪比统一采用下表规则。C/N0始终指当前闭环分量，不补偿码偏或残余频差造成的相关损失；1 s／5 s表示功率统计时长，不表示相干积分时长。同步确认和擦码由上层提供，新方法从下一完整块开始，切换时清除历史。

| 载噪比阶段 | 方法与窗口 | 报告规则 |
|---|---|---|
| 同步前，全部八信号 | M2M4：逐1 ms功率及功率平方形成二阶／四阶矩；首报后独立1 s统计 | 首次200 ms、满1 s及以后每1 s；首报仍参加首个完整秒；无法分离正信号和正噪声时为NaN，不套用NWPR固定值 |
| 同步后，全部八信号 | NWPR：逐块求窄宽功率比再平均；块内先擦已知符号，不跨未知导航bit；本次20 ms为主、10 ms另验 | 同样首次200 ms、随后每1 s；当前1 s报告≤18 dB-Hz转长窗、≥22转短窗，中间保持；初始长窗，使用已有1～5个完整秒 |
| NWPR低值输出 | 平均功率比R<1报10 dB-Hz；R=1或可计算结果低于8时报8 dB-Hz | 同时保留原始估计；R≥块内点数等不可计算情况仍为NaN；8/10不表示实际精度或信号存在 |
| NWPR衰落滞后处理 | 长窗报告≥20 dB-Hz，且高于当前1 s至少4 dB时，报告两者dB均值 | 不改相干块长；原始字段仍保存所选长窗估计 |

首报、五秒历史、固定输出及长短窗处理机制已核对芯片`evalu_cn0`；20±2 dB-Hz数值沿用完整工程映射，本次未解析到芯片对应宏的数值定义，不宣称18/22是已确认的芯片宏展开值。M2M4是本次授权的同步前方法，不是芯片该函数已有实现。

芯片同步前也有载噪比来源：捕获移交按档位填写参考值，位同步搜索完成后利用最佳候选相干功率与宽带功率估计C/N0，并在判断同步是否通过之前更新通道值。同步成功后才启动常规NWPR持续更新。此项源码核对不自动替换当前重构已采用的同步前M2M4。

`raw_db_hz`为所选窗口原始估计，`db_hz`为应用上述规则后的报告，线性`snr`与报告一致。22 dB-Hz的1 s M2M4在32种子中仅21个有定义且中位偏高3.16 dB，同步后NWPR为32/32且中位偏差−0.41 dB；不能直接把同步前M2M4高值作为强信号或PLL切换依据。3/4 dB-Hz的固定报告更不能用于灵敏度资格判断。

频差按新观察时长求绝对值均值；相差按新观察时长求未限幅RMS，不减均值。两者使用独立窗口，完整发布后清空；只输入新数据，不重复累计旧结果。模块7.2已接入相差折返、限幅和累计判决，不新增单次频差、相差或有效率拦截。

| 用途 | 当前条件与含义 |
|---|---|
| 数据型同步开放 | 最近3次有效绝对频率估计的跨度≤15.625 Hz，当前残差绝对值≤15.625 Hz |
| 全部同步峰值比 | ≥1.18。数据型比较获胜频点上的主边界与相隔10 ms的边界；导频比较主位置与其余位置最大值，分母定义不同 |
| 数据型同步统计量 | 线性C/N0（Hz）×“窗口长度／500 ms”≥370，不是370 dB-Hz；L1CA/G1另要求峰两侧±1 ms处功率分别高于±2 ms处，B1I不做此峰形检查 |
| BOC同步前鉴频 | 已停用0.65集中度及0.14主码相干比拦截；不因此删除码峰和同步判决 |
| 已同步导频块间鉴频 | 归一化共轭积合成幅度≥0.10；未通过时使用有效DFT回退。单对已知符号相关的该比值为1，不是单次相差门限 |
| BOC粗码 | 三方向对比度≥0.10；E1另要求去噪后的主组功率≥其噪声标准差的4倍；保留独立确认 |
| BOC细码 | 首次试探仅将绝对码差≤0.20 chip的观察送DLL；至少400 ms监测的均值绝对值及RMS均≤0.10 chip后开放同步 |
| BOC有限调码 | 每次≤0.10 chip，160 ms完成；累计同向完成E1 4次／B1C 3次可请求细码试探，不代替居中检查 |
| PLL进入 | 同步锁定且处于ShortSlow；每400 ms新频差绝对值均值<10 Hz，连续3批通过；当前NWPR满足G1>30 dB-Hz、其余>28 dB-Hz；第三批完成后，下一次控制开放PLL |
| PLL限幅与回退 | 按鉴相周期处理折返，先统计原相差，再将反馈限幅至±67.5°；200 ms相差RMS>45°时，当前末次相差仍限幅反馈，下一次转FLL并重新确认；不使用单次频差<1 Hz入口限制 |
| 强弱状态切换 | ShortSlow的1 ms等效线性SNR<0.631累计4次可转长环；普通长状态C/N0≥32 dB-Hz累计21次可回ShortSlow；不是捕获档位切换 |
| 极弱／辅助切换 | 普通长／动态档≤18 dB-Hz累计6次进入Sensitivity；Sensitivity>24累计26次回LongSlow、≤13累计16次且辅助有效进入BitAiding；BitAiding>15累计6次回LongSlow |

状态切换还受同步、码稳定、动态及驻留条件约束，不能仅由C/N0推算必处于哪个状态；上表累计次数不全部要求连续，不满足时按代码递减或清零。PLL的28/30 dB-Hz来自芯片条件，现代导频统一28 dB-Hz是本地映射，不宣称为芯片专属参数。0.631是线性信噪比：按1 ms换算约28 dB-Hz，不是新增的0.631 dB门限。

PLL工作后，C/N0下降或单次频差超过10 Hz本身不立即截断相差，累计相差及上层状态许可决定退出。状态不允许时立即禁PLL并清除质量统计；新NWPR未定义时保持带宽，但不能用于新的进入确认。进入、回退或换带宽均保留共享环路积分，不搬入芯片独立积分清零；无新相差但有新频差时按模块6使用纯FLL，观察空档不重复累计统计。
