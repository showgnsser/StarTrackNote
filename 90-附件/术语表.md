# StarTrack术语表

| 术语 | 含义 |
|---|---|
| PDI | Pre-detection integration，硬件发布的一段相关积分；本项目固定约1 ms |
| NCO | 数控振荡器；载波NCO控制本振相位，码NCO控制本地码相位 |
| DDC | 数字下变频，用本地载波把输入搬到基带 |
| Prompt | 本地码当前中心位置的相关抽头 |
| Early/Late | Prompt两侧的局部码相关抽头 |
| VE/VL | 更外侧的Very-Early/Very-Late抽头 |
| FLL | 频率锁定环，控制载波频率及趋势 |
| PLL | 相位锁定环，在强信号时精修载波相位 |
| DLL | 延迟锁定环，控制剩余码率以维持码峰居中 |
| C/N0 | 载波功率与噪声功率谱密度比，单位dB-Hz |
| 相干积分 | 复数直接相加，保留相位 |
| 非相干积累 | 模平方或鉴别量相加，不保留块间相位 |
| BOC | PRN码再乘方波子载波的调制，相关函数有多个峰 |
| ASPeCT | 用完整BOC和PRN-only双副本抑制旁峰的码鉴别方法 |
| FineCheck | 在稳定抽头几何上用连续细码均值/RMS证明码已进入主峰 |
| finite slew | 在固定时间内叠加有限码率，实现一次有界码相位移动 |
| ready | 观察窗是否完整结束 |
| valid | 完整观察是否通过自身质量与物理门 |
| used | 有效观察是否又通过上层门并实际进入环路 |
| pending | FSM判据已满足，但新策略命令还未被硬件PDI确认 |
| physical_valid | 频率量是否可解释为无偏物理Hz，而不只是控制鉴别量 |
