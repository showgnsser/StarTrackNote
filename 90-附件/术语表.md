# StarTrack术语表

| 术语 | 含义 |
|---|---|
| chip | PRN扩频码的最小符号，不是导航数据bit |
| PRN | 卫星公开的伪随机扩频码模板 |
| code phase | 本地PRN码在主码周期内的位置，单位chip或Q16 |
| PDI | Pre-detection integration；本项目硬件固定发布1 ms相关结果 |
| NCO | 数控振荡器；载波NCO推进载波相位，码NCO推进本地码相位 |
| DDC | 数字下变频，用本地复载波把输入搬到基带 |
| Prompt | 当前本地码中心位置的相关抽头 |
| Early/Late | Prompt两侧的局部码抽头 |
| VE/VL | 更外侧的Very Early/Very Late抽头 |
| replica | 同一抽头的本地码副本；BOC信号保留BOC和PRN-only两套 |
| Observer | 从相关值形成频率、相位或码误差，只测量不控制 |
| FLL | Frequency Locked Loop，控制载波频率及趋势 |
| PLL | Phase Locked Loop，强信号时用相位误差精修载波 |
| DLL | Delay Locked Loop，控制剩余码率以维持码峰居中 |
| carrier aid | 用载波多普勒换算主要码率动态 |
| Monitor | 对一段观察统计均值、RMS、有效率和趋势，不直接控制 |
| FSM | 根据压缩证据选择下一套积分、观察和环路策略 |
| C/N0 | 载波功率与噪声功率谱密度比，单位dB-Hz |
| M2M4 | 用二阶/四阶矩估计C/N0，可用于同步前 |
| NWPR | 用窄带相干功率与宽带功率反解信号/噪声 |
| coherent integration | 复数直接相加，保留块间相位 |
| non-coherent accumulation | 功率或鉴别量相加，不保留块间相位 |
| BOC | PRN码再乘方波子载波的调制，相关函数含旁峰 |
| ASPeCT | 用BOC和PRN-only双副本构造修改功率和局部码误差 |
| modified power | $|R_{BOC}|^2-\beta|R_{PRN}|^2$，是可为负的有符号量 |
| coarse observation | 只给方向的粗码事件，不允许进入DLL PI |
| fine observation | 已在局部单调域内、带chip单位的连续码误差 |
| slew | 固定时间叠加有限码率，使码相位平滑移动固定chip，不是相位跳变 |
| FineCheck | 用连续细码均值/RMS证明已经进入正确主峰的只读安全门 |
| PilotSync | 搜索并独立确认导频二次码相位和边界 |
| PilotWiper | 用已确认公开二次码符号擦除导频全部抽头/副本 |
| ready | 观察窗是否完成或本历元是否有新报告 |
| mature | 规定的监测/测量历史是否已经收满 |
| valid | 已完成观察是否通过数学和统计门 |
| physical_valid | 观察是否有明确物理单位、参考和无模糊解释 |
| used | 观察是否通过上层许可并实际进入环路 |
| candidate | FSM本历元建议的目标，尚未发命令 |
| pending | 新策略命令已发出，等待后续PDI确认 |
| committed | 硬件确认command id后，目标状态正式接管 |
| gap | PDI时间/样点不连续，依赖连续性的窗口必须清除 |
| source tap 3 | 日志中的五抽头组合频率来源，不表示单独某个物理tap |
| handoff | 捕获把信号、PRN、NCO、码相位和起始样点交给跟踪 |
| attraction domain | 闭环从该初始误差会收敛到正确主峰的范围 |
| tracking pass | 闭环稳定和物理误差门通过，不自动包含显示或完整资格 |
| qualification | 固定版本完成规定信号、种子、动态、恢复和耐久矩阵后的范围声明 |
